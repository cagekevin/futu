# 重写设计 —— **让已知的每一类错"写不出来"**

> 日期：2026-10-09 ｜ 起因：用户指出「不要老是去修 bug，要站在**如何把它正确写出来**的角度写」
>
> **本文不是"修哪几个 bug"，是"为什么那几类 bug 本来就不该能写出来"。**
> 每个结构决定都对应**一个我实际犯过的错**，并说明它为什么从此**不可能**。

---

## 一、先把"我犯过的错"按**根因**归类

| 根因 | 我犯的错（实例） | 为什么"事后检查"挡不住 |
|---|---|---|
| **R1. 裸数字没有单位** | `(close − stop) ≤ max_stop_adr × adr`（**美元 ≤ 比例**）⇒ 552 个候选只剩 5 个 | 它能算出数、不报错；**只有"手算一个例子"才看得出来**。而且我把它**误读成"日线做不到"** |
| **R2. "此刻知道什么"没有结构性保证** | 曝险在**开盘前**用了**当日收盘**算的宽度（一天前视）| 每一处单独看都"像是对的"；只有**把时间轴画出来**才看得出 |
| **R3. 出处写在注释里、文档手写** | `rise_12m_min=50%`：**代码注释标"他"、文档写"我定的"** | 两处会**各自漂移**；没有单一来源 |
| **R4. 同一件事在多处重复实现** | 5 处 `trades.append(Trade(...))` ⇒ 其中一处漏了"股数归零要平仓" | 加新出口路径时**必然漏一处** |
| **R5. 审计工具"审不了就跳过"** | `if k in prod` ⇒ 对账**恰好漏掉唯一有 bug 的那条** | 审计工具**自己**制造了盲区 |
| **R6. 条件集用布尔开关切换** | `vcp_filter=True/False` ⇒ **两套框架被连乘**（16 条相乘 = 4e-10）| 布尔开关**表达不了"并列的两套"** |
| **R7. 公式散落** | beta 的 ddof 混用（`np.cov` ddof=1 vs `.var()` ddof=0）| 单个公式"看起来对"，**只有手算已知答案才现形** |

## 二、七个结构决定（每个对应一类错）

### D1. ★ **单位换算只有一个地方** —— 治 R1

**问题**：`美元` 与 `比例` 混算。Python 没有单位系统，所以**不能靠类型**。

**做法**：**所有跨单位的比较，必须走一个具名函数**；代码里**禁止**出现 `... <= ... * adr` 这种裸式。

```python
# backtest/units.py —— 单位换算的**唯实现点**
def adr_multiple(distance_dollars, close, adr_ratio) -> float:
    """把"价格距离（美元）"换成"ADR 倍数"。**唯一的换算式。**"""
    return distance_dollars / close / adr_ratio

def pct_of_price(distance_dollars, close) -> float:
    return distance_dollars / close
```

**并且**：因子层**必须**在名字上带单位（`adr20` → `adr_pct20`；`ma_dist_*` 是 ATR 倍数）。
⇒ 看到 `adr_pct20` 就知道是比例，**不会**写出"美元 ≤ 比例"。

**为什么从此不可能**：唯一换算式在 `units.py`；策略里**只调它**。
再写错，就要在**同一个文件里**写错两次。

### D2. ★ **两个决策点**：`AtClose(t)` 与 `AtOpen(t)` —— 治 R2

**问题**：一天里有两个决策时刻，**能看到的数是不同的**：
- **收盘后**（生成信号）：能看到 **≤ t**
- **开盘前**（定仓/曝险）：只能看到 **≤ t−1**

**做法**：把这两个时刻做成**两个显式对象**，策略/曝险**只能从它们取数**：

```python
# backtest/asof.py
@dataclass(frozen=True)
class AtClose:
    """`t` 日**收盘后**能看到的：含第 t 行。用于**生成信号**。"""
    _cut: int
    def series(self, frame): return frame.iloc[: self._cut + 1]

@dataclass(frozen=True)
class AtOpen:
    """`t` 日**开盘前**能看到的：只到第 t−1 行。用于**定仓 / 曝险**。"""
    _cut: int
    def series(self, frame): return frame.iloc[: self._cut]
```

**装配规则（写进契约）**：
- 选股条件 → `AtClose(t)`（信号在收盘后生成）
- **曝险档位 → `AtOpen(t)`**（开盘前就要定）
- **定仓 → `AtOpen(t)` 的权益**
- 出场判定 → 当日 `high/low/close`（**出场本来就要用当日**，合法）

**为什么从此不可能**：`AtOpen` **物理上取不到**第 t 行 ⇒ 想前视也拿不到数据。

### D3. ★ **出处是数据，文档自动生成** —— 治 R3

```python
class Source(StrEnum):
    ORIGINAL = "原文"     # 他资料里明写的
    INFERRED = "推断"     # 我据原文推的（如"盘整态看昨天"）
    CHOSEN   = "我定"     # 他确实没给（如 5 日区间阈值）

@dataclass(frozen=True)
class Rule:
    key: str
    label: str
    source: Source
    where: str          # 出处行号，`原文` 必填
    unit: str           # "bool" / "ADR倍数" / "比例" / "美元"
    value: Any = None   # 阈值（`我定` 的必须有）
```

**做法**：条件集 = **`tuple[Rule, ...]`**（**唯一来源**）；文档由它**自动生成**。
⇒ `DEFAULTS` 的注释、规格里的表、`--free-params` 的表头，**全部**从这一份生成。

**为什么从此不可能**：出处只有一处；改一处**全局同步**。

### D4. ★ **出场只有一个出口函数** —— 治 R4

```python
def _close(pos, *, day, price, reason, hold) -> Trade:
    """**唯一**构造 Trade 的地方。任何出场路径都必须走它。"""
```

**为什么从此不可能**：新增出场路径时，**只有一种写法**（调它）；"漏字段"无处可漏。

### D5. ★ **审计必须穷举** —— 治 R5

```python
def audit(rules, prod_masks, naive_impls) -> None:
    for r in rules:
        if r.key not in naive_impls:
            raise AuditError(f"规则 {r.key} 没有对照实现 ⇒ **拒绝出结论**")
```

**为什么从此不可能**：审不了就**报错**，不再静默跳过 ⇒ 不可能"恰好漏掉唯一有 bug 的那条"。

### D6. ★ **"并列的规则集"是对象，不是布尔开关** —— 治 R6

```python
BASE_RULES  = (...)          # §6.1 通用条件（T1–T8 + 选股过滤器）
HTF_RULES   = (...)          # §8.1 高位盘整那一支
VCP_RULES   = (...)          # §7.1 VCP 那一支（**替代** base，不是叠加）

@dataclass(frozen=True)
class RuleSet:
    name: str
    rules: tuple[Rule, ...]
```
**跑法是"选一个 RuleSet"，不是"给 base 加开关"** ⇒ 连乘不可能发生。

### D7. ★ **公式集中 + 手算锚定** —— 治 R7

`trade_metrics.py` 的每个公式旁边**必须**有"已知答案"的测试；
且**同一 ddof 只在一个地方决定**（用 `.mean()` 显式写，不用 `np.cov` 的默认）。
