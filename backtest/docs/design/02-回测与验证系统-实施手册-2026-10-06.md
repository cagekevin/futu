## 0. 分层边界（先纠正 01 号文档的错误）

### 0.1 判据（一句话）

> **问：这个量是"关于市场的"，还是"关于你的"？**
> - **关于市场**（市场/标的的客观事实，含参数化派生）→ **数据层**
> - **关于你的**（你的策略 / 假设 / 标准 / 决策）→ **不属于数据层**

一句话：**数据 = 市场是什么样；非数据 = 你决定怎么做。**

**⚠️ 我第一版判据写错了**，记在这里防复发：

> ~~问：换一个消费者，它还成立吗？~~ ← **错的**

那个判据测的是**通用性**，不是**是不是数据**。**反例 = PnL**：

- "换个消费者，PnL 还成立吗？" → **成立**（同一个策略，谁算都一样）
- 按那个规则 → PnL 该进**数据层**
- 但每个策略的 PnL 都进数据层？**显然荒谬**

**通用 ≠ 是数据**；**专用 ≠ 不是数据**（某只股票今天的收盘价很专用，但它是数据）。

**正确的分界是"客观事实 vs 你的决策"**：

| 量 | 关于谁 | 归谁 |
|---|---|---|
| `target_ret`（价格实际怎么走） | **市场**（客观） | 数据层 |
| `PnL`（如果你这么做会怎样） | **你**（反事实） | 回测层 |

**`target_ret` 是"价格实际怎么走"，`PnL` 是"你这么做会怎样" —— 前者是数据，后者不是。**

### 0.2 分工（对 01 §2.2 的一处**再判定**：`target_ret` 仍归回测层）

| 东西 | 关于市场？还是关于你？ | 归谁 | 说明 |
|---|---|---|---|
| K线 / 期权链 / 快照 | **市场** | 数据层 | ✅ 一致 |
| 复权因子 | **市场**（公司行为） | 数据层 | ✅ 一致 |
| 交易日历 | **市场** | 数据层 | ✅ 一致 |
| GEX / walls / RPS | **市场**（客观派生） | 数据层 | ✅ 一致 |
| **复权价** | **市场**（客观派生） | **数据层**（存原料 + 唯一实现） | ✅ 与 01 一致 |
| **标签 `target_ret`** | **混合**：价格事实 **+ 你的执行约定** | **回测层** | ⚠️ 见下 |
| 我的策略的因子值 | **你**（决策产物） | 策略自己 | — |
| PnL / Sharpe / MDD | **你**（反事实：这么做会怎样） | **回测层** | ✅ 一致 |
| 评分 / 判定 / WF / placebo | **你**（你的标准/方法） | **回测层** | ✅ 一致 |

**⚠️ `target_ret` 为什么留在回测层（2026-10-06 更正本手册初版）**：

- 它**不是纯"市场事实"**：`log(open[t+2] / open[t+1])` 里含"**t+1 开盘成交**"这个
  **执行约定** —— 那是**你的交易假设**，不是市场的属性。
- **把假设藏进"数据层" = 让假设隐形**：下游会当它是"事实"，将来换执行约定
  （t+1 收盘 / VWAP）时**不知道去哪改**。
- 且它是**含未来**的量：数据层的键是"观测日 t"，但 t 日的值要 **t+2** 才知道
  → 数据层**没有"可观测时刻"这个概念**，存进去就埋了一个 lookahead 坑。
- ⇒ **留在回测层**（01 §2.2 的原判是对的）。数据层只需给 `open`（它已经给了）。

### 0.3 回测层的全部职责（只剩四件）

```
回测层 = 事实的消费者（纯模拟 + 判决，不生产数据、不落盘数据）
```

1. **PnL** —— 把事实按成本假设折算成收益
2. **指标** —— Sharpe / Sortino / MDD
3. **评分** —— 多目标打分（可选）
4. **判决** —— WF / 判定规则 / placebo / 报告

> **回测层不产出数据、不落盘数据。** 它只输出**报告**（"这个策略 INVALID"）。
> 报告是**结论**，不是市场数据 —— 所以它不算"数据"，可以留在回测层。

"""唯一配置源（B1）。

## 2. 步骤 2：唯一数据入口（接数据层）

### 目标

写 `source.py` —— **回测只经这里拿数据**。

### 为什么用跨进程 CLI

> ⚠️ **先纠正一个我写错的理由**：我第一版写"因为 `data-layer/config.py` 与本地 `config.py`
> 同名冲突，所以用子进程" —— **这是错的**。改名就能解决，**不该当架构理由**。
> 正确理由在下面。

| # | 理由 |
|---|---|
| **1** | **数据层自己推荐跨进程** —— `Agent.md` §1 把「跨进程 JSON」标为**推荐** |
| **2** | **同进程有硬约束**：`Agent.md` §1 写"仅 Python 前端（**需在 `data-layer/` 内运行**）"。回测在 `backtest/`，**不满足** |
| **3** | **只依赖版本化契约**：跨进程走 JSON，契约版本 `CONTRACT_VERSION = "1.0"`（`provide/api.py:27`）。数据层**内部模块改名/重构不波及回测** |
| **4** | **数据层在演进**：它已占用 `config` / `engine` / `store` / `provide` / `fetch` / `data` / `pipeline` / `vendor` / `tests` 等顶层名。同进程会让**回测的文件名被它的命名空间绑住** —— 今天避开 `config`/`engine`，明天它加个 `metrics.py`，我们就撞了 |
| **5** | **代价几乎为零**：回测**一次**加载数据（`align_panel` 一把拿全部标的），spawn 一个 Python 的开销可忽略 |

**结论**：跨进程 —— **不是因为"改名麻烦"，是因为回测只该依赖契约，不该依赖数据层的模块命名空间。**

> 顺带一个好处：走契约后，回测的文件名**完全自由** —— `config.py` / `engine.py` 随便叫，
> 不用担心撞谁。这本身就是"解耦"的体现。

### 建 `backtest/source.py`

```python
"""唯一的数据入口（承 01 §0.3）。

回测**只经这里**拿数据；不 import data-layer 内部，也不自己对齐。
用**跨进程 JSON**（provide.cli）—— 只依赖**版本化契约**
（`CONTRACT_VERSION = "1.0"`），数据层内部改名/重构不波及回测。
（理由见上文「为什么用跨进程 CLI」，**不是**因为"改名麻烦"。）
"""
from __future__ import annotations

import json
import subprocess

import config


def _cli(*args: str):
    """调 provide.cli → JSON。失败**必须报错**，不静默返回空（承 F4/P6）。"""
    proc = subprocess.run(
        [str(config.DATA_LAYER_PY), "-m", "provide.cli", *args],
        cwd=str(config.DATA_LAYER),
        capture_output=True, text=True,
    )
    if proc.returncode != 0:
        raise RuntimeError(
            f"provide.cli {' '.join(args)} 失败（exit={proc.returncode}）："
            f"{proc.stderr.strip()}"
        )
    return json.loads(proc.stdout)


def days() -> list[str]:
    """库里有数据的交易日（升序）。"""
    return _cli("days")


def align_panel(symbols: list[str], *, item: str = "kline",
                days: list[str] | None = None,
                min_bars: int = config.MIN_BARS) -> dict:
    """多品种对齐面板（交集；对齐由**数据层**保证，承 D1 —— 回测不重建）。

    返回（provide.cli align 的契约）：
        {
          "index":   [Unix 秒, ...],             # 公共时间戳（升序）
          "values":  {"SPY": [bar | None, ...]}, # 与 index 等长
          "strategy": "intersection" | "union_ffill",
          "n_symbols", "n_bars", "n_union", "n_dropped", "n_filled",
        }
    bar = {time_key, date, open, high, low, close, volume}
    """
    args = ["align", "--symbols", *symbols, "--item", item,
            "--min-bars", str(min_bars)]
    if days:
        args += ["--days", *days]
    return _cli(*args)


def extract(panel: dict, field: str) -> dict[str, list[float]]:
    """从面板抽出某字段的逐 bar 值。

    ⚠️ **降级即拒用**：`strategy != "intersection"` 时，面板里有 ffill 出来的
    **捏造 bar**（它们**不是 None**，挡不住）→ **硬报错**，绝不静默用假数据（承 D1/P6）。
    缺 bar（None）同样报错，不补。
    """
    if panel.get("strategy") != "intersection":
        raise ValueError(
            f"对齐降级为 {panel.get('strategy')}（交集不足）—— 含捏造 bar，拒绝使用"
            f"（承 D1/P6：宁可报错，不喂假数据）"
        )
    out: dict[str, list[float]] = {}
    for sym, col in panel["values"].items():
        vals: list[float] = []
        for i, bar in enumerate(col):
            if bar is None:
                raise ValueError(
                    f"{sym} 第 {i} 根 bar 为 None（对齐降级？）—— 承 P6 不补"
                )
            vals.append(float(bar[field]))
        out[sym] = vals
    return out
```

## 3. 步骤 3：标签（D2）

### 目标

写 `label.py` —— 未来收益标签。

> **归属声明**：标签**留在回测层**（2026-10-06 更正）。
> 它 = 价格事实 **+ 执行约定**（`t+1` 开盘成交）—— 后者是**你的假设**，不该藏进数据层（见 §0.2）。
> 数据层只提供 `open`（已提供）；**不在数据层定义 label**。

### 建 `backtest/label.py`

```python
"""标签 target_ret（承 D2）。

归属：**留在回测层**（2026-10-06 更正）—— 它含"t+1 开盘成交"这个执行约定，
是**你的假设**，不是纯市场事实（见 §0.2）。数据层只提供 `open`。

口径（写死，不许改）：
    target_ret[t] = log(open[t+2] / open[t+1])
    最后两个位置置 0（边界）。

为什么是 t+1 → t+2 而不是 t → t+1：
    你看到 t 收盘 → 决策 → 实际成交在 t+1 开盘 → 收益算到 t+2 开盘。
    用 close[t] → close[t+1] 是错的（收盘瞬间无法成交）。
"""
from __future__ import annotations

import math

import config


def target_ret(opens: list[float]) -> list[float]:
    """open 序列 → target_ret 序列（与输入等长；尾部 h 个置 0）。"""
    h = config.TARGET_HORIZON
    n = len(opens)
    out = [0.0] * n
    for t in range(n - h):
        denom = opens[t + 1]
        numer = opens[t + h]
        if denom <= 0 or numer <= 0:
            raise ValueError(
                f"open 非法：open[{t + 1}]={denom} / open[{t + h}]={numer}"
                f"（承 P5：异常值显形，别让它变成 math domain error）"
            )
        out[t] = math.log(numer / denom)
    return out
```

## 4. 步骤 4：PnL（R1）

### 目标

写 `engine.py` —— **全系统只有这一套 PnL 公式**。

### 建 `backtest/engine.py`

```python
"""回测引擎：PnL（承 R1）。

PnL 只有**一套公式**，全系统只在这里算（承 R1）。
四行，每行都有坑 —— 见行内注释。
"""
from __future__ import annotations

import math

import config


def positions(factors: list[float]) -> list[float]:
    """因子 → 仓位。

    ① tanh 封顶 ±1（不封 → 可能开 100 倍仓）
    ② |pos| < 阈值 → 空仓（回测/实盘共用同一阈值，承 B4 解耦思路）
    """
    out: list[float] = []
    for f in factors:
        p = math.tanh(f) * config.POSITION_CAP
        if abs(p) < config.MIN_TRADE_EXPOSURE:
            p = 0.0
        out.append(p)
    return out


def pnl_series(pos: list[float], tgt: list[float],
               cost_rate: float = config.COST_RATE) -> list[float]:
    """逐 bar PnL：pos * ret - |Δpos| * cost（承 R1）。

    ③ 换手用**上一根**仓位算（忘了 → 未来函数）
    ④ 换手成本必须算（只算持仓成本 → 高频策略虚高）
    """
    n = len(pos)
    if len(tgt) != n:
        raise ValueError(f"pos({n}) 与 tgt({len(tgt)}) 长度不等")
    out = [0.0] * n
    prev = 0.0                       # ③ 首根之前视为空仓
    for t in range(n):
        turnover = abs(pos[t] - prev)
        out[t] = pos[t] * tgt[t] - turnover * cost_rate
        prev = pos[t]
    return out


def turnover_series(pos: list[float]) -> list[float]:
    """逐 bar 换手 |Δpos|（供审计/统计）。"""
    out = [0.0] * len(pos)
    prev = 0.0
    for t in range(len(pos)):
        out[t] = abs(pos[t] - prev)
        prev = pos[t]
    return out
```

## 5. 步骤 5：指标（B2 / R2 / R3）

### 目标

写 `metrics.py` —— 年化因子自动估计 + 三个指标。

### 建 `backtest/metrics.py`

```python
"""指标：年化因子（承 B2）+ 风险调整（承 R2/R3）。

每个指标都有**明确口径**，不许各写各的。
"""
from __future__ import annotations

import math

import config

SECONDS_PER_YEAR = 365.25 * 86400.0
_EPS = 1e-12


# ── 年化因子（承 B2）────────────────────────────────────────────────────

def periods_per_year(times: list[int]) -> int:
    """从时间戳序列估计「每年 bar 数」（承 B2）。

    不写死周期 —— H1/D1/15min 自动适配。
    失败**显式报错**，不静默回退（承 P1：静默回退会让 Sharpe 放大 26×）。
    """
    if len(times) < 2:
        raise ValueError("periods_per_year：时间戳少于 2 个，无法估计（承 P1）")
    span = float(times[-1] - times[0])
    if span <= 0:
        raise ValueError(f"periods_per_year：时间跨度非正（{span}）（承 P1）")
    years = span / SECONDS_PER_YEAR
    return int(max(10, min(600000, round(len(times) / years))))


# ── 风险调整（承 R2/R3）─────────────────────────────────────────────────

def annual_return(pnl: list[float], ppy: int) -> float:
    """年化 = 单 bar 平均收益 × 每年 bar 数（承 R3：**不再除样本长度**）。"""
    return _mean(pnl) * ppy


def sharpe(pnl: list[float], ppy: int) -> float:
    s = _std(pnl)
    if s < _EPS:
        return 0.0
    return _mean(pnl) / s * math.sqrt(ppy)


def sortino(pnl: list[float], ppy: int) -> float:
    """下行标准差**带地板**（承 R2）。

    地板 = 全序列 std 的 20%。没有它，稀疏 PnL 会靠极小分母刷出天文数字
    （策略只在上涨时交易 → 下行 std → 0 → Sortino → ∞）。
    """
    full = _std(pnl)
    down = [x for x in pnl if x < 0]
    dstd = _std(down) if len(down) > 1 else 0.0
    dstd = max(dstd, max(full * 0.2, _EPS))
    return max(-20.0, min(20.0, _mean(pnl) / dstd * math.sqrt(ppy)))


def max_drawdown(pnl: list[float]) -> float:
    cum = peak = mdd = 0.0
    for x in pnl:
        cum += x
        peak = max(peak, cum)
        mdd = max(mdd, peak - cum)
    return mdd


def side_ratio(pos: list[float]) -> tuple[float, float]:
    """(多占比, 空占比) —— 承 V3：单边 > 85% → 疑似 beta。"""
    if not pos:
        return 0.0, 0.0
    long_ = sum(1 for p in pos if p > config.MIN_TRADE_EXPOSURE) / len(pos)
    short = sum(1 for p in pos if p < -config.MIN_TRADE_EXPOSURE) / len(pos)
    return long_, short


def n_trades(pos: list[float]) -> int:
    """交易笔数（方向变化算一笔）。"""
    n = 0
    prev = 0.0
    for p in pos:
        if p != 0.0 and (prev == 0.0 or (p > 0) != (prev > 0)):
            n += 1
        prev = p
    return n


# ── 内部 ────────────────────────────────────────────────────────────────

def _mean(xs: list[float]) -> float:
    return sum(xs) / len(xs) if xs else 0.0


def _std(xs: list[float]) -> float:
    if len(xs) < 2:
        return 0.0
    m = _mean(xs)
    return math.sqrt(sum((x - m) ** 2 for x in xs) / len(xs))
```

## 6. 步骤 6：分段一致性 + 判定（V2 / V3 / B5）

### 目标

写 `validate.py` —— 带 gap 的**分段一致性**切分 + 8 条硬判定。

### 建 `backtest/validate.py`

```python
"""验证层：Walk-Forward（承 V2/B5）+ 判定规则（承 V3）。

判决**只用 PnL + 硬规则**，不掺任何"搜索期的启发式加分"（承 V1）。
"""
from __future__ import annotations

import config


# ── 分段一致性 + purge gap（承 V2 / B5）─────────────────────────────────
# ⚠️ 名字要诚实（2026-10-06 更正）：固定策略**没有训练**，所以这不是真正的
# Walk-Forward（WF = 在 train 上拟合、在 val 上评）。这里 `train` 段**从不被使用**，
# `gap` 也因此**是空操作**。它真实的作用是：把样本外切成连续 N 段、数"几段为正"
# —— 即**分段一致性检验**。将来引入训练/参数搜索后，再升级为真 WF。

def segment_consistency_folds(n_bars: int, *, n_folds: int = config.WF_FOLDS,
                              gap: int = config.WF_GAP,
                              warmup: int = config.WF_WARMUP) -> list[dict]:
    """把样本外切成连续 n_folds 段（+ purge gap），供"分段一致性"统计。

    val 段：把 [warmup, n_bars) 均分成 n_folds 块。
    fold k 的 train = [warmup, val_start - gap) —— 预留 gap，**将来**若引入训练
    可直接用（标签是 log(open[t+2]/open[t+1])，train 尾部 gap 根的标签会看到 val，
    不丢就是泄漏，承 V2/B5）。
    """
    if n_folds < 2:
        raise ValueError("n_folds 至少 2")
    span = n_bars - warmup
    block = span // n_folds
    if block <= gap:
        raise ValueError(
            f"每块 {block} bar 不足以容纳 gap={gap}（承 B5：fold_size 应 >> gap）"
        )
    folds: list[dict] = []
    for k in range(1, n_folds):
        vs = warmup + k * block
        ve = n_bars if k == n_folds - 1 else warmup + (k + 1) * block
        train_end = vs - gap                       # ← purge
        if train_end <= warmup:
            continue
        folds.append({
            "fold": k,
            "train": (warmup, train_end),
            "val": (vs, ve),
            "gap": gap,
        })
    return folds


# ── 8 条硬判定（承 V3）──────────────────────────────────────────────────

_ORDER = {"VALID": 0, "SUSPICIOUS": 1, "INVALID": 2}


def judge(*, ann_ret: float, sharpe: float, mdd: float, max_side: float,
          h1_ann: float, h2_ann: float,
          wf_positive: int, wf_total: int,
          cost2x_profitable: bool) -> tuple[str, list[str]]:
    """8 条硬判定（承 V3）。返回 (verdict, issues)。

    verdict ∈ {VALID, SUSPICIOUS, INVALID}，取最严重的一条。
    """
    verdict = "VALID"
    issues: list[str] = []

    def down(level: str) -> None:
        nonlocal verdict
        if _ORDER[level] > _ORDER[verdict]:
            verdict = level

    if ann_ret < config.MIN_ANN_RET:
        down("INVALID")
        issues.append(f"年化 {ann_ret*100:.2f}% < {config.MIN_ANN_RET*100:.0f}%")

    if sharpe < config.MIN_SHARPE:
        down("SUSPICIOUS")
        issues.append(f"Sharpe {sharpe:.3f} < {config.MIN_SHARPE}")

    if mdd > config.MDD_SUSPICIOUS:
        down("SUSPICIOUS")
        issues.append(f"MDD {mdd*100:.2f}% > {config.MDD_SUSPICIOUS*100:.0f}%")
        if mdd > config.MDD_INVALID:
            down("INVALID")
            issues.append(f"MDD {mdd*100:.2f}% > {config.MDD_INVALID*100:.0f}%")

    if max_side > config.MAX_SIDE_RATIO:
        down("SUSPICIOUS")
        issues.append(f"单边占比 {max_side*100:.1f}% > {config.MAX_SIDE_RATIO*100:.0f}%（疑似 beta）")

    if h1_ann * h2_ann < 0:
        down("SUSPICIOUS")
        issues.append(f"前后半段异号 H1={h1_ann*100:+.2f}% H2={h2_ann*100:+.2f}%")

    if wf_total and wf_positive < wf_total * 0.5:
        down("SUSPICIOUS")
        issues.append(f"分段仅 {wf_positive}/{wf_total} 段为正")

    if not cost2x_profitable:
        down("SUSPICIOUS")
        issues.append("2x 成本下亏损")

    return verdict, issues
```

## 7. 步骤 7：独立审计（V1）

### 目标

写 `audit.py` —— **只用 PnL + 硬规则判决，不掺搜索期的启发式加分**。

> **R1 与 V1 不矛盾**：
> - **R1** 管 **PnL 公式**（只一套，全系统共享）
> - **V1** 管 **判决依据**（不许掺"搜索期的奖励项"，如 `turnover_quality` 加分）

### 建 `backtest/audit.py`

```python
"""独立审计（承 V1）：**目标独立**（判决只认 PnL + 硬规则），不掺搜索期奖励。

★ 注意（2026-10-06 更正）：
- **PnL 公式共享**（`import engine`）—— 这是 **R1**（全系统唯一公式），**不是**违反 V1。
  两个生产实现 = 两个真相，更糟。
- V1 的**独立**在于：① 判决**不 import** 任何评分/搜索模块；② 独立证据来自**带外测试**
  （手算期望值 + 污染未来，见 tests/）。**不是**"再写一份 PnL"。
"""
from __future__ import annotations

import config
import engine
import metrics
import validate


def audit(pos: list[float], tgt: list[float], times: list[int],
          *, label: str = "strategy") -> dict:
    """对一个策略做完整审计，返回报告 dict（不落盘数据，只出结论）。"""
    n = len(pos)
    if len(tgt) != n or len(times) != n:
        raise ValueError("pos / tgt / times 长度必须一致")

    ppy = metrics.periods_per_year(times)

    # ① 基准成本
    pnl = engine.pnl_series(pos, tgt, config.COST_RATE)

    # ② 成本压力 2x（承 V4）
    pnl2x = engine.pnl_series(pos, tgt, config.COST_RATE * 2.0)

    # ③ 前后半段（承 V3）
    half = n // 2
    h1_ann = metrics.annual_return(pnl[:half], ppy)
    h2_ann = metrics.annual_return(pnl[half:], ppy)

    # ④ 分段一致性（承 V2；固定策略无训练 → 不是真 WF，见 validate 注释）
    wf_pos = wf_tot = 0
    for f in validate.segment_consistency_folds(n):
        vs, ve = f["val"]
        seg = pnl[vs:ve]
        if seg:
            wf_tot += 1
            if metrics.annual_return(seg, ppy) > 0:
                wf_pos += 1

    # ⑤ 指标
    ann = metrics.annual_return(pnl, ppy)
    sharpe = metrics.sharpe(pnl, ppy)
    sortino = metrics.sortino(pnl, ppy)
    mdd = metrics.max_drawdown(pnl)
    long_r, short_r = metrics.side_ratio(pos)
    max_side = max(long_r, short_r)
    trades = metrics.n_trades(pos)

    # ⑥ 判决（承 V3）
    verdict, issues = validate.judge(
        ann_ret=ann, sharpe=sharpe, mdd=mdd, max_side=max_side,
        h1_ann=h1_ann, h2_ann=h2_ann,
        wf_positive=wf_pos, wf_total=wf_tot,
        cost2x_profitable=metrics.annual_return(pnl2x, ppy) > 0,
    )

    # ⑦ 交易数门槛（承 V6）
    min_trades = max(5, int(n * config.MIN_TRADES_PER_100_BARS))
    if trades < min_trades:
        if validate._ORDER["SUSPICIOUS"] > validate._ORDER[verdict]:
            verdict = "SUSPICIOUS"
        issues.append(f"交易 {trades} 笔 < 门槛 {min_trades}（承 V6）")

    return {
        "label": label, "n_bars": n, "ppy": ppy,
        "ann_ret": ann, "sharpe": sharpe, "sortino": sortino, "mdd": mdd,
        "long_ratio": long_r, "short_ratio": short_r, "max_side": max_side,
        "n_trades": trades,
        "h1_ann": h1_ann, "h2_ann": h2_ann,
        "wf_positive": wf_pos, "wf_total": wf_tot,
        "cost2x_ann": metrics.annual_return(pnl2x, ppy),
        "verdict": verdict, "issues": issues,
    }


def format_report(r: dict) -> str:
    """报告 → 文本（回测层唯一的"产出"，是结论不是数据）。"""
    L = [
        f"══ 审计报告：{r['label']} ══",
        f"  bar 数        : {r['n_bars']}   每年 bar 数: {r['ppy']}",
        f"  年化          : {r['ann_ret']*100:+.2f}%",
        f"  Sharpe        : {r['sharpe']:+.3f}",
        f"  Sortino       : {r['sortino']:+.3f}",
        f"  MDD           : {r['mdd']*100:.2f}%",
        f"  多/空占比     : {r['long_ratio']*100:.1f}% / {r['short_ratio']*100:.1f}%"
        f"  (max_side {r['max_side']*100:.1f}%)",
        f"  交易笔数      : {r['n_trades']}",
        f"  前后半段年化  : H1 {r['h1_ann']*100:+.2f}%  H2 {r['h2_ann']*100:+.2f}%",
        f"  分段为正      : {r['wf_positive']}/{r['wf_total']} 段",
        f"  2x 成本年化   : {r['cost2x_ann']*100:+.2f}%",
        f"  判定          : {r['verdict']}",
    ]
    for i in r["issues"]:
        L.append(f"    ! {i}")
    if not r["issues"]:
        L.append("    （全部检查通过）")
    return "\n".join(L)
```

> 动量信号在它上面必赚。**这不是策略好，是数据太好。**
> 所以：**合成数据只用来验证"代码对不对"，绝不用来判断"策略行不行"**。

## 8. 步骤 8：防泄漏测试（V7 / V9）

### 目标

写两个测试 —— **这是"回测可信"的最后一道闸**。

### 建 `backtest/tests/test_causality.py`

```python
"""污染未来测试（承 V9）：把 t 之后换成垃圾，t 时刻的结论必须逐位不变。

这是"因果性"的终极检验 —— 比"追加未来数据看变不变"更彻底。
承 V9：任何偷看未来的实现，输出必然改变。
"""
from __future__ import annotations

import random
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent))

import engine  # noqa: E402


def causal_signal(closes: list[float], w: int = 5) -> list[float]:
    """示例因果信号：t 时刻只用 <= t 的数据（过去 w 根动量）。"""
    out = [0.0] * len(closes)
    for t in range(w, len(closes)):
        out[t] = (closes[t] / closes[t - w] - 1.0) * 20.0
    return out


def positions_of(closes: list[float]) -> list[float]:
    return engine.positions(causal_signal(closes))


def test_no_future_dependence(n_checks: int = 8, seed: int = 7) -> bool:
    """把 t 之后的收盘价换成随机垃圾 → 仓位序列 [0..t] 必须逐位不变。"""
    rng = random.Random(seed)
    n = 400
    closes = [100.0 + 3.0 * ((i * 37) % 11) / 11.0 for i in range(n)]

    base = positions_of(closes)
    ok = True

    checked = 0
    for t in range(50, n - 50, max(1, (n - 100) // n_checks)):
        checked += 1
        polluted = closes[:t + 1] + [rng.uniform(20.0, 500.0) for _ in range(n - t - 1)]
        after = positions_of(polluted)
        if after[:t + 1] != base[:t + 1]:
            ok = False
            for i in range(t + 1):
                if after[i] != base[i]:
                    print(f"  [FAIL] t={t}: 位置 {i} 变了 {base[i]} -> {after[i]}")
                    break

    print(f"{'[PASS]' if ok else '[FAIL]'} test_no_future_dependence "
          f"({checked} 个时点)")
    return ok


def test_signal_is_causal() -> bool:
    """信号本身：只依赖 <= t 的数据。"""
    closes = [100.0 + i for i in range(50)]
    sig = causal_signal(closes, w=5)
    ok = all(sig[t] == 0.0 for t in range(5))
    print(f"{'[PASS]' if ok else '[FAIL]'} test_signal_is_causal（前 5 根为 0）")
    return ok


if __name__ == "__main__":
    res = [test_no_future_dependence(), test_signal_is_causal()]
    print("-" * 50)
    print(f"  {sum(res)}/{len(res)} 通过")
    raise SystemExit(0 if all(res) else 1)
```

## 9. 步骤 9：端到端（`run_backtest.py`）

### 目标

### 建 `backtest/run_backtest.py`

```python
"""端到端入口：从 provide 拿数据 → 审计 → 出报告。

回测层**不落盘任何数据** —— 只打印报告（结论）。
"""
from __future__ import annotations

import argparse
import sys

import audit
import engine
import label
import source


def momentum_signal(closes: list[float], w: int = 5) -> list[float]:
    """示例信号：过去 w 根动量（因果）。**换成你自己的策略即可**。"""
    out = [0.0] * len(closes)
    for t in range(w, len(closes)):
        if closes[t - w] > 0:
            out[t] = (closes[t] / closes[t - w] - 1.0) * 20.0
    return out


def main(argv: list[str] | None = None) -> int:
    ap = argparse.ArgumentParser(description="回测与验证（端到端）")
    ap.add_argument("--symbols", nargs="+", required=True, help="如 SPY QQQ")
    ap.add_argument("--item", default="kline")
    args = ap.parse_args(argv)

    # ① 拿数据（唯一入口）
    panel = source.align_panel(args.symbols, item=args.item)
    if panel["strategy"] != "intersection":
        # 降级 = 有捏造 bar → **硬停**，不喂假数据（承 D1/P6）
        print(f"[拒绝] 对齐降级为 {panel['strategy']}（交集不足）—— 不喂捏造 bar",
              file=sys.stderr)
        return 2
    times = [int(t) for t in panel["index"]]
    opens_by = source.extract(panel, "open")
    closes_by = source.extract(panel, "close")

    # ② 逐标的审计
    reports = []
    for sym in args.symbols:
        if sym not in closes_by:
            print(f"[跳过] {sym}：面板里没有该标的", file=sys.stderr)
            continue
        opens, closes = opens_by[sym], closes_by[sym]
        sig = momentum_signal(closes)
        pos = engine.positions(sig)
        tgt = label.target_ret(opens)
        reports.append(audit.audit(pos, tgt, times, label=sym))

    if not reports:
        print("没有可审计的标的", file=sys.stderr)
        return 1

    # ③ 出报告
    print()
    for r in reports:
        print(audit.format_report(r))
        print()

    # ④ 汇总
    n_invalid = sum(1 for r in reports if r["verdict"] == "INVALID")
    n_susp = sum(1 for r in reports if r["verdict"] == "SUSPICIOUS")
    print(f"══ 汇总：{len(reports)} 个标的  "
          f"INVALID {n_invalid}  SUSPICIOUS {n_susp}  "
          f"VALID {len(reports) - n_invalid - n_susp} ══")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```
