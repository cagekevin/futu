# 债务账本 · 主表（只留待办）

> **写入者唯一 = `python scripts/debt.py`**（禁手写表格行、禁"改状态再追一行"）。
> 读法：`list`（默认待办）· `list --all` / `area <NN>` / `search <关键词>` / `show <TD-ID>`（**均已打通归档**）。
> 已完成项由 `archive` 移入 [`债务-归档.md`](./债务-归档.md)；主表只留待办。
> 明细真源 = 各区域日志（`daily/架构日志/<NN>-<区域>-<日期>.md`）的「探债」段 —— **账本只存一行摘要，不存叙述**。

## 字段口径

| 列 | 取值 | 说明 |
| --- | --- | --- |
| **TD-ID** | `TD-<区号>-<序号>` | 区号两位；序号**区内递增、永久固定**（不回收）。 |
| **区域** | 区域名 | 取该区既有写法（`add` 自动沿用）。 |
| **现象摘要** | ≤120 字 · **禁裸竖线 `|`**（用「／」） | 一行一债；长叙述写区域日志。 |
| **归类** | `还债` / `持平` / `增债` | 白名单（`add` 硬校验）。 |
| **利息率** | `高` / `中` / `低` | 白名单。 |
| **状态** | `待还` / `待用户拍板` / `已解决` / `已裁定非债` / `已裁定` / `待翻新` / `已退役` / `不做` | 写入口校验。 |
| **锚点** | `<NN>-<区域>-<日期>.md` | **只准区域日志文件名**（无路径分隔符、文件须存在）。 |

> 读债前先过 [`docs/adr/README.md`](../../docs/adr/README.md) 索引 —— 哪些既有约定已被**推翻**（铁律 6）。
