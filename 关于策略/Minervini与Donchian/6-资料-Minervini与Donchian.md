## 1. Minervini：规则原文（二手整理）

### 1.1 趋势模板（8 条，**必须全部或绝大部分满足**）

| # | 条件 | 作用 |
|---|---|---|
| 1 | 当前价格高于 **150 日**和 **200 日**均线 | 中长期不处于明显下行 |
| 2 | **150 日均线 > 200 日均线** | 长期趋势转强 |
| 3 | **200 日均线至少上行 1 个月** | 过滤刚从下跌中反抽的股票 |
| 4 | **50 日均线 > 150 日、> 200 日均线** | 短中期强于长期 |
| 5 | 当前价格高于 **50 日均线** | 价格仍在主趋势之上 |
| 6 | 当前价格 **≥ 52 周低点 × 1.30** | 过滤底部徘徊 |
| 7 | 当前价格 **≥ 52 周高点 × 0.75**（距高点 ≤25%） | 强势股接近新高 |
| 8 | **相对强度（RS）排名靠前**（常用 ≥70，即前 30%） | 跑赢大多数股票 |

> **注意**：这 8 条是**可计算的**——这就是它比缠论强的地方。**能写成代码，就能回测。**

### 1.2 止损（**硬性上限**）

- **单笔最大亏损 7–8%**，从**入场价**算。
- 目的之一是**消除盘中自我谈判**（8% → 悄悄移到 10% → 20%）。
- **但 7–8% 是上限，不是目标**：实际止损设在**底部结构低点稍下方**。
  - 若底部低点距 pivot 5% → 可接受；
  - 若距 pivot 12% → **放弃这笔**，等更紧凑的形态。

### 1.3 仓位（**公式**）

```
股数 = 风险预算 ÷ 止损距离
```

- 原文案例：风险预算 **$500**（= $50,000 账户 × **1%**）÷ 止损距离 $6.50 = **76 股**（向下取整）。
- ⚠️ **我搜到的"1.25%–2.5% 单笔风险"在原文里没出现**——那篇用的就是 **1%**。所以"1.25–2.5%"是坊间版本，不是原文。

### 1.4 加仓（金字塔，**只在盈利中加**）

| 批次 | 触发 | 规模 |
|---|---|---|
| 试探仓 | 放量 pivot 突破 | **50%** |
| 第一次加仓 | 守住 + 放量突破更高位 | **30%** |
| 最终加仓 | 新紧凑底部突破 | **20%** |

**四条原则**：
1. **在强势中加，不在弱势中加**（加仓价必须**高于**前次入场价）；
2. 每次加仓规模**小于**前次；
3. 止损随仓位上移；
4. **绝对禁止对亏损仓位加仓。**

### 1.5 大盘环境过滤（**四维度**）

指数趋势（50/200 均线）、派发日、新高/新低广度、**跟进日**（O'Neil 概念：主要指数放量涨 ≥1.5%）。

- 原文给出的胜率参考：**确认上涨趋势中约 50–60%；确认下跌趋势中降至 25–30%。**
- 环境不利时 → **主动降敞口、转现金**，而不是死守。

### 1.6 卖出规则 —— **⚠️ 原文没给完整规则**

- 只有"7–8% 硬止损"和"环境转坏就降敞口"；
- **"什么时候卖盈利的仓位"，我搜到的二手资料里没有完整规则。**

> **这一点很关键**：**他的方法里最赚钱的部分（让利润奔跑），恰恰是规则最模糊的部分。**
> 而"模糊"意味着：**你要自己补**——而自己补，就是过拟合。

## 2. VCP：定义与**可验证性**

### 2.1 定义（二手整理）

**核心**：一系列**幅度递减**的回调（收缩），配合**成交量枯竭**。

| 收缩 | 典型深度 | 成交量 | 结构要求 |
|---|---|---|---|
| C1 | **20–25%**（高波动可达 30–35%） | 先放量、后萎缩 | 确立基部最大深度 |
| C2 | **10–15%** | 较 C1 收缩 | **不得深于 C1** |
| C3 | **5–8%** | 明显平静 | **低点高于 C1、C2** |
| C-final | **3–5% 或更小** | **整个基部最低** | 形成于区间上沿 |

**必需条件**：
- **2–6 次收缩**；
- **每次回调幅度必须小于前一次**（否则 = 波动在扩张 → 形态失效）；
- **低点依次抬高**（higher lows）；
- **成交量枯竭**（末次收缩成交量 = 基部最低）；
- **基部形成时间 3–65 周**；
- 基部期间**不得跌破 50 日均线**。

**入场（pivot）**：最终收缩右侧的**最高点**；在 pivot **上方 5–10 美分**买入，**且必须成交量放大**（≥近期均量 40–50%）。

### 2.2 可验证性评估 —— **这是本节的重点**

| 部分 | 能不能回测 |
|---|---|
| **趋势模板 8 条** | ✅ **能**（全部是均线、价格、排名的数值条件） |
| **突破买点（pivot + 溢价）** | ✅ **能** |
| **止损（7–8% 或结构低点）** | ✅ **能** |
| **仓位公式** | ✅ **能** |
| **"收缩质量"（C1 是 25% 还是 22%？"紧凑"到什么程度？）** | ❌ **不能**——主观 |
| **"成交量枯竭"的阈值** | ⚠️ 半能（要自己定阈值 → 就变成过拟合的入口） |
| **"大盘环境"判断** | ⚠️ 半能 |
| **纪律（每天盯盘、无条件砍）** | ❌ **回测永远测不了** |

**结论**：
> **VCP 里"可回测的部分"是它的骨架（趋势模板 + 突破 + 止损 + 仓位）；
> "不可回测的部分"是它的灵魂（收缩质量的判断 + 纪律）。**
>
> **而收益来自灵魂，骨架只能保证你不死。**

### 2.3 最要紧的一条：**没有独立第三方验证**

- 我搜了学术与独立回测：**没有找到**对 SEPA / VCP 的独立验证研究；
- 找到的全部是**教学博客、指标销售页、社群内容**；
- **他的成绩（美国投资冠军赛）是真实可核验的**——但那是**他一个人的样本**。

> **所以准确的说法是：**
> **"有一个可核验的冠军 + 一套可编码的规则 + 零个独立验证。"**

## 3. Donchian：原始参数

### 3.1 四周规则（Donchian 原版）

- **周期**：**四周 = 20 个交易日**（他说"在所有市场上，四周都是极佳的周期"）；
- **买入**：价格突破**前 20 日最高点**；
- **卖出/做空**：价格跌破**前 20 日最低点**（期货市场反手）；
- **1960 年**他还公布过一套"**两周突破交易法**"。

### 3.2 海龟（Turtles，1983）——把 Donchian 规则化

| 项 | System 1 | System 2 |
|---|---|---|
| **入场** | **20 日**突破 | **55 日**突破 |
| **出场** | **10 日**反向突破 | **20 日**反向突破 |
| **止损** | **2N**（N = ATR20） | 同 |
| **加仓** | 每朝有利方向走 **0.5N** 加 1 unit，**最多 4 units** | 同 |
| **头寸** | **1 unit = 账户 × 1% ÷ N** | 同 |

### 3.3 一个关键的发现：**它和 Minervini 是同一个骨架**

| | Donchian / 海龟 | Minervini |
|---|---|---|
| 入场 | 20/55 日突破 | pivot 突破 |
| 止损 | **2N**（2 倍 ATR） | **7–8% 或结构低点** |
| **仓位公式** | **账户 × 1% ÷ N** | **风险预算 ÷ 止损距离** |
| 加仓 | 每 0.5N 加一次 | 50/30/20 |

> **两个"仓位公式"是同一个式子。**
> **差别只在"入场过滤"**：Minervini 多加了两层——**趋势模板 + 基本面加速**。
>
> **换句话说：他不是发明了新方法，他是在 Donchian 的骨架上，加了筛选条件。**

## 4. 可回测的伪代码

```python
# ============ 一、趋势模板（8 条全满足才算候选）============
def trend_template(px, ma50, ma150, ma200, ma200_1m_ago, hi52, lo52, rs_rank):
    return (
        px > ma150 and px > ma200            # 1
        and ma150 > ma200                     # 2
        and ma200 > ma200_1m_ago              # 3  200 日均线至少上行 1 个月
        and ma50 > ma150 and ma50 > ma200     # 4
        and px > ma50                         # 5
        and px >= lo52 * 1.30                 # 6
        and px >= hi52 * 0.75                 # 7
        and rs_rank >= 70                     # 8  相对强度前 30%
    )

# ============ 二、VCP（收缩 + 量枯竭）============
def vcp(contractions, vols, base_weeks, px, ma50):
    # contractions: 各次回调深度（正数，按时间顺序）
    if not (2 <= len(contractions) <= 6):        return False
    if not all(contractions[i+1] < contractions[i]
               for i in range(len(contractions)-1)):  return False   # 每次更浅
    if not (3 <= base_weeks <= 65):              return False
    if px < ma50:                                return False        # 不得破 50 日线
    if not vol_dryup(vols):                      return False        # 末次收缩量 = 基部最低
    return True

# ============ 三、入场 ============
pivot = max(high[最终收缩区间])          # 最终收缩右侧的最高点
if px > pivot + 0.05 and vol_today > 1.4 * vol_avg20:
    enter()                              # 放量突破才进

# ============ 四、止损（写死，不许改）============
stop = max(entry * 0.92,                 # 7-8% 上限
           last_contraction_low * 0.99)  # 或结构低点稍下方
if px < stop:
    exit_all()                           # 无条件

# ============ 五、仓位（写死）============
risk_budget = equity * 0.01              # 单笔风险 1%
shares      = floor(risk_budget / (entry - stop))

# ============ 六、加仓（只在盈利中）============
# 50% / 30% / 20%；加仓价必须 > 上次入场价；止损上移；禁止向下加仓

# ============ 七、退出 ============
# ⚠️ 原文未给完整规则 → 必须自己补 → 而"自己补"就是过拟合的入口

# ============ 八、大盘过滤 ============
# 指数 > 50/200 均线；无派发日；新高 > 新低；出现跟进日
# 不满足 → 降敞口 / 转现金
```

## 5. 成本与收益分布（$6,000，$2/笔）

> 脚本：`关于策略/工具/成本模拟.py`，20,000 条蒙特卡洛路径，单笔风险 1% of 账户。

### 5.1 成本表（确定性）

| 年笔数 | 每周 | 年成本 | 占本金 |
|---|---|---|---|
| 30 | 0.6 | $60 | **1.0%** |
| 60 | 1.2 | $120 | **2.0%** |
| **90** | **1.7** | **$180** | **3.0%** |
| 150 | 2.9 | $300 | 5.0% |
| 300 | 5.8 | $600 | **10.0%** |
| 990 | 19.0 | $1,980 | **33.0%** |
| 3,000 | 57.7 | $6,000 | **100%（一年亏光）** |

**读法**：$2/笔看着小，但 **990 笔/年 = 33%**——正是他上次的水平。
**反过来算**：**如果他上次真的花了 33%，那是每周 19 笔。** 如果没那么多，**说明那笔钱不全是佣金，是点差 / 隔夜 / 杠杆融资。**

### 5.2 收益分布（关键结果）

一年 90 笔，**结果完全由"胜率 p"和"平均赢 R"决定**：

| 假设 | 每笔期望 | 中位终值 | **亏损概率** |
|---|---|---|---|
| p=0.50, 赢=1.5R | +0.25R | $7,260 | 5.6% |
| **p=0.45, 赢=2.0R** | **+0.35R** | **$8,026** | **2.8%** |
| p=0.45, 赢=1.5R | +0.12R | $6,545 | **25.9%** |
| p=0.40, 赢=3.0R | +0.60R | $9,870 | **0.2%** |
| **p=0.40, 赢=2.0R** | **+0.20R** | **$6,916** | **16.7%** |
| p=0.40, 赢=1.5R | **0.00R** | $5,780 | **62.8%** |
| p=0.35, 赢=2.0R | +0.05R | $5,957 | **50.4%** |
| p=0.30, 赢=3.0R | +0.20R | $6,879 | 21.1% |
| p=0.30, 赢=2.0R | **−0.10R** | $5,265 | **85.1%** |

**三个结论：**

1. **"正期望" ≠ "大概率赚钱"。**
   `p=0.35, R=2.0` 是**正期望**（+0.05R），但**亏损概率 50.4%**——**掷硬币**。

2. **盈亏平衡线**（每笔期望 = 0，需要 `p × R = (1−p) × 1`）：

   | 胜率 p | 需要平均赢 R > |
   |---|---|
   | 50% | 1.00 |
   | 45% | 1.22 |
   | 40% | **1.50** |
   | 35% | **1.86** |
   | 30% | 2.33 |

3. **临界值附近，结果几乎由运气决定**——**而这正是你无法事前知道的地方。**

### 5.3 成本吃掉多少？（有成本 vs 零成本，同样假设）

| 年笔数 | 中位终值（零成本） | 中位终值（$2/笔） | 成本吃掉 |
|---|---|---|---|
| 60 | $8,494 | $8,350 | 2.4% |
| **90** | **$10,106** | **$9,870** | **3.9%** |
| 150 | $14,307 | $13,827 | 8.0% |
| **300** | **$34,116** | **$32,497** | **27.0%** |

> **结论**：**低频（≤90 笔）时，$2/笔不是杀手；高频（≥300 笔）时，它吃掉四分之一到三分之一。**
> **所以"次数上限"锁住的，不是"$2"，是"$2 乘以你的手"。**

### 5.4 一个"现实检查"（这段最有用）

用**二手站点给的那组参数**（p=0.40，平均赢 3R）算：

- 每笔期望 = 0.40 × 3% − 0.60 × 1% = **+0.6%（占账户）**
- 一年 90 笔：`1.006^90 = 1.71` → **一年 +71%**
- 十年：`1.71^10 ≈ 218 倍` → **$6,000 → 约 $130 万**

> **一个能十年翻 200 倍的参数组合，不会公开写在博客上。**
>
> **所以那组参数几乎肯定是"从赢的例子里挑出来的"。**
> **——这就是"样本外"和"扣成本"为什么必须做：不做，你会拿一个不可能的参数，去计划你的钱。**

## 6. 结论

1. **Minervini 的规则是真的、可数的、可回测的**——**比缠论强一个档次**。趋势模板 8 条、止损 7–8%、仓位公式、加仓规则，**都能写成代码**。

2. **但它的"灵魂"不可回测**：**收缩质量的判断 + 纪律**。**而收益来自灵魂。**

3. **没有任何独立第三方验证。** 有冠军、有规则、**零验证**。

4. **它和 Donchian / 海龟是同一个骨架**：突破入场 + 波动止损 + 风险固定仓位。
   **Minervini 的增量是"入场过滤"（趋势模板 + 基本面），不是新方法。**

5. **成本不是杀手，"频率"才是**：
   - 90 笔/年 → 成本 3% → 可接受；
   - 300 笔/年 → 成本 10%，且**吃掉 27% 的中位收益**；
   - 990 笔/年 → **33%**。

6. **收益分布完全由 p 和 R 决定，而这两个数是你猜的。**
   **在"看起来合理"的参数区间里，亏损概率从 0.2% 到 85%。**
   **——所以"这个策略行不行"，没法靠推演回答，只能靠样本外检验。**

7. **最要紧的一条**：
   > **这套东西里，"能学的部分"（规则）不产生优势；
   > "产生优势的部分"（纪律 + 收缩判断）学不会。**
   >
   > **而你已经知道这一条了——现在它有了数字。**
