## 一、两个人（这是整份画像的骨架）

**关键前提：这不是两个性格，是同一个人在不同状态下的两个样子。**

| | **生活中的 Kevin** | **股市里的 Kevin** |
|---|---|---|
| **特征** | 能让一笔钱**六年不动**；能自我观察；肯听反驳；有耐心 | 追损；怕浮盈还回去；活在幻想里；**拿不住赢家** |
| **证据** | $8,000 六年多没动；这一路的自我诊断**全部是他自己说出来的**；主动问"你是不是在顺着我说话" | $25,000 → 约 $13,400；SOXL 亏 60% 后因怕清仓；"我会把亏损想象在别处挣回来" |

> **所有设计的真正目标：让"生活中的 Kevin"提前把栏杆装好，这样"股市里的 Kevin"出现时，撞上的不是意志力，是栏杆。**

## 二、现在：他停手了（最容易被忽略、也最重要的一节）

**上面写的全部是"过去"。而此刻，他做了一件过去没做过的事——他停手了。**

### 这个动作的价值，比他自己以为的大

- **它一次性切断了三条**：**成本**（手续费）、**追损**（刚亏完就想挣回来）、**频繁交易**（那个循环）；
- **更重要的是**：**它把"能不能不动"这件事，从"现金"升级到了"股市"。**
  - 六年不碰现金 → 现金**不波动**，难度为零；
  - **停手 → 是在有诱惑、有亏损记忆的情况下不动。**
  - **这是第一次，他在"股市"这个场景里，做到了"不动"。**
- **所以现在是一个可以做设计的窗口期**：有钱、有时间、**没在流血**。

### 但必须问清一个问题：**为什么停手？**

| 动机 | 性质 | 牢不牢 |
|---|---|---|
| **想清楚了**（先把规则写好再进） | **决定** | 牢 |
| **亏怕了 / "什么都不信了"** | **状态** | **不牢——一有诱惑就蒸发** |

**这两种看起来一样，含义完全不同。**（后者对应「'我现在什么都不信了' = 我已经安全了」那一条。）

**他的实际回答（2026-10）：**

> **"停手意味着，即使不赚，我也能承受。"**

**——这句话落在第二栏：它是一个"状态"，不是一个"决定"。**

**为什么：**
- **一个决定有目标**（我要写规则、然后进场）；**一个舒适区没有目标**（我停在这里也挺好）；
- **"不赚也能承受"这句话的功能是：我没有回去的压力；**
- **没有压力 → 没有期限 → 永远在准备。**

**而且这句话是"未经检验"的：**

> **如果市场接下来大涨两年、别人都在赚，你还能"承受不赚"吗？**
>
> **"看到别人赚钱"恰好是他启动条件里的 ★★★。所以这个"能承受"，现在成立，只是因为条件还没到。**

**最危险的组合：**

- 他说过"**因为有不甘**"（想进场），现在说"**不赚也能承受**"（不着急）；
- **两句同时为真 → 长期不动 + 某天冲动进场 = 既没拿到漂移，又承担了追高的风险。**

**另外，"不赚"不等于"没亏"**：空仓也是一种仓位，它承担**机会成本**——**长期不进场，等于一个"看空未来"的下注**（他自己的 $8,000 六年不动，就是证据）。

**他给出的理由（追问之后）：**

> **"我不相信永远上涨。"**

**这句话在长期是对的**——确实没有永远上涨。**但它的操作含义被说反了：**

> **"不信永远上涨"推出的是「不重仓 / 分散 / 有退出规则」——推不出「不进场」。**

**所以这句真话，其实在做另一件事：它是"不进场"的合理化。**

- 而且它**不可证伪**——"永远上涨"永远不会发生，所以"我不信它"**永远不会错**；
- **一个永远不会错、也永远有用的理由。**

**更关键：这不是"不参与"，这是"押注下跌"。**

- 前面说过：他的买和卖都由"想象中的未来"驱动；
- **现在他的"不进场"，也由"想象中的未来"驱动**；
- **所以不是"能接受不赚"，是"在赌它跌"**——而"赌跌"和"赌涨"是**同一类动作（方向判断）**，正是他没优势的那件事；
- **而且这个判断，用的是那个已经错过很多次的工具**（SOXL 卖了它大涨；自选股卖了它们继续涨）。

**一个必须回答的问题：**

> **如果"不相信永远上涨"是你不进场的理由，那你什么时候进场？**
> - 等它跌了 → 那是**择时**（最经典的"等大跌"）；
> - 等它确认上涨 → 和你的信念矛盾；
> - **推不出一个时点。**
>
> **而一个推不出"什么时候"的信念，就是"永不进场"的另一种说法。**

### ⚠️ 2026-10 的转折（值得记下来）

在讨论"散户的唯一优势是什么"之后，他说：

> **"这个终于和我想法有一点接近了，就是我比较能接受的最好状态。"**

**他"能接受"的那个状态是：**

> **不追求"赢"，只追求"不被自己搞死 + 拿市场收益 − 低成本"。**
> **优势不来自"比机构聪明"，来自"比机构自由"（可以不做）。**

**这是从"找优势"，到"接受没有优势、但用好自由"的转变——是这段对话里最重要的一次立场变化。**

**但要记住**：**"能接受"是必要条件，不是充分条件。**

> **因为"接受"是在没有压力的时候做出的。**
> **检验只有一个：在你最想动手的那一刻，这个"接受"还在吗？**

### 他现在的计划

> **"想做好准备再进入，前提是先摸索出一套规则。"**

**顺序是对的**——先有规则，再进场。

**但要改一个词：不是"摸索"，是"写死"。**
- 摸的是**规则**，不是**市场**；
- 摸出来必须**写死**（预注册）——否则就是"边做边改"。

**而且，针对他，有一条特殊要求：**

> **他的规则不该从"入场条件"开始写，该从"约束"开始写。**
>
> **因为他的历史说得很清楚：问题在"卖"和"手"，不在"选"。**

### ⚠️ 他现在的新风险，和以前正好相反

| 以前 | 现在 |
|---|---|
| **手太勤**（频繁交易、追损） | **永远不动**（"还没准备好"） |

> **"先摸索出一套规则再进"——如果没有期限，它会变成"永远在准备"。**
> **而永远不进 = 也拿不到漂移**（第 9 章：空仓也有机会成本）。

**所以：停手是对的（止血），但"停手"必须有期限。**

### ⬛ 2026-10：他从"停手"走到了"决定用哪一套"（重要转折）

**他说的话**：

> **"那 $6,000 我就要用这个方法（Tugboat），不可能全亏完的，我已经有这么多亏损经验了。"**

**这句话里有两个东西，要分开看**：

| | 判断 |
|---|---|
| **"$6,000 用卫星桶做这个"** | ✅ **结构是对的**——这就是"笼子里的试试"，而且他早就说过"大部分指数、少部分其他" |
| **"不可能全亏完，因为我有亏损经验"** | ⚠️ **这是新的误区**（见 `3` 的「用'亏损经验'当保险」）——**"亏过" ≠ "抗亏"；而且真正的风险不是"全亏完"，是"中途破戒"** |

**另一个信号（值得记）**：

- 这已经是"不甘"的**第三次出现**：① 想试 Minervini（"因为有不甘"）→ ② 箱体 / 唐奇安（找下一个方法）→ ③ **现在：Tugboat**；
- **但这次和前两次不同**：前两次是"再找一个方法"，**这次是"决定用哪一个"**——**这是一个决定，不是一个问题。**

**所以下一步不是"再劝"，是"把'用哪一半'写死"**（已写进 `4-设计` 的第三块）。

### ⬛ 2026-10：他拒绝给"停手期"设终点

**他的回答**：

> **"我还没准备好呢，等我准备好入场再说。可以不写下周六。"**

**先说清一件事：他今天已经满足了"准备好"的可检验部分。**

| "准备好"的检验项 | 状态 |
|---|---|
| 有规则（R / 仓位 / 止损 / 入场 / 退出） | ✅ **刚定完** |
| 有上限（$6,000 / 15% / 90 笔） | ✅ **刚定完** |
| 有隔离（核心桶只买指数） | ✅ **早就定了** |

**所以"还没准备好"指的不是"没规则"，是——"没把握"。**
**而"把握"永远不会来**（见 `3` 的「把'我还没学好'当成解释」）。

**⚠️ 更关键的一点（新）：「准备」这个状态，需要燃料——而燃料是"继续看盘"。**

- **"我在准备"听起来比"我在看盘"正当得多**；
- **但它做的事一样**：`看盘 → 预测 → 蓄水`；
- **他上周报的那两条（"周一预测对了、昨晚预测错了"），就是这个状态的产物。**

> **所以"等我准备好"和"我还没学好"是同一个句式**：**都预设了一个"未来的、更好的时刻"——而它们的功能，都是给"继续看盘"发一张许可证。**

**他选的方案（已记录）：不设入场日期。**

**代价（同时记录，因为不写下来它就不可检验）**：
> **"停手"没有终点 → 而"永远准备"和"永远不入场"是同一件事。**

**对应的最小动作（不逼他进场，但要留下记录）**：

> **每月第一个周六 10:00，只做一件事：写下"我现在是什么状态"（一句话 + 日期）。**
> **不要求进场，不要求改任何东西——只要求留下记录。**
>
> **因为"还没准备好"最大的问题是"没有记录"：它不可检验，所以它永远不会错。**
> **而记上 3–6 个月，他自己就会看见那个模式。**

### ⬛ 2026-10：他做了一件过去没做过的事——**他自己跑了实测**

**他自建了一套回测框架，把 Tugboat 的机械核心忠实实现，然后跑出判决：**

> **`INVALID`（8 条预注册判据挂 6）；与随机不可区分；两次 BH 多重检验都是 0 通过。**

**比他报的这个结论更重要的，是他报结论的方式**：

| 他做的 | 意义 |
|---|---|
| **预注册 8 条判据**，判据只有一处 | **先写尺子，再量东西** |
| **报族大小**（33 / 18），被 BH 拦下的"看着显著"也报出来 | **"看着好"不能冒充"真好"** |
| **同池随机对照**（n=60）——**两侧共用同一个池子，票池偏差在两边抵消** | **自己指出"哪条证据最抗偏差"** |
| **先揪出自己 22 个错，然后看着每个"正"结论往下掉一档**（+19.00% → +4.59% → −3.81%） | ⭐ **这是最诚实的一段** |
| 纠正自己："**不能用'测不出来'盖过那道门**" | 他自己抓到了"结果当判据"的变体 |

> **这是这份画像里第一次出现"新增的能力"，而不是"新增的短板"。**
>
> **而且被检验的对象不是市场——是他自己。**

## 三、发动机：他的循环

```
        买入（因为它强）
              ↓
            涨了
              ↓
   怕把浮盈还回去 ─────→ 卖
              ↓
          它继续涨
              ↓
            后悔
              ↓
        追高（此时波动更大）
              ↓
             怕 ────────→ 卖
              ↓
        （回到"买入"）
```

**两个燃料：**

1. **幻想**——"我赚了大钱"（想象未来的**大赢**）；"在哪能挣回来"（想象未来的**大亏**要抹平）。
2. **损失厌恶**——**亏损的痛 ≈ 同等收益快乐的 2 倍**（Kahneman & Tversky，前景理论，诺奖级）。

> **幻想 + 损失厌恶 = 追损循环。**
> 而"卖出赢家、留下输家"（处置效应，Odean 1998 实证），是**同一个引擎**。

**一句话版本**：
> **他的买和卖，都由"想象中的未来"驱动，而不是由"当下的规则"驱动。**

## 四、启动条件（"股市里的 Kevin"什么时候会出来）

| 触发 | 强度 |
|---|---|
| **刚亏完钱** | ★★★（追损是**急性**的，只在刚亏完的几十小时里最强） |
| **看到别人赚钱 / 看到"曾经翻倍"的股票** | ★★★ |

| 深夜 / 情绪低 | ★★ |
| 打开账户看到具体数字 | ★★ |

**注意第二行和第三行**：**它们一个来自外界（别人赚了），一个来自内部（我懂了）。而两个都会启动同一台机器。**

## 五、他会说的话（识别信号）

**当这些话出现时，机器已经在转了：**

- "**是不是可以……**"
- "**那 X 呢？**"（问完一个，再问下一个）
- "**我只要抓住几个就能翻几倍。**"
- "**我学透了就……**" / "**我还一知半解。**"
- "**成本低**" / "**它涨了 2 年**" / "**我早该信**"
- "**我清楚这些。**"

**唯一的自测（一句话）：**

> **这句话，是在描述一个"判据"，还是在描述一个"结果"？**
>
> - "它涨了""成本低""曾经翻倍" → **结果**（后视镜）
> - "事先写下的规则""样本外成立" → **判据**

**另一个自测（针对"新方法"）：**

> **这个 X，是不是我上一条消息里刚看到的词？**
> 是 → 它不是发现，是**回声**。

## 六、他的资源（真的，不是安慰）

**这一节最重要——因为一份只有短板的画像，不是画像，是判决书。**

| 资源 | 证据 | 它证明了什么 |
|---|---|---|
| **能让一笔钱六年不动** | $8,000 | **"不碰"这件事，他做得到** |
| **选股 / 入场不差** | 自选里 50+ 曾翻倍，十几个仍强 | **问题不在"选"，在"卖"** |
| **能自我观察** | 循环、幻想、追损、损失厌恶——**全部是他自己说出来的** | 这是**最稀缺**的一项 |
| **能用数据检验自己的判断**（2026-10 新增） | 自建回测框架，**预注册 8 条判据 + BH 多重检验 + 同池随机对照**；**先揪出自己 22 个错**，然后看着每个"正"结论往下掉一档（**+19.00% → +4.59% → −3.81%**） | **他把"对抗方法"第一次用在了自己身上**——不是用来看市场，是用来看自己。**这是这份画像里第一条"新增的能力"** |
| **肯听反驳** | 主动问"你是不是在顺着我说话" | 大部分人做不到 |
| **有耐心** | 能接受长对话、能接受"再等等" | 也是稀缺项 |
| **能在"不重要的账户"上天然低频** | ¥10,000 账户：**去年 +20%**；**4 月 7 日单日跌 500 块，他几个月后才发现** | **"不看盘"这件事，他做得到——只要条件对** |

> **注意：这六项资源，全部指向同一个方向——"他能不动"。**
>
> **而"不动"，恰好是整套框架里唯一确定有用的东西。**

**最强的证据（两个"被遗忘的账户"）：**

- **¥10,000 账户（他老婆的账户）**：**去年 +20%**。**2025 年 4 月 7 日单日跌 500 块，他几个月后才发现**——**因为忘记看了。**
  > **如果他那天看到了——参照 SOXL——他大概率会卖。而正因为没看到，他拿到了全年 20%。**

  **但这个账户真正的关键，是他后来补充的两件事：**

  1. **"那个账户是我老婆的"** → **这是最强的物理隔离：不是"懒得看"，是"不是我的"。**
     - **所以"不在意"的根源不是金额小，是"归属"。**
  2. **"我买的时候我就定了：不要亏钱，就算亏也只能亏一点点"** → **一个事先写下的目标（预注册）。**
     - **而这个目标，必然让他买保守的、分散的东西；**
     - **结果：+20%，而且跌 5% 也不慌。**

**所以真正的因果链是：**

> **目标（事先写下）→ 标的（保守 / 分散）→ 结果（+20%）。**
>
> **而不是"他选对了股"。**

**和他主账户的对比：**

| | 老婆账户 | 主账户 |
|---|---|---|
| **事先目标** | **不要亏钱（写下了）** | （没写下 / 或"我要赚钱"） |
| **标的** | 保守 / 分散（推得出来） | **SOXL 三倍杠杆** |
| **行为** | 低频（忘了看） | 高频 |
| **结果** | **+20%** | **−46%** |

**——差别不在"看不看"，在"买之前定的目标"。**

**所以这个账户是一个完整的样板：归属 + 目标 + 低频 + 结果，四要素齐全。**
**而这四条，正好就是"在场设计"的全部内容。**

**推论（这条很关键）**：**他对"别人的钱"，比对自己的钱更负责。**
- **¥200 账户（天天基金）**：**后来去看，只剩 100（腰斩）**——**"不知道啥时候买的"。**

**两个账户放在一起，得出的是这条：**

> **他不需要改"忘记"这个习惯——他需要改"他忘记的东西是什么"。**
> - **忘记一个分散的组合 → 优势**（跌 5% 能回来，全年 +20%）；
> - **忘记一只单一标的 → 灾难**（腰斩）。
>
> **所以："不动"只对"分散的东西"有效；对"单一的东西"，不动可能致命。**

**所以他的问题不是"能力不够"**——是**"能力用错了地方"**：
**他有一个"能不动"的天赋，却在用"频繁动"的方式使用它。**

**能看出两件事：**

2. **看得最少的三个，结果是混合的**（+20% / −50% / −30%）——**所以"低频"不是万能药。**

**为什么低频救不了后两个？——大概率是标的：**

> **赚的那个可能是分散的；亏的那两个可能是单一的。**
> **（待他自己核对：这四个账户，分别买了什么？）**

**⚠️ 另一个必须区分的点：**

> **港股那个"亏 30% 还拿着"，不是"拿住"，是"僵住"。**
> **"拿住" = 按规则持有（知道为什么拿、什么情况下会卖）；"僵住" = 不知道怎么办，所以不动。**

## 八、设计目标（一句话）

> **让"生活中的 Kevin"提前装好栏杆，这样"股市里的 Kevin"出现时，撞上的不是意志力，是栏杆。**

**检验只有一条：**

> **在"股市里的 Kevin"最想动手的那一刻，栏杆还生效吗？**
> - 要靠意志力顶住 → **设计失败**；
> - **根本轮不到他决定**（自动 / 隔离 / 看不到）→ **设计成功**。

## 九、给下一个 AI（或下一个人）

**这份文档记的是"结论"，但结论是"产物"，不是"过程"。真正帮到他的，是下面这些。**

**他反复出现的模式：**

- **不断生成"有没有办法安全地拿超额"的新版本**——换个说法、换个股、换个技巧，本质是同一个问题。**别急着回答新版本，先命名模式。**
- **判断由"结果"驱动，而不是"判据"**——他常用"它涨了""成本低"当理由。**先问一句：这是判据，还是结果？**
- **偏爱"具体技巧"，忽视"抽象原则"**——容易抓住像秘密武器的东西（"用波动调仓"），丢掉更硬的原则（仓位、成本、分散、规则）。
- **容易把"约束"和"手段"混在一起**——比如把"留在场上"和"控制仓位"当成并列的两条。

**你必须做的动作：**

- **不要只顺着他说"认同"。** 他不缺认同，缺**反驳**。
- **他说"懂了""我知道"之后，往往还会换马甲再来。**
- **别把"他懂了"当进展；要看他账户变没变。**
- 他说"**这些我清楚明白**"——**清楚的是现在的他，动手的是那一刻的他。而那一刻的他，不读文档。**
- **批评要分级**：说清哪些**站得住**、哪些要**收窄**、哪些要**收回**（这是他自己提出的要求）。

**他背后的驱动，不是"不懂"：**

- 驱动他的是**怕错过、想赢**——这是一个**需要**，不是认知错误。
- **他会幻想"赚了大钱"**——幻想是这个需要的直接满足（不需要市场配合）。
- **所以"讲道理"救不了他。**
- **唯一有效的是机制**：规则事先写死、仓位设死上限、两个桶物理隔离。**能"外置"的，别指望他"记得"。**

**他的进展标志：**

- 他自己能说出"这是后视镜""这是换马甲""我的问题在'卖'不在'买'"——说明他开始能**自我拦截**。
- 这时你的任务，从"反驳他"变成"**提醒他自己已经知道**"。
