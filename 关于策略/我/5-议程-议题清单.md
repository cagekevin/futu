## 第一层：关于你（人）

### 你的行为史
- **要问什么**：你的钱，过去是怎么表现的？
- **为什么重要**：设计要按你的"尺码"做。
- **现状**：✅ 已清楚——**不动的钱在，动过的钱亏**（$25k → $13.4k），2025 年**卖低买高**。

### 你的真实短板
- **要问什么**：你最容易在哪里失败？
- **为什么重要**：机制要**针对短板**。
- **现状**：✅ 已清楚——**事中会动手**（恐慌早退、追高）。

### 你的真实优势
- **要问什么**：你有什么别人没有的？
- **为什么重要**：设计要**利用优势**。
- **现状**：✅ 已清楚——**时间**（10 年）、**情绪韧性**（扛过 1.5 年工资的亏）、**能守规则**（不加钱）。

### 你的"需要"
- **要问什么**：驱动你的是什么？
- **为什么重要**：**需要不会消失，只能被安置。**
- **现状**：✅ 已清楚——**怕错过、想回本**。

### "想回本"这个执念，怎么安放 ⬜
- **要问什么**：你想回本——这个愿望怎么处理？
- **为什么重要**：它会推你动手；**设计不掉它，但能安置。**
- **要决定什么**：怎么让"回本"**不需要你做任何动作**。
- **方向**（你刚给出）：**按 5%+ 的国债，10 年差不多回本**——
  **也就是说：回本靠的是"持有 + 时间"，不靠你的操作。**
  **所以设计的目标，是"不破坏这个回本"，而不是"操作出回本"。**
- **现状**：✅ **方向已明确**（回本靠"持有 + 时间"，不靠操作）。

### 你的真实风险承受力 ⬜
- **要问什么**：你能扛多大的回撤而不动手？
- **为什么重要**：它决定**仓位上限**。
- **要决定什么**：**无法事前定**——只能靠**一次真实下跌**验证。
- **现状**：⬜ 未验证。

### 这笔钱的目的
- **要问什么**：这笔钱最终干什么？
- **为什么重要**：目的决定**能承担的风险**。
- **现状**：✅ 已明确——**养老**；37 岁，**还有 20+ 年**。

### 集体行为 / 情绪
- **现状**：✅ 现象真实；可用的部分是**波动**，不是方向。

### 汇率敞口
- **要问什么**：资产在美元、生活人民币，怎么办？
- **现状**：✅ **已决定：暂不考虑**（还有其他存款）。

### 税务 / 跨境 ⬜
- **要问什么**：三笔钱在三个平台，怎么报税？哪个平台省？
- **为什么重要**：税务是**确定的负**（成本的一种）。
- **要决定什么**：是否需要调整平台 / 账户类型。
- **现状**：⬜ 未讨论。

### 各种"方法"有没有优势 ⬜
- **要问什么**：MACD / 背离 / 黄金分割 / 形态 / 动量 / 集体行为，到底有没有优势？
- **要决定什么**：用"**数**"去验证（见《4-设计-在场机制》待验证清单）。
- **现状**：⬜ 已列清单，**未验证**。

### 熊市 / 极端回撤怎么应对 ⬜
- **要问什么**：在牛市顶点入场、几十年不回本（日本 1990 / 纳斯达克 2000）——怎么设计？
- **为什么重要**：这是"永远在场"**最真实的代价**。
- **要决定什么**：要不要**机械减仓规则**；**宽分散 / 分批 / 再平衡 / 仓位**的具体参数。
- **已有候选**：**触发式规则**（跌 X% 加仓 / 估值极值减仓）——但有三条硬约束（弹药 / 锚 / 连续下跌），且与"满仓在场"矛盾。
- **现状**：⬜ **待讨论**（已在《4-设计-在场机制》2.7 立条目）。

## 第四层：关于执行与兜底 ⬜（**几乎没碰**）

### 验证怎么真的做
- **要问什么**：怎么真的跑回测 / 找资料 / 审查别人的验证？
- **为什么重要**：否则"待验证清单"永远**停在纸上**。
- **要决定什么**：数据从哪来、用什么工具、怎么算"过"。

### 验证仓位怎么定
- **要问什么**：拿多少去验证"我扛不扛得住"？
- **要决定什么**：**"痛，但不动"的量**——上限（腰斩睡不着 → 太大）/ 下限（跌 30% 没感觉 → 太小）；**第一次宁可小**。
- **现状**：✅ 判据已明确（**具体数字待定**）。

### 时间线
- **要问什么**：什么时候开始？多久复盘一次？
- **要决定什么**：**启动日、复盘频率**。

### 兜底：如果我还是动了手，怎么办
- **要问什么**：第一道防线被撞破之后，**第二道是什么**？
- **为什么重要**：**第一道防线一定会被撞**——没有兜底，设计就是纸的。
- **要决定什么**：动手之后，怎么"**拉回来**"。

### 极端情形
- **要问什么**：10 年内真要用钱 / 平台出问题 / 汇率剧变 / 市场十年不涨——怎么办？
- **要决定什么**：每种情形的**预案**。

### "设计本身失败"怎么识别
- **要问什么**：怎么知道这套设计不管用？
- **要决定什么**：失败的判据（**不是"亏了"，是"偏离规则"**）。

### 投资之外
- **要问什么**：现金流、生活、心理、信息源、社交——哪些会影响"在场"？
- **要决定什么**：要不要**切断某些信息源**（股评、视频、群）？
