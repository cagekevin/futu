## 四、现状（2026-10）

**已定：**

| 项 | 值 |
|---|---|
| 卫星桶上限 | **$6,000** |
| **R（每笔风险）** | **0.5% = $30** |
| **单笔仓位上限** | **15% = $900** |
| **单笔止损** | **1–1.5 × ADR，≤ 10%** |
| **入场方式** | **限价单（Pullback）——不用 HTF** |
| **止损执行** | **条件单** |
| 笔数上限 | **90 笔/年** |
| 看盘日 | **周六 10:00–10:30**（只看、只写，不动手） |
| 执行日 | **次日 / 开盘前**（按写下的结果执行） |
| 周一到周五 | **不看、不动**（用条件单代替） |
| 核心桶 | **只买指数**，其余不动 |
| **退出条件** | **三段式**：① 结构止损 → ② 到前高 / +2R 卖 1/3–1/2，并把止损上移到成本 → ③ 之后收盘破 20MA 全清 |
| **参数冻结期** | **第一个季度（≈ 22 笔）内，一个字都不改** |
| **停手线** | **−25%（$1,500）或连亏 15 笔** |
| 新钱 | **不加**（直到扛过一次真实下跌） |
| 当前状态 | **停手期**（未在场） |

**还没定：**

- **笔数上限要不要按实测重设**（实测：这套规则 **≈ 6.6 笔/年**，而笼子是 **90 笔/年 = 13 倍** → 建议改成 **≤ 12 笔/年**）；
- **停手期的期限**（一个日期）；
- **兜底**：如果还是动了手，第二道防线是什么。

**⚠️ 2026-10-09 实测的影响（必读）：**

> **Tugboat 的机械核心已实测 → `INVALID`（8 挂 6），与随机不可区分。**
>
> - **卫星桶"拿右尾"的目的基本被排除** → 只剩"**测你的手**"这一个目的；
> - **所以 R 可以更小**（目的是暴露行为，不是拿收益）；
> - **执行判据的分量，比策略判据更重。**
>
> 详见 `Tugboat/19-最终结论-2026-10-09.md`。

## 五、引用约定（**写 / 改本文档时必读**）

> **文档引用只写「`关于策略/<主题>/<文件名>`」——不写主题内部的物理层级。**
> **"哪个主题"是逻辑分区（稳定）；主题内部怎么嵌套，不进引用。**
>
