## 0. 一句话

**复权因子 = 每个除权日一条的"单日因子"**，用来把**不复权价**换算成**前复权 / 后复权价**。
数据层**存 raw + 因子**，复权换算由**唯一实现**做（**mode 显式、无默认**）。

---

## 1. 权威公式（官方文档，逐字）

> **前复权价格 = 不复权价格 × 前复权因子 A + 前复权因子 B**
> **后复权价格 = 不复权价格 × 后复权因子 A + 后复权因子 B**

- 来源：`openapi.futunn.com/futu-api-doc/quote/get-rehab.html`（v10.11）。
- 接口：`get_rehab(code)` → **每除权日一行**，字段 `forward_adj_factorA/B`、`backward_adj_factorA/B`。
- 技能里的 `futuapi/scripts/quote/get_rehab.py` 只是包装调用，**不含公式**；公式来自官方文档页。

### 1.1 对拍验证结果（2026-10-06，拿富途自己的复权 K线逐根比）

脚本：`tests/verify_adjustment_formula.py`（不落库）。做法：同标的、同区间，取
`autype=0`（raw）/`1`（前复权）/`2`（后复权），用库里因子套公式，与富途**逐根比**。

| 口径 | 公式 | 结果 |
|---|---|---|
| **前复权 qfq** | `qfq(t) = raw(t) × ∏_{d > t} forward_adj_factorA(d)` | ✅ **确认**：NFLX **逐根 0.000000%**；AAPL 0.017%（= 因子 5 位小数的量化噪声） |
| **后复权 hfq（仅拆股）** | `hfq(t) = raw(t) × ∏_{d ≤ t} backward_adj_factorA(d)` | ✅ **确认**：NFLX（只有拆股、无派现）**逐根一致** |
| **后复权 hfq（含派现）** | ？ | ❌ **未确认**：AAPL（有派现）差 ~3%，5 个候选公式都不对 |

- **边界必须严格**：前复权 `d > t`、后复权 `d ≤ t`。前复权用 `d >= t` → 差 **90%**（全错）。
- 因子 A/B **只存 5 位小数** → 有量化噪声（AAPL 那 0.017% 就是它，**印证 D11**）。
- 库里的因子与富途现拉**一致**（AAPL 都是 62 条，含 1987–1995 也无分红）→
  后复权的差**不是缺数据，是公式**。

## 2. 因子是"单日"的，不是"累计"的（实测确认）

用本机真实数据反推（`forward_adj_factorA = 1 − 每股派现 / 除权前收盘`）：

| 除权日 | per_cash_div | forward_A | 反推除权前收盘 | 当时 AAPL 实际 |
|---|---|---|---|---|
| 2015-05-07 | 0.52 | 0.99584 | ~125 | ~$125 ✓ |
| 2020-05-08 | 0.82 | 0.99730 | ~304 | ~$310 ✓ |
| 2026-05-11 | 0.27 | 0.99907 | ~290 | ~$290 ✓ |

⇒ **每个除权日一条，各管自己那一天**；**不是**从上市起的累计因子。

---

## 3. 拆股 / 派现，编码不同（实测确认）

| 事件类型 | `split_ratio` | 前复权 A / B | 后复权 A / B |
|---|---|---|---|
| **拆股**（4:1，2020-08-31） | 0.25 | **0.25 / 0** | **4.0 / 0** |
| **拆股**（7:1，2014-06-09） | 0.14286 | 0.14285 / 0 | 7.0 / 0 |
| **派现**（2026-05-11） | — | **0.99907 / 0** | **1.0 / 0.27** |
| **派现**（2015-05-07） | — | 0.99584 / 0 | 1.0 / 0.52 |

- **拆股**：前复权 `A = split_ratio`；后复权 `A = 1 / split_ratio`（**纯乘法**，B = 0）。
- **派现**：前复权 `A = 1 − 派现 / 除权前收盘`（乘法）；后复权 **A = 1、B = +派现**（**加法**）。

---

## 4. 口径分工：qfq 含未来，hfq 因果（承 D8）

- **前复权（qfq）**：t 时刻的价要用 **t 之后**才发生的除权（`∏_{d>t} A_f`）⇒ **含未来信息**，
  **只能用于展示，禁止用于回测**（D8 / D-H）。
- **后复权（hfq）**：只用 **≤ t** 的事件 ⇒ **严格因果**，**回测用它**。

⇒ 数据层**不替下游选口径**：提供因子 + 唯一实现，`mode` **必须显式**（`"hfq"` / `"qfq"`），**无默认**（承 P1）。

## 5. 仍待确认（**不猜**）

### 5.1 后复权：结构找到了，常数项没定

用 `F = hfq/raw` 反推富途的**每事件因子**（`tests/verify_adjustment_formula.py <SYMBOL>`）：

- **结构**：`hfq(t) = raw(t) × ∏_{d ≤ t} backward_A(d) + D(t)`，
  其中 **D 在除权日之间恒定、拆股日也不变**（实测：2020-08-28 与 08-31 的 D 都 = 1079.6）
  → D 是**加法**的分红累计项。
- **每事件因子** `f` ≈ `1/forward_A`（总收益口径），但**每个事件差 ~0.1%**，累积 → AAPL 差 ~3%。
- ❌ **D 的精确形式没定**：`ΣB` / 按后续拆股缩放 / 按全部拆股缩放 —— **都对不上**。

### 5.2 ⚠️ 富途自己的 hfq 不是严格总收益自洽的

拆股日（4:1，`backward_A = 4.0` **精确**）本该**连续**（TR 无跳变），但实测
`hfq(2020-08-31)/hfq(2020-08-28) = 1.032650`，而按 4× 应为 `1.033920` —— **差 0.12%**。
⇒ 富途的 `autype=2` 序列**不能当"金标准"**；它自身就有 ~0.1%/事件 的偏差。

### 5.3 结论

- **后复权暂不实现**（常数项 D 没定；且没有可靠基准可对拍）。
- **前复权可实现**（§1.1 已逐根确认），但目前**没有消费方**（回测要 hfq）。
- 验证手段：`tests/verify_adjustment_formula.py <SYMBOL>`（可换标的复现）。
- 因子 A/B 的**量化噪声**（5 位小数）要不要在实现里去噪 —— 待定（D11）。

## 6. 我们怎么做（数据层口径）

- **存 raw**：K线统一 `autype=0`（不复权）；**因子单独存**（数据项 `adjust_factor`，每除权日一条）。
- **唯一实现**：复权换算在数据层**只实现一次**（`engine`），下游**不自建**（承最高目标"数据只有一份"）。
- **mode 显式、无默认**：`hfq`（回测）/ `qfq`（展示），**不设默认口径**。
- **缺因子就报错**：算复权时若该标的因子不全 → **报错**，不静默当 1.0（承 P6）。
- 接口限制：`get_rehab` **每 30 秒最多 60 次**（官方文档）。
