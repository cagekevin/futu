# 富途 —— 代码格式 / 市场推断 / 校验

> **跨通道**（REST 与 OpenD 通用）。取数必需的平台规范。
> 来源：futu 技能 `futuapi/GUIDE.md`（代码格式、市场推断、校验）+ 本机实测补充。
> 总览见 `README.md`。

---

## 1. 代码格式（`市场.代码`）

| 市场 | 格式 | 示例 |
|---|---|---|
| 港股 | `HK.<5位数>` | `HK.00700`（腾讯）、`HK.09988`（阿里） |
| 美股 | `US.<TICKER>` | `US.AAPL`、`US.TSLA` |
| A 股-沪 | `SH.<6位>` | `SH.600519`（茅台） |
| A 股-深 | `SZ.<6位>` | `SZ.000001`（平安银行） |
| 日股 | `JP.<数字编号>` | `JP.7203`（丰田）、`JP.6758`（索尼） |
| 新加坡 | `SG.<代码>` | `SG.D05`（星展）、`SG.U11`（大华） |
| 马股 | `MY.<数字编号>` | `MY.1155`（MAYBANK） |
| 加密-币种/指数 | `CC.<币种>` | `CC.BTC`、`CC.ETH`、`CC.SOL` |
| 加密-币对 | `CC.<币对>`（**不带 `/`**） | `CC.BTCUSD`、`CC.BTCHKD` |
| SG 期货 | `SG.<主连>` | `SG.CNmain`（A50）、`SG.NKmain`（日经） |

**指数用双点**：`US..SPX`、`US..IXIC`、`US..SOX`、`US..DJI`
（⚠️ 形式对，但**美股指数 K线无权限** → `暂不支持美股指数`，见 `opend.md:3.8`）。

---

## 2. 市场自动推断（硬约束）

**从代码前缀推断市场**，**不需要手动指定 `--market`**。
若传入的 `--market` 与代码前缀不一致 → **以代码前缀为准**（并警告）。

---

## 3. 代码格式校验（硬约束）

代码**必须含 `.`**，前缀必须是：
`US` · `HK` · `SH` · `SZ` · `SG` · `MY` · `JP` · `CC` 之一。
格式不合法 → 直接报错退出。

> 与我们 `store/keys.py` 的关系：**库里存纯代码**（无前缀，如 `AAPL`）；
> **进 `fetch/` 时才加前缀**（`_code()` / `_strip()`）。承 plan X4：键里无源名/前缀。

---

## 4. 各市场能力差异（取数相关，实测/技能）

| 市场 | 正股行情 | 期权 | 备注 |
|---|---|---|---|
| **US** | ✅ | ✅ | 美股期权链可用（我们当前选的标的都在此） |
| **HK** | ✅ | ✅ | 经纪队列仅港（`get_broker_queue`） |
| **JP** | ✅ 正股 | ❌ | 期权链返回 `-1 期权标的仅支持港美正股ETF以及港指美指` |
| **SG** | ✅ 正股 | ❌ | `OptMarketCategory` 不含 SG |
| **MY** | ✅ 正股（需 LV1 权限） | ❌ | 经纪队列接口可调但**队列始终为空** |
| **CC（加密）** | ✅ 7×24 | ❌ | 需 `security_firm=FUTUSECURITIES/FUTUINC/FUTUSG` |

**选股（V2 `get_stock_screen`）**：US/HK/JP/SG/MY 均支持。

---

## 5. 与我们 `fetch/` 的对应

- `fetch/sources/futu/opend_source.py::_code` / `_strip`：纯代码 ↔ `US.xxx` 互转（**只在本模块内用**，承 F1）。
- 标的市场前缀暂以 **US** 为主（我们当前标的：AAPL/SPY/QQQ/IWM…）。
- 加新市场时：`_code` 要支持对应前缀；`store` 层**不变**（仍存纯代码）。
