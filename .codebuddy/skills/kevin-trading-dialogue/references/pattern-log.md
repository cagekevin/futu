# 模式日志（pattern-log）

> **这个文件让 skill 能长大。**
>
> **怎么用**：每次对话结束前，把「已知机制的新表现」和「AI 自己的错误」追加进来。
> **升级规则**：同一表现出现 **≥ 3 次** → 升级进 `SKILL.md`；连续 **6 个月**没出现 → 标记「可能已消失」。

---

## 一、机制清单（本质层 · 很少变）

> **6 个模式不是 6 个毛病——是同一个"需要"的出口。**
> **识别新模式只有一句：这个新表现，是哪个需要的出口？**

| 机制 | 是"需要"的哪种出口 |
|---|---|
| **M1 换马甲** | 需要找一个"还没试过的" |
| **M2 结果当判据** | 需要"我已经看懂了"的感觉 |
| **M3 工具替代理解** | 需要"这件事已经被解决了" |
| **M4 把"还没学好"当解释** | 需要把"没有优势"改写成"还没找到" |
| **M5 幻想** | 需要不需要成本的满足 |
| **M6 找许可** | 需要把"动手"合法化 |
| **M7 拿"经历"当"保证"** | 需要"我不用再受约束" |

**M7 的两个方向（同构）**：
- **"我还没学好"** → 推迟开始（用它换"不许动"）；
- **"我亏过很多 / 这个我做过"** → 解除限制（用它换"可以动"）。
- **共同点：拿一个不可检验的东西，替代"写死的规则"。**

## 三、AI 错误记录（最重要的一节）

> **不记录自己的错误，AI 会重复犯。**

| 日期 | 我错在哪 | 正确的做法 |
|---|---|---|
| 2026-10 | 把"$8,000 现金六年没动"当成"他能扛住波动"的证据 | **现金不波动，难度为零**。不碰现金 ≠ 不碰腰斩的仓位 |
| 2026-10 | 把"每天跑 scan / 记 RSI"归入"抄不来（全职强度）" | **它是机械劳动**；他做过。**分界线是"你在不在场"，不是"难不难"** |
| 2026-10 | 用"类比"代替查证（"箱体和 Minervini 是同一家族"），没去查原始规则 | **该去查就去查**；"像" ≠ "是" |
| 2026-10 | 用"不构成投资建议"当退路，少做了该做的工作 | 它**一半是边界，一半是退路** |
| 2026-10-09 | 把"金字塔加仓很可能输给买入持有"说成**结论**（**我没算**） | **判据可以给，结论不能给早。** 他当场指出"你直接把我这个想法否决了"。**待验证 ≠ 大概不行** |
