# 一、他的世界观（五条前提）

**——他的所有做法，都是从这五条推出来的。**

### 前提 ①：**我无法预测市场**

**这不是谦虚，是起点。** 他反复说：不知道涨跌，不猜顶不猜底。
> **"提前观察见顶不代表我们就是要预测最高点……市场的最高点只有事后才能够确认。"**

### 前提 ②：**我能控制的只有"暴露多少"**

**既然不能预测方向，那唯一能控制的就是"下多少注"。**
> **→ 所以他的整套体系，是围绕"曝险（exposure）"转的，不是围绕"预测"转的。**

### 前提 ③：**市场是分阶段的**

**筑底 / 上涨 / 筑顶 / 下跌（Stan Weinstein 四阶段）。**
**而且阶段不一定按固定顺序发生** → **所以筑底和筑顶常常分不清。**

### 前提 ④：**我的优势不在"知道得更多"，在"系统 + 纪律 + 自己的资料"**

> **"AI 不会帮你无中生有变出一套会赚钱的交易体系。AI 真正的价值，是把你已经有的优势放大。"**
> **"不是我用 AI 所以我能交易，而是我先会交易，AI 才能帮得上忙。"**

### 前提 ⑤：**真正保护你的，是"少犯错"，不是"多赚"**

> **"最好的进攻就是防守……跑赢大盘的其中一个重点，是比拼谁犯错少、或者在犯错的时候谁输得少。"**

# 二、由前提推出的做法

## 2.1 R —— 因为"不能预测方向"，所以"固定每笔风险"

**逻辑链**：

```
我无法预测这一笔会不会对
    ↓
所以我不能按"我觉得会涨"来下注
    ↓
我只能固定"这一笔最多亏多少"
    ↓
→ 这就是 R
```

### 为什么不用固定百分比止损（5% / 10%）？

**因为他发现：不同标的的波幅差太远。**

| 问题 | 说明 | 例子 |
|---|---|---|
| **对高波动股太窄** | **日均波幅就有 8.5–13%** → 10% 止损很容易被打中 | **OKLO**（核电股）；加密 altcoin |
| **对低波动股太宽** | 跌 **3–4% 就已经破坏形态**，但 10% 止损还没触发 | **可口可乐**、指数 ETF |

> **→ 一刀切的百分比，忽略了"不同标的波幅不同"。**

### 公式与取值

```
R = 每笔交易的风险 = 一般 = 本金的 1%
股数 = R ÷ (买入价 − 止损价)
```

**他的例子**：本金 **100 万**，R = **1 万**；Tesla 买 **290**、止损 **270** → 差 **20** → **500 股** → 仓位 **14.5 万** = **本金的 14.5%**。

| 项 | 规则 |
|---|---|
| **一般** | **1%** |
| **进取上限** | **不超过 2%**（2% × 连输 5 笔 = **−10%**） |
| **新手建议** | **0.5%–0.75% 起步**，再逐步调 |
| **R 的绝对值** | **不随本金变动**（100 万 → 105 万，R 仍是 1 万） |
| **调整频率** | **每季度 / 每年**一次 |
| **禁止** | **不要在疯狂牛市高位加大 R** |

**他引用的**：

> Soros 的门徒 Druckenmiller 回忆 Soros 的教导：**"投资的成败不在于对错频率，而在于正确的时候赚多少、错误的时候亏多少。"**

**R 的第二个作用：算"总曝险"**

- **5 笔持仓 = 5R 潜在损失**；
- 其中 2 笔止损移到**盈亏平衡** → 曝险降到 **3R**；
- 若这 2 笔一个 **+3R**、一个 **+1R** 离场 → **+4R 利润**；
- **→ 用这 4R 去开新仓（"用利润下注"）**。

## 2.2 曝险（Progressive Exposure）—— 因为"不能预测"，所以"用仓位代替预测"

**这是整个频道最核心的一块。他明说：Risk Management 占 7–8 成重要性，Situational Awareness 只是锦上添花。**

### 四阶段

| 阶段 | 市场状态 | 动作 | 为什么 |
|---|---|---|---|
| **① 疑似见底** | 情绪低落、超卖、**坏消息不再跌**（对坏消息迟钝、开始挑好消息） | **小注尝试**；**止损设窄**；**不成功就快速认错** | 因为**不知道是不是底**，所以只能**用小注去试** |
| **② 动能恢复、大众还在怀疑**（"这只是熊市反弹"） | 你的交易开始顺手 | **快速加仓，曝险快速上升** | 因为**"顺手"是市场给的反馈**，比你的判断可靠 |
| **③ 曝险到上限** | 还想加仓 | **开新仓同时关旧仓 / 部分获利**，止损移到盈亏平衡 | 因为**上限是事先定死的**，不能因为"感觉好"就突破 |
| **④ 过度延伸 / 亢奋** | 大家极度乐观、过度超买 | **压低曝险 + 节奏变快**（很窄的止损、**2–3 天部分获利**） | 因为**超买可以更超买**，所以**不完全清仓，但降低暴露** |

**降曝险的触发（最关键的信号）：**

> **策略集体失效**——突破失败、止损密集被打中（尤其移动止损、breakeven 密集触发）。
> **→ 果断降曝险，不犹豫。**

### 他给的实例（数字）

- 周五 **QQQ 跌 4.8%**（带量），从周三高点共跌 **5.82%**；
- 他个人：**周三 drawdown 2.49%**（触发他降曝险）→ **周五 +0.49%** → **整体从高点回撤 1.x%**（vs 大盘 5.x%）；
- 他的原话：**"我的曝险机制救了我一命。"**

### 他对"周五跌、周一怎样"的统计的态度（这段很值得学）

- 样本只有 **10–20 个** → **不充足**；
- 周一**涨跌参半，无显著性**；
- **更重要的是**：**"我们的交易不是只看下个星期一，还是看下个星期甚至下个月。"**

## 2.3 四阶段与节奏 —— 因为"市场分阶段"，所以"每个阶段做不同的事"

### Weinstein 四阶段（他的用法）

**关键点：**

1. **30 周线 = 150 日均线**：**股价在其上 = 第二阶段（上涨）；在其下 = 第四阶段（下跌）**；
2. **四阶段不一定按固定顺序**（也可能是：上涨→下跌→上涨→下跌→筑底→筑顶）；
3. **所以筑底和筑顶常常难以分辨**——**单看成交量也未必准**；
4. **四阶段也适用于较短的时间框架**（长期上升趋势里，也有上涨/横盘/下跌的小阶段）。

### 每个阶段他做什么（"懒散"是关键词）

| 阶段 | 他的做法 |
|---|---|
| **筑底 / 筑顶** | **最"懒散"**——**不主动开仓，仓位控制在固定曝险内**。理由：**没方向，做多做空失败率都高**。**以观察为主**（观察何时走出方向、哪些行业/个股强于大盘） |
| **下跌** | **不做多**；但**格外留意"潜在支撑在哪"**——因为**"强动能下跌后的反弹通常十分猛烈"** |
| **上涨** | **重点在"买入节奏"**（不是"买什么"） |

### 怎么改进节奏？—— **拿自己的交易记录去对照大盘**

**他的方法（很实用）：**

- **把自己的交易标注在大盘走势图上**（绿 = 盈利、红 = 亏损、数字 = 序号）；
- **例（2024 SPY 一段上升，3 个多月）**：共 **58 笔**，其中 **33 笔亏、25 笔盈**；
- **分成三块看：**

| 位置 | 现象 | 结论 |
|---|---|---|
| **最右（过度延伸）** | **红色明显增多**——胜率降低但**依旧频繁出手** | **最容易大幅回吐的地方** |
| **最左（刚突破 / 动能爆发）** | **交易次数明显不足** | **没有果断尝试、没迅速铺开** |
| 中间 | 正常 | —— |

- **另一个分析（2023 SPY）**：用直线代表交易（左端买入、右端卖出）→ **能看出某一天的总体仓位**；
  - **同样在右侧 over-extended 时曝险增加**；
  - **持仓最多的三天约 6–7 个仓位**；**持仓 7 个仓位那天附近，亏损显著增多**；
  - **中前段横盘**阶段亏损也增多（没有明显趋势）；
  - **最左（大盘刚启动）可以提早入场尝试**。

**结论：**

> **大盘好转、开始突破向上时 → 果断尝试下注，顺利就迅速增加曝险；**
> **大盘进入过度延伸、市场亢奋时 → 控制曝险，坐仓格外谨慎。**

### 上升阶段的两端，怎么识别

**刚进入上升阶段：**

- 不再向下探底，价格重拾上涨，指标和宽度好转；
- **可能突然下探跌破支撑，但会快速收复** → **Shakeout（甩掉弱手）→ 看涨信号**；
- **最重要的特征**：**市场参与者（包括你自己）普遍还怀疑** —— **"Wall of Worry"**；
  > **"正是这种不确定，才是我们果断下注尝试的最好时机。"**

**上升末期：**

- 大家都感觉良好、社交媒体上很多股神晒单、走势强劲、过度延伸、指标超买
  → **控制曝险、适度获利了结**；
- **注意：是"适度获利了结"，不是"全部清仓"**：
  > **"市场往往可以比你想像的还要更加疯狂，鱼尾也可以是肥的流油的。"**
- **折中方法**：**通过适度获利来控制整体曝险** —— **既降低回撤伤害，又保留捕捉最后疯狂的机会**。

## 2.4 预警（Situational Awareness）—— 因为"不能预测"，所以"只做观察清单"

**他的框架**：把 SA 拆成 **5 个维度**，每个维度给出"加曝险 / 减曝险"的信号。

| 维度 | 他用的指标 |
|---|---|
| **动能** | **20MA / 50MA 以上的股票比例**（市场宽度）；Stockbee 的 4% 涨跌家数 |
| **价格行为** | 指数是否**带量下跌**；是否跌破 **20MA**；是否贴着 20MA 横盘 |
| **情绪** | VIX；**COT 报告**（机构期货仓位）；**NAAIM**；CNN fear & greed；AAII |
| **背驰** | RSI / MACD histogram 与价格的顶部背驰 |
| **历史数据** | 季节性（seasonality） |

**关键：**

> **不需要所有维度都满足——满足的条件越多，越适合加 / 减曝险。**

**他的重要提醒：**

> **"大盤能夠重新回到 20MA，表示向上動能重新啟動。"**
> 在熊转牛初期，**重回 20MA 比等到 150MA 之上，能更早察觉入场时机**。

### 他讲的"见顶三阶段"（也是 SA 的一部分）

**核心观点（反直觉，但很对）：**

> **最容易输大钱的，不是大跌的时候，是"顶部横盘 + 情绪热烈"的时候。**

**他先讲了一个"新手输钱剧本"：**

```
上涨（闭眼赚钱）→ 膨胀（想全职交易）→ 忽略风险信号
→ 一个较深的回撤（不服气、报复性交易）→ 市场转横盘
→ 连续小亏（death by thousand cuts）→ 继续尝试
→ 回撤 > 之前的盈利 → 恐慌 → 大幅减仓 → 卖在最低点 → 反弹错过
```

| 阶段 | 关键词 | 特征 | 该做什么 |
|---|---|---|---|
| **① 疯狂** | **Euphoria** | 跳空高开、斜率变陡、长期超买；**所有人一致看多**；NAAIM ≥ 90–95 | **不是卖出信号**；**保持清醒、不要放大仓位、不要加杠杆** |
| **② 背离** | **Divergence** | 指数还创新高，但：斜率放缓、**放量不涨**（派发）、**宽度回落**、**领涨股不再领涨**、**news failure**、**突破成功率下降** | **开始风险控制**：降仓位、收窄止损、卖最弱持仓 |
| **③ 确认** | **Confirmation** | 顶部剧烈波动、**单日跌超 4% 的股票数 > 300 频繁出现**、领涨股崩坏、VIX 抽高、**散戶还在 buy the dip** | **三件事**：策略转保守 / 缩短周期 / 大幅降曝险 |

**他反复强调的三条免责（很诚实）：**

1. **见顶不是一个点，是"证据逐步累积的过程"**；
2. **不需要每次都猜中最高点**，但**必须在证据增加时愿意改变**；
3. **等到你确认市场出问题时，账户已经回吐了一部分利润——这是正常的。**
   > **"把赚到的钱保护好，远比向市场复仇重要。"**

## 2.5 系统 —— 因为"优势在系统不在预测"，所以"先建系统"

### 有效系统的四个条件（他自己定的标准）

| # | 条件 | 说明 |
|---|---|---|
| **1** | **正期望值** | `胜率 × 平均获利 − 败率 × 平均损失 > 0`；**需要 backtest + forward test**，**需要交易记录** |
| **2** | **完整的步骤** | 至少回答 **what / how / why / when to trade** |
| **3** | **步骤之间逻辑清晰的联系** | 如：大盘动能足 → 多做突破 + 加曝险；动能一般 → 做回撤型 + 缩曝险 |
| **4** | **可重复操作** | **环环相扣、清晰简单**；**过于复杂模糊的系统难以重复执行** |

### 他自己的系统 = 六个模块

```
收集 → 处理 → 分析 → 计划 → 执行 → 复盘
```

| 模块 | 他怎么做 |
|---|---|
| **收集** | 市场数据 / 经济数据 / 大盘数据；**聚焦在"跟策略相关且你能分析的"**；**从 SA 需要什么反推要收集什么** |
| **处理与分析** | **他坦白这是他的难点**；尽量量化 + 简单量化分析；**另一个思路是 Checklist 模式** |
| **计划** | ① 对**有能力掌握的交易标的**有清楚认知（哪些动能澎湃 / 四平八稳 / 对利率敏感 / 常突破失败）；② **熟练掌握 1–2 种策略，越简单越好**；③ **时刻有风险管理意识** |
| **执行** | **提前算好买入点 / 仓位 / 离场点 + 做好交易记录**。**"重点是提前制定好，才能在机会到来时迅速执行，不会手忙脚乱。"** |
| **复盘** | **定时做**（他**至少一个月一次**） |

**关于交易记录（他特别强调）：**

> 记录**越详细越好**——**不只记价格，要记"这笔交易的原因"和"当时的市场情况"**；
> **离场时也记原因**。
> **"有了这些详细的资料，你在做复盘的时候才会记得当时的情况，才能有效分析成功或失败的具体原因。"**

## 2.6 AI 的定位 —— 因为"AI 只放大不创造"，所以"先有系统再谈 AI"

### 他的核心结论（放最前面）

> **"目前 AI 不会帮你无中生有变出一套会赚钱的交易体系。**
> **AI 真正的价值，是把你已经有的优势放大。"**

**顺序是反的：**

> **不是"我用 AI 所以我能交易"，而是"我先会交易，AI 才能帮得上忙"。**
>
> **"如果你现在连自己的系统都还没有建立起来，这支影片给你最有价值的一句话就是：先别急着碰 AI，先把你的交易系统建立起来。"**

### 两个关键词

| 词 | 含义 |
|---|---|
| **Engineering** | **你不懂交易，就不知道要把 AI 引导到哪里去** |
| **Data** | **Garbage in, garbage out**；**要拿优势，必须有别人没有的资料** |

### 他遇到的"两难"（很诚实）

**把 AI 放进交易，会遇到一个矛盾：**

| | 客观部分 | 主观部分（让 AI 推理） |
|---|---|---|
| 例子 | 突破前一日高点入场、止损设最近三日低点、+4R 离场 | 让 AI 自己判断入场/离场点 |
| 好处 | **一致、可回测** | 可能**更精准、更灵活** |
| 坏处 | 可能不够灵活 | **① 不稳定（放大收益也放大损失）；② 难以回测验证** |

> **他的追问**：**"一旦自由空间多了，AI 跟随的那套策略，还能不能算是我们验证过有 edge 的策略？"**

**他的方案**：**把系统分离成"纯客观部分"和"纯主观部分"**——客观的让 AI 写代码执行，主观的让 AI 推理；
**验证方式**：**他和他的 Agent 做交易比赛**（结果论英雄）——但**这要大半年的 forward test**。

### 他推荐的起点（很务实）

> **从实际场景出发，小范围开始，先把你系统里的某一个环节交给 AI，**
> **而且要选那种"AI 推理能做得比你更好更快"的环节。**

**他自己的两个例子：**

1. **叙事和催化剂分析**（setup 用 screener + 肉眼筛；**催化剂 / 叙事的搜集和验证交给 AI**）；
2. **每日社交媒体（X）与市场主题追踪**（让 AI 扫描情绪、抓当天发酵的主题、做摘要 → 建立 SA）。

### 他最后强调的：**资料库**

**好资料的两个标准**：**① 质量**（完整 / 准确 / 一致 / 唯一 / 及时）；**② 人无我有**。

> **"Yahoo Finance 那种网路上免费找得到的资料不算，因为你找得到别人也找得到，AI 当然也能找得到，那就毫无优势可言。"**
> **Proprietary data 很贵**（Bloomberg terminal **每年 24,000 美金**）。

**但他说：你手上有三种独特资料：**

| # | 资料 | 用途 |
|---|---|---|
| **1** | **你的交易日志（trading journal）** | **最重要又最容易被忽略**——AI 可以**反推出你真实的策略样貌**，告诉你"哪一类单最赚、哪个坏习惯最伤你" |
| **2** | **你的观察清单（watchlist）** | 让 AI 做成 dashboard，每天自动观察分析 → **提升 SA** |
| **3** | **二次加工的资料** | 自建指标、自己跑的相关性分析、策略回测资料 |

**关键动作**：**建立一个属于自己的交易资料库**（也是 Agent 的知识库和记忆）→ **"交易资料飞轮"**：
> **资料越多 → AI 越懂你 → 建议越准 → 交易越好 → 资料越优质。**

**他给的第一个行动：**

> **"打开你的交易记录，把它整理成一份结构化的格式，哪怕只是一张 Excel。从今天开始好好记录——这就是你资料飞轮的第一圈。"**

**背景**：**T2108**（纽交所 40 日均线以上的股票比例）大幅下跌，但 **SPY 一路上扬、离新高很近**——**宽度与价格背离**。

**他问 AI 三个问题**（数据：2012 年至今）：

| 问题 | 结果 |
|---|---|
| **1. T2108 跌破 20 后，SPY 后续走势？** | **后续 5/10/21/42/63/126 日都是正回报**（超卖反弹）。**但大部分时间是"指数已经明显下跌后"才发生** |

> - **"AI 找出的相似歷史片段……有漲有跌，也沒有顯著性結論。"**

**他最后说，真正的判断还是靠：**

> **"價格體系、價格走勢、領漲股 set up 有沒有多、突破的成功率高不高為主。"**

# 六、两种核心策略（突破 2.0 / 回撤 2.0）

> **他的原话**：**"回撤交易和突破交易是目前最主要的两种核心策略，基本上已经可以覆盖大部分的市况。"**
>
> **怎么选**：
> - **动能强、趋势顺、资金愿意追高** → **突破交易**；
> - **弱动能牛市正常调整、指数震荡回吐** → **回撤交易**。

## 6.1 突破交易 2.0

### 他的"开窍"过程（这段很有价值，因为能看出他也在走弯路）

| 阶段 | 做法 | 遇到的问题 |
|---|---|---|
| **①** | **突破某个价位就买**（O'Neill Cup with Handle、Minervini VCP、箱型、头肩底） | **追入后立刻回撤，账面亏损，心理压力大** |
| **②** | **等突破后回撤再买**（Pullback Buy） | **要么不回撤（白等），要么担心假突破而犹豫** |
| **③** | **突破前偷步买** | **担心没确认，失败率高** |
| **④ 开窍** | 注意到**突破时常常伴随"均线收缩 → 扩张"** | —— |
| **⑤ 被点醒** | **Qullamaggie / Pradeep**：**突破的本质不是"突破某个价格"，而是"区间扩张（Range Expansion）"** | —— |

**核心洞察（他反复强调的一句）：**

> **极致的收缩会带来极致的扩张。**
> **成功的区间扩张之前，通常都会出现非常紧密的价格盘整——"暴风雨前的宁静"。**

**→ 所以他把突破交易，简化成"只看一种形态"：**

> **右侧价格的紧密低波幅盘整（Tight Range）。**

### Tight Range 怎么算"够紧"

| 项 | 标准 |
|---|---|
| **时长** | **一般 5 天或以上**；**狂牛市场下 3 天**也可以 |
| **前提** | **股价不要太 Overextended**（太远离 50MA → 突破失败概率增加） |
| **配合均线看** | **均线平行或开始收拢** → 盘整充足 → **扩张的力度和持久度才可观** |

### 但 Tight Range 可上可下 → 需要四个条件提高"向上"的概率

1. **股价在 200 日均线之上**（上升趋势）；
2. **盘整靠近支撑位**（下方有支撑 → 成功率高 + 好设止损 + 好盈亏比）；
3. **过去 12 个月至少涨过 50%**（强者的证明，也可能代表有好的蓄势）；
4. **最近几天没有"高动能下跌"的突兀走势**（没有抛压）。

> **⚠️ 反向**：**如果紧密盘整之前出现高动能下跌（尤其在高位）→ 这更像"做空形态"，要避免。**

### 三种形态，和怎么选

| 形态 | 类似 | 特点 |
|---|---|---|
| **高位盘整** | **High Tight Flag** | 动能强，**但容易过度延伸，突破后容易后继无力** |
| **中间盘整** | **VCP 的 Cheat 形态** | 动能一般但**没有过度延伸**，蓄力中 |
| **低位盘整** | **VCP 的 Low Cheat** | 动能落后，但**潜在上行空间大，盈亏比好** |

**怎么选（两种思路）：**

**① Pradeep 的方法**：**每天观察"过去 5 天涨超 20% 和跌超 20%"的股票**，看它们属于哪种形态的突破
→ 如果**大部分是"中间盘整"**，说明**当前市场这种形态成功率较高**；
→ **同时也能看到哪些板块在集体突破** → 选股焦点放在那些板块。

**② 结合大盘**：

| 大盘 | 个股 | 做什么 |
|---|---|---|
| **好**（20MA 之上） | 有好趋势 / 主题 / 催化 | **高位紧密盘整** |
| **动能一般**（50MA 之上） | 大型旗舰股 | **中间紧密盘整** |
| **调整尾声** | 之前的明星股，叙事还在 | **低位紧密盘整**（盈亏比最好） |

### 大环境（三个研判点）

1. **大盘在 30 周（150 日）均线之上**，最好在 50 日之上；
2. **宽度与动能**：20MA / 50MA 以上股票比例 + Stockbee 的 4% 涨跌家数；
3. **有催化剂**：**持续有大的主题 / 概念 / 行业炒作，最好和科技股有关**。

### 入场时机（三种）

| 方式 | 做法 | 止损 |
|---|---|---|
| **① 突破时买入** | 在更小时间框架（1/5/30 分钟）区间突破时买入；不习惯就等 1 小时 / 日线出现波幅扩张突破时入场 | **确认突破那根 K 线的底部 / 当日低点 / 前一日低点 / 区间底部** |
| **② 突破后回踩买入** | 突破当天或第二天，回撤到紧密区间**上方**时买入 | 同上 |
| **③ 提前（偷步）买入** | 股价还在区间内、或靠近区间底部时买 | 同上 |

**回踩买入的三条要点：**

1. **回撤最好在当天或突破第二天**；**超过两天没回撤 → 大概率突破成功了 → 直接放弃**；
2. **股价没走远就回撤**才好；**走很远才回撤 → 回撤力度会很大 → 假突破嫌疑**；
3. **配合小时间框架的均线 / VWAP / 支撑阻力线**找最佳入场点（交汇区域 = 强支撑 → 可设更窄止损 → 更大仓位）。

### 止损（这里的取舍说得很清楚）

- **越窄 → 仓位越大，但被打中的概率越高**；
- **要点：尽量不大于一个 Average Daily Range（ADR）**；
- **结合 SA**：**市场开始变得波动、动能开始下降 → 不要设得太窄**。

### 分段获利（他讲了四种人的做法）

| 谁 | 规则 |
|---|---|
| **ColorMag** | 入场后 **3–5 天**就开始部分获利 |
| **Pradeep** | 入场后有 **3–5 天的显著涨幅**就大部分获利 |
| 其他人 | 涨幅达 **3 倍 ADR** 就部分获利 |
| **他自己** | **通常至少要有 3–4 个 R 才考虑部分获利** |

**大原则（两条，很实用）：**

1. **除了最后一段，其他部分用 "sell into strength"（趁强势卖）**；
   **部分获利后立即把止损上移到入场点或设移动止损** → **回收曝险**；
2. **最后一段用 "sell into weakness"（趁弱势卖）**：
   **收盘价跌破 10 日或 20 日均线时卖** → **让最后一部分仓位去捕捉最后的涨幅**。

### 提前离场的四种情况

1. **单日大动能下跌**（突兀走势）；
2. **突破一段时间后价格已远离区间，但短时间内迅速跌回区间内**（疑似假突破）；
3. **多日没有发生预想的爆发性走势**（5 天以上 → 时机不对，机会成本）；
4. **大盘或所在行业发生集体性显著回撤**。
   （例子：他买了核能股 **BWXT**，第三天整个核能行业集体回调 → 他先离场。）

### 催化剂（最核心的筛选条件）

> **"股价突破的成功率、动力强度和持久度，跟股票背后的概念和叙事高度相关。"**

- 例子：**LHX**（军工：国防预算 / 地缘政治 / 太空合约）；**INTC**（美国政府入股）；
- **他现在的做法**：**用 AI 帮他从一堆有突破形态的股票里，提取"有催化的个股"**，再追问细节。

### 他自己的案例（**含大量失败，这点很诚实**）

**成功的**：Meta（高位盘整，回踩 10 日线买）、CCJ（中间盘整，核能蓝筹）、USAR（稀土）、KTOS（国防）、SOLX（制冷 / 数据中心散热 / 太空数据中心，**做了两次**）、SOUM（AI）、GLXY（底部盘整）、VOYG（太空）、IDCC（高位盘整）

**失败 / 不理想的**：

| 标的 | 他的复盘 |
|---|---|
| **SNOW** | **形态很漂亮，但"我比较着急，还没触及止损就离场了。如果能再持仓久一点，回报会好很多——这是我个人操作上的问题。"** |
| **PLTR** | **"入场有点 FOMO……用当日低点作为止损。以上帝视角看，可以等他做个盘整靠近 10 日线时再入场。"** |
| **PLUG** | **当日入场、当日止损**；第二天忍不住又进，再次被止损 → **"这不正是突破后立刻大动能拉回原点、疑似假突破的情形吗？"** |
| **NBIS** | 高位盘整入场，**涨幅有限** → **"高位盘整的突破容易后继无力，尤其处在过度延伸状态时。"** |
| **LUMN** | 试了两次效果都不好，但**"财报前趁还有利润就离场，做法上是没问题的"** |
| **ALAB / MSTL / OUST / MP** | 突破失败，认输离场 |

**JPM：做到第三次才成功** —— **"第二次买入是有些心急的。"**

**他由此总结的三条（很重要）：**

> 1. **"突破交易是需要有多次入场的心理准备，但如果第一次失败了，第二次入场前最好是等待更加确定的信号。"**
> 2. **"试错是有成本的，一直试一直错容易 dead by thousand cuts。因此决定在入场时一定要有更加明确的信号或者理据。"**
> 3. **"也要给试错设定一个上限——比如我自己，如果做三次都不成功，就会直接放弃。"**

## 6.2 回撤交易 2.0

### 核心三句话

1. **股价要回撤到重要的关键位置（Key Level）**；
2. **股价在这个位置要有明确的支撑确认**；
3. **这笔交易要有足够好的盈亏比**。

> **"回撤交易不是随便逢低买进，而是等股价跌到了值得出手的位置、等市场告诉你这里真的有买盘，这个时候才进场。"**

### 什么是 Key Level

> **不是单一一根线，而是"多个支撑因素汇聚的区域"。**
> **"一个真正值得注意的 Key Level，通常不是只有一个理由——我认为至少要三个或以上的支撑因素汇聚在一起。"**
> **"而且最好这个位置在图表上很清晰、很自然、一眼看得出来，而不是你硬凑出来的。"**

**汇聚因素包括**：移动平均线（50/150/200 日）、前高突破后的回踩位置（原阻力变支撑）、Fibonacci（0.5 / 0.618）、VWAP（尤其重要事件后的 anchored VWAP）、Volume Profile 的高成交密集区（Point of Control）、整数关口 / 心理价位、公司或大股东回购的位置。

### 支撑确认（两个面向）

| 面向 | 信号 |
|---|---|
| **价格行为** | **pin bar**（长下影）、**bullish engulfing**、强势阳线；**Wyckoff Spring**（跌破 Key Level 后迅速回收）——**这种信号往往更强烈** |
| **成交量** | **放量反弹**更有说服力（"不只是价格站起来了，而是有真实资金进场承接"） |

### 回撤不能太浅

> **"至少要回撤到 50 天移动平均线附近，这种回撤才会比较有操作价值。"**
> **"再浅一点的回拨，很多时候就像是盘中的杂讯。"**

### 两类回撤

| | **普通回撤** | **深度回撤** |
|---|---|---|
| **适用** | **牛市中的弱势上升趋势**（整体向上，但速度不够快、突破成功率不高） | **较深的牛市调整**（大盘跌 5%、10%，甚至 20% 的技术性熊市） |
| **触发条件** | ① 仍在上升趋势；② 回撤到 Key Level；③ 有支撑确认 | ① **极度超卖、恐慌性抛售、有均值回归倾向**；② 回撤到 Key Level；③ 支撑确认 |
| **额外重点** | ① **回撤过程有序**（不是恐慌式崩跌，量能逐渐收敛）；② **之前有过强势上涨或漂亮突破**（加分项） | **成交量**：希望看到**放量下杀后，在关键位置出现更大量的承接**，或**长下影 + 放量反弹** |
| **适合标的** | ① **指数型 ETF**（SPY/QQQ）；② **大型旗舰股**（Mag7）；③ **市场高度关注的明星股**（PLTR / MU / COIN） | ① **指数 ETF**（最合适）；② **大型旗舰股** |
| **⚠️ 禁忌** | —— | **"千万不要把深度回撤这一套策略随便用在中小型股票身上"**——大盘回调时中小型股很多**不是被错杀，而是真的走坏了**，很容易一路阴跌 |

### 入场方式

**① 等支撑确认的 K 线走出来，以那根 K 线的高点作为入场触发。**
（如果那根 K 线波幅太长 → **不要急着追高**，等之后回撤到那根 K 线中间位置再切入。）

**② Delay 入场法**：
**股价在 Key Level 附近先止跌 → 横盘几天 → 波幅收缩 → 收缩完成后，当成一次小型突破来做。**

> **"回撤交易的入场不一定非要抄在最低点，很多时候等一下反而会更好。"**

### 止损（和突破交易相反）

- **回撤交易不建议用很窄的止损**；
- **原因**：**回撤本身就代表股价刚经历一轮下跌，情绪不稳、波动大** → 窄止损容易被扫；
- **放在底部之下 + 合理缓冲**：缓冲参考 **0.5–1.5 倍 ATR**；
- **但止损要跟盈亏比一起看**：**至少要求 2:1 的盈亏比**。

> **"如果加上合理缓冲之后、甚至不加缓冲的情况下，股价预计反弹到短期顶部也做不出 2:1 的盈亏比，那通常我就会放弃这笔交易。"**
> **"不是跌得够多我就能去做，而是跌得够多之后还要值得去做。"**

### 获利与提前离场

- **分段获利**：第一个获利点参考**前一个短期顶部**或**前一段整理区间的上沿** → 减码一部分；剩下看能否延续。
- **提前离场三种**：
  1. **单日突兀、破坏结构的走势 + 远超平日的成交量**（很长的 bearish K 线）；
  2. **入场后 10 天左右没有 follow through**；
  3. **整个板块 / 行业 / sister stocks 一起走坏**。

### 选股（这一段和突破交易差别很大）

> **回撤交易更依赖"你平时对个股的认识 + 长期的 watch list 累积"**，
> **因为股票本身的质地（基本面、叙事、产业地位、市场热度）比图表形态更重要。**
>
> **"这就是为什么回撤交易很难像突破交易那样，单纯依靠技术指标去做大规模筛选。"**

### 案例

- **成功**：Meta（Key Level = 主力位置 + Volume Profile POC + 50 日线）、
  **CrowdStrike**（200 日线 + 主力位置 + Fib 0.5；**第一次入场第二天 gap down → 先离场，第二次再进**）、
  **QQQ 深度回撤**（2025 年 4 月关税、恐慌抛售、放量、超卖、回到 2024 年低点 + Fib 0.618 → **"这成了我 2025 年回报最关键的一笔"**）、
  TLT（长年期美债 ETF，周线支撑 → 日线底部突破入场 = **延迟入场**）、Google；
- **失败**：**Eton**（第四天 gap down 打到止损）、**CACI**（第二天长阴打止损）。

**他由此总结的两句（很重要）：**

> 1. **"没有一个策略是完美或者必胜的。"**
> 2. **"如果连回撤交易的失败率都非常高，那么我们就要小心当下的市场状况，会不会还有更深度的回调。"**

# 七、策略与市况的匹配（这一节最重要）

> **他的核心观点**：**"交易需要刻苦练习技术，但更讲求应用时的巧妙。技术更多是要求练好'做什么、怎么执行'，而'巧'则是要求掌握好'交易的时机和背后的逻辑'。"**
>
> **他用的类比（宝可梦属性相克）**：
> **"用杰尼龟打皮卡丘的时候非常难打……但如果对上火系精灵，用水系就好打很多。交易世界也是一样的道理。"**

## 7.1 为什么学会 VCP 却无法持续盈利

**先看他的立场（很重要，他不是在否定 VCP）：**

> **"我绝对不是要说 VCP 不行、或者 Mark Minervini 不行。事实上 Mark Minervini 已经用他辉煌的交易成绩证明了 VCP 的成功，而我也曾经通过 VCP 获得不少盈利。"**

### VCP 的六要点（他总结的）

1. **股价在 150 日线之上**（上升趋势，Weinstein 的判定）；
2. **相对强度要强**（MarketSmith 的 RS 值，**他一般选 90 以上**）；
3. **股价接近 52 周新高**（**最好不低于 52 周新高的 15%**）；
4. **波幅收缩，最好三次或以上**；
5. **收缩到最后，股价波动 < 1%**；
6. **最后配合成交量下跌**。

### 他的关键洞察

> **"VCP 本质上是一种突破交易的形态，跟 Cup with Handle、Bull Flag 本质上是一样的，只不过样子不同。"**
> **"突破能否成功，还需要看的是——动能。"**

**结论：**

> **如果大市具备动能 → VCP 等突破交易的成功率往往比较高。**
> **如果你总是突破失败，可能并非 VCP 六要点有哪一点没满足，而是——你在不适合的大市状况下做 VCP 突破。**

### 不适合的市况（他给的失败案例，按时期分组）

| 时期 | 市况 | 失败的 VCP 例子 |
|---|---|---|
| **2025 年 2–3 月** | **大跌市之前的见顶市况** | **ESTC、SNOW、BIRK** |
| **2024 年 7–9 月** | **大势调整期** | **Microsoft**（横盘，不算成功）、**Tesla**（9/19 高成交量突破，**走没多久掉头向下、打中止损后又向上抽升**——**"这种走势最最最讨人厌"**） |
| **2021 年 9–10 月** | 调整 | **MELI**（借业绩利好 gap up 突破，后续没走远）、**PLTR**（9/16 高成交量突破但无 follow through）、**MSTR、Shopify、Amazon、Adobe、VRT** |
| **2021 年底–2022 年初** | **初步见顶、进入熊市** | **AVGO、BA** |

**这些时期的共同特征：**

> **缺乏动能、甚至是深度拉回、且在相对高位走势非常反复、波动有扩大的迹象。**

### 怎么印证"市况"？—— Stockbee 的 Market Monitor

**主要看两个数：**
- **当日升超 4% 的个股数**；
- **当日跌超 4% 的个股数**。

| 时期 | Market Monitor 显示 |
|---|---|
| **2025 年 2–3 月** | **很多天"跌超 4% 的个股数 > 升超 4% 的个股数"，且很多天跌超 4% 的股票 > 300 个** → **动能非常差** |
| **2024 年 7–8 月 / 2021 年 9 月** | **绿（升超 4% 多）和红（跌超 4% 多）相互交错** → 今天升明天跌 → **非常不利** |
| **2022 年年初** | 绿明显少于红，而且**深绿和深红（>300 个）交错出现** → **"别说是 VCP 了，其他策略也很容易被左一巴掌右一巴掌"** |

### 他判断"大市动能"的四个方法

1. **Stockbee 的 Market Monitor**（当日升/跌超 4% 的股票数）；
2. **标普 500 能否维持在 20 日线之上并平稳向上**；
   - 例子：**2021 年整年**都是有利行情 → 他做过一笔成功的 **CRWD，获利约 5R**；
3. **有没有热点新闻**——**必须是"重大到足以改变整个基本面"的 big news，不是小道消息**；
   - 例子：**2024 年 11 月 Trump 当选** → **Tesla 两个月爆升近一倍**；Bitcoin VCP 突破后回踩再涨 50%；altcoin 有的三位数回报；
   - **他的理由**：**"炒小道消息所需要耗费的时间和精力，跟所获得回报往往不成正比。"**
4. **RSI**：**用 RSI 的变化看哪些板块/行业最近突然走强** → 找下一浪的领涨行业/个股。
   - 他**每天记录各大板块的 RSI 变化**，做成折线图 → 看**板块轮动**。

## 7.2 Situational Awareness 的建立

**他从 Pradeep（Stockbee 创始人）学来的。**

> **核心一句话**：**"辨识市场状况的改变，从而引导交易策略的改变。"**

**5 个维度（他会问自己的问题）：**

| # | 维度 | 他看什么 |
|---|---|---|
| **1** | **动能** | 强还是弱？Market Monitor、20MA/50MA 以上比例、McClellan、RSI/MACD |
| **2** | **价格行为** | 趋势向上还是向下？**有没有过度延伸（over-extension）**？（配合 Bollinger / RSI 超买超卖） |
| **3** | **情绪** | 偏乐观/悲观，还是**极度**乐观/悲观？**市场对重大新闻的反应正常还是反常？**（NAAIM、AAII、COT） |
| **4** | **背驰（Divergence）** | **观测到的现象与大盘不一致甚至相反**：新闻背驰、技术指标背驰、20MA 以上股票数与大盘走势的背驰 |
| **5** | **历史统计数据** | 季节性（"Sell in May"、9 月通常较差） |

### 各策略适用的市况（他总结的表）

| 策略 | 动能要求 | 价格行为 | 情绪 | 通常发生时间 |
|---|---|---|---|---|
| **HTF / VCP**（进取突破） | **高**（充足上升动能）+ 宽度好 | **在 20MA 上、维持上升趋势、暂未极度过度延伸** | 无特别要求（**但极度乐观时，缩短持仓时间**） | **4 月 / 7 月 / 10 月** |
| **Complex Pullback** | **不严格**，但至少是（弱）上升趋势 | 市场进入回调 | 回撤幅度**差不多到悲观 / 极度悲观** | **2–3 月 / 5–6 月 / 8–9 月** |
| **左侧（Counter Trend）** | **反着来**：连续恐慌下跌、宽度极差 | **已超卖、价格远离均线** | **极度悲观且维持了一段** | 有时伴随"对坏消息不再下跌"的背驰 |

### 他的三个"提前辨识市场变化"的信号（很实用）

1. **领导股 / 领导板块的多少**：
   **动能充足的牛市会不断涌现领导股/热点**；
   **如果一路领先的领导股突然变弱**（跌破 20MA/50MA、**大成交量下跌**）→ **警觉大盘走弱**；
2. **策略本身**：
   > **"之前用得很好的策略突然不奏效了，或者发现另一种策略开始奏效"** → **可能是市场情况转变的信号**；
3. **最直接：监控你的收益曲线（Equity Curve）**：
   > **"如果一直持续长进，代表你的策略适用于现在的市场情况；**
   > **反之，如果收益曲线毫无寸进、或者出现回撤，与市场发展出现了背驰，那就需要警惕。"**

### 他的免责（很重要）

> **"五个条件都符合某种策略，不代表用这个策略百分百必胜；同样，没有满足五个条件，也不代表不能做。"**
> **"如果做得顺手、策略确实奏效，就应该继续，直到失效为止。"**

## 7.3 左侧交易 vs 右侧交易

**他的立场：**
- **他主要用右侧交易**（因为他是从右侧入门的）；
- **但经历牛熊后，发现有些市况十分适合左侧**；
- **"左侧交易对我只是一个配菜。"**

### 左侧交易的本质

> **"价格走势有周期性——升得久了或升得多了就会跌，跌得久了或跌得多了就会升。这是一个均值回归的过程。"**
> **"左侧交易，就是交易这个均值回归的过程。"**

### 判定左侧时机的四个条件

| # | 条件 | 量化 |
|---|---|---|
| **① 价格极度远离均值** | 用 **150 日或 200 日线**作为均值参考 | **2025 年 3–4 月**：低点距 200 日线 **18.4%**（vs 之前高点距 200 日线 **7.8%**，多两倍多）；**2020 COVID**：**37%**；**2018 年 12 月**：**16%** |
| **② Capitulation（恐慌性抛售）** | 下跌动能**异常急促强劲**、跳空下跌或**非常大非常长的阴烛**、下跌角度**接近 90 度**、**成交量暴增**、**ATR/ADR 极速增大** | **2025 年 4 月初**：标普**连续三天跳空下跌**，成交量和波幅暴增 → **"许多玩家已经投降，此后可能再无货可沽"** |
| **③ 情绪极度悲观（反向指标）** | NAAIM 经理人持仓、CNN fear & greed、AAII | **他自己的观察（很有意思）**：**"当社交媒体通篇都是负面情绪、长期看涨的基金经理都出来认错投降、完全跟投资无关的 KOL 也在谈大市下跌、身边同事开始说股市完蛋、家中老母亲叫你卖掉股票的时候。"** |
| **④ 市场宽度极差** | **50 日线以上的股票比例** | **低于 20% → 进入可能反转区间；跌到 10% 或以下 → 见底反弹可能性更大**（他推荐 **MarketInOut** 网站免费看） |

**⚠️ 他的重要提醒**：

> **"第一只脚"也可能失败** —— **熊市可能有第二只脚、第三只脚**。
> 例子：**2015 年 8 月**的 capitulation（跳空 gap 更大），但**2016 年初还有一次大跌**（第二只脚）。
> **不过**：**2015 年 8 月第一只脚反弹幅度已接近 12%**，**已有不错的利润空间可以获利操作**。

### 入场与止损

- **入场**：**重要支撑位**——**在 higher time frame（周线甚至月线）上找，通常是之前大跌浪的底部**；
  **Fibonacci 0.618** 作为辅助——**"如果重要支撑位刚好也在 Fib 0.618，我的入场信心会更大"**；
- **止损**：**入场点下方 + 1.5 到 2 倍 ATR 作为缓冲**。

### 期望值与胜率（他给的硬数字）

> **"我自己的交易记录来看，总体上左侧交易的胜率是在 30% 到 35%。**
> **所以我每笔左侧交易必须要至少有 2.5 个 R 以上的盈利，才能够维持正期望值。"**
>
> **"左侧交易的优势并不是在成功率，而是在高回报风险比——**
> **用低的成功率换取高的回报风险比，在总体上仍能维持正的期望值。"**

### ⚠️ 最重要的两条限制

> **1. "左侧交易建议只用在美股指數交易，比如 ETF（SPY / QQQ），不建议用在个股，尤其是二三线股票。"**
> **"因为美股指数经过了历史的洗礼，证明趋势长期保持向上，做美股指数的左侧交易相对较为安全；但个股来说，就真的难保不会只跌不升，风险太大。"**
>
> **2. "即便是结合了这支影片所讲的所有衡量左侧交易的时机，左侧交易的成功率依然是天然地比右侧交易要低——所以为什么对我来说，左侧交易只是一个配菜。"**

# 八、两个具体的入场形态

## 8.1 High Tight Flag（HTF）—— 来自 Qullamaggie

### Qullamaggie 是谁（这段背景很值得知道）

- 瑞典散户 **Christian Qullamaggie**；
- **8 年从 9,000 多美金做到 8,000 万（8,000 多倍）**；
- **爆仓过 3 次**——每次靠**做保安**一边上班一边存钱，再回来；
- **因为赚太多，缴税多到进入瑞典"缴税最多的公民"第 15 名**（公开数据）；
- **他在自己网站介绍的三个常用策略**：**Breakout / Episodic Pivot / Parabolic Short**；
- **他的 Breakout，就是 High Tight Flag。**

### 为什么值得"学透"这个形态

> **"其他突破形态——比如杯柄形态、头肩底——最右边即将突破的那个部分，其实就是一种 High Tight Flag。"**
> **"只要学会并熟悉掌握 HTF，其他所有突破交易形态的核心，你基本上都能掌握。"**

### 形态拆解（五个要点）

**① 左边要有一段"非常急促的大涨"（Up Leg）**

| 项 | 标准 |
|---|---|
| **时间** | **1–3 个月**（不能太长） |
| **涨幅** | **至少 30% 以上** |
| **形态** | **涨的时候干脆利落**（几根大阳线）；**跌的时候轻微且短暂** |

**对比例子**：**ABNB**（清脆有力，短时间突发暴涨、几根大阳线）vs **Tesla**（**扭扭捏捏，没涨多少就跌，时间跨度长 → 动能不足**）。

**② 盘整期间幅度要"紧致"**

| 项 | 标准 |
|---|---|
| **盘整时间** | **2 周到 2 个月**；**牛市很强时，1 周就够** |
| **⚠️ 不建议太长** | **盘整太久 = 动能减弱的迹象** |
| **形态** | **波幅收缩**；到最后几根 K 线**非常紧致、低波动** |
| **回撤** | **轻微、有秩序**；**骨架基本在 10MA 或 20MA 之上** |

**对比例子**：**Rocket Lab**（两段盘整都紧密，**ADR 每次收缩都在降低**，突破时波幅扩张）vs **TM**（盘整松散、最后跌破 10 日线、**下跌时成交量上升** → 动能差）。

**③ 成交量收缩**（和 VCP 一样）—— **不是必要，但有最好**。

**④ 入场（在日内级别做，这是它和普通突破最大的不同）**

**流程**：

```
盘前：把要交易的股票放进 watchlist
开盘前：进入日内级别图表（1 / 5 / 30 分钟）
开盘后：等第一个完整 K 线出现
```

**要求**：

- **第一个 5 分钟最好是一根阳线**；
- **第一个 5 分钟的收盘价必须高于前一天的收盘价**（**最好开盘价也高于**）；
- **入场点 = 第一个阳线的最高点**；
- **止损 = 第一个阳线的最低点**。

**⚠️ 关键校验（这条最重要）**：

> **止损幅度不应该大于该股票的 ADR（14 天平均日均波幅）。**
> **如果大于 → 说明第一根阳线生幅过大、止损过宽 → 不宜追入。**

**⑤ 离场（三步，非常清晰）**

```
1. 等 3–5 天后，部分获利（1/2 或 1/3，看进取程度）
2. 获利后马上把止损上移到入场点 —— 确保这笔交易不会亏损
3. 之后当收盘价低于 10MA 或 20MA 时，全部结束仓位
```

> **他解释为什么这么做**：
> **"它是靠短期部分获利来获得你心理上的优势，从而提升持仓能力，以博取更大、更久的升幅。"**

### HTF 的五个要点（他的总结）

| # | 要点 | 细节 |
|---|---|---|
| **1** | **需要动能的环境** | 四个指标：Stockbee Market Monitor、大盘是否维持 20MA 之上、RSI 变动、宽度 |
| **2** | **选高动能个股** | **相对强度 > 97**（Qullamaggie 的建议：过去某段时间价格最强的 1–2%；**他有时放宽到 > 90**）；**ADR > 3%** |
| **3** | **窄止损 = 大仓位** | `股数 = R ÷ (入场点 − 止损点)` |
| **4** | **窄止损 = 低胜率** | **Qullamaggie 自己透露胜率只有 30–35%** → **要做好多次入场的准备** |
| **5** | **每次下注曝露多少风险** | 见下 |

**关于"相对强度回看期"的区别（很细，但有用）**：

| 回看期 | 含义 |
|---|---|
| **1 个月 > 97** | **近期才有爆发性走势，目前可能还处于短暂盘整**（例：QUBT） |
| **6 个月 > 97** | **之前有过爆发性走势，盘整时间相对较长** |

**两种都可以交易**，看风险喜好；**大市值股票（如 Tesla）更适合用长期一点的相对强度**。

**关于"曝险"的两种思路（这段很有价值）**：

| | 情况 A：1R 一次下注 | 情况 B：把 1R 分 3 次下注（每次 0.33R） |
|---|---|---|
| **预计试 3 次** | 前两次失败 → **已损失 2R** | **极端情况三次全败，损失也只有 1R** |
| **优点** | **博取更大回报** | **分散曝险、换取多次入场机会** |
| **缺点** | **整体仓位波动放大**——连输 3、4、5 次时损失很大 | **限制潜在回报**（0.3R × 5:1 = 1.5R） |

> **"没有标准答案……更多的是要自己去思考：我的交易风格是怎样？我有多进取？我的心理承受力有多大？"**

### 他的五条个人心得（很值钱）

**① 要非常耐心（他用了"狙击手"的比喻）**

> **"你不能盲目出手，因为它是窄止损——盲目出手会经常被打中止损。**
> **必须等待最佳出手时机，而当时机出现时，必须毫不犹豫、果断出手。"**
> **"想象自己是一个狙击手或者刺客——我打的是暴击，要一招制敌、一招毙命，而不是散弹枪疯狂扫射。"**
> **"一年当中，你也不是每一刻都有交易的机会。"**

**② 动能需要"燃料"——而燃料更多是消息面的东西**

- **2025/4/9**：Trump 的推文（关税）→ 市场**绝地大反弹** → **大市动能 360 度反转**；
- **2025/5**：Trump 加速核电厂建设 → **核能股（LEDU、SMR）**；
- **2025/6**：稳定币 **Circle 上市** → 金融科技/加密相关股票；
- **价格行为上**：**大盘突破"多年"或"底部盘整很久"的重要支撑主力位置 → 通常代表大行情**。

**③ 优先选"热门明星股 / 主题股"——他把股票分四类**

| 类别 | 特点 | 适合吗 |
|---|---|---|
| **热门明星股 / 主题股** | 市场聚焦、有主题有故事有想象空间、**体量适中** | ✅ **最适合** |
| **强势行业里的强势个股** | 某些消息带动整个行业变强 | ✅ 有利 |
| **大型旗舰股**（Mag7 除 NVDA/TSLA） | **体量太大，难炒起来** | ⚠️ 次之 |
| **传统蓝筹股** | 不是市场焦点 | ❌ 不适合 |

**④ "一鼓作气，再而衰，三而竭"——尽量交易第一或第二个 Up Leg**

- **PLTR**：第二个 Up Leg 突破后有较大较久的上升；到**第三个时动能明显下降**；
- **DDOG**：第一个 Up Leg 后大幅上升，第二个还行，**第三个开始动能衰竭并有反转信号**。

**⑤ 延迟入场（进阶技巧）**

**当开盘已 gap up 很多、止损距离 > ADR 时**：

> **停一停**，等日內价格回撤，并在分钟级别出现反转（强烈反弹、higher lows / higher highs）→ **再寻求入场**。

**例子**：**RBLX**（突破进场尴尬 → 等回撤形成短线 higher lows → 突破主力位置回踩时进场 = 延迟入场）。

| | |
|---|---|
| **好处** | 减少被止损频率 + **保持较窄止损（较大仓位）** |
| **代价** | **有可能股价直接向上冲，你就错失机会** |

## 8.2 Simple Pullback —— 来自 Adam Grimes

**来源**：**Adam Grimes《The Art and Science of Technical Analysis》**。

**定义（他归纳成一句）**：

> **上升趋势中，股价在突破或上涨后出现"有秩序的回撤"，并在回踩支撑主力位置附近入场。**

### 先看"突破后可能出现的四种走势"（这张分类表很有用）

| # | 走势 | 怎么办 |
|---|---|---|
| **1** | **一路向北暴涨** | **没有理想介入机会 → 果断放弃，转而找其他机会** |
| **2** | **高位盘整** | **等波幅收缩到极致形成 HTF，然后入场** |
| **3** | **回踩支撑阻力位置附近** | **适用 Simple Pullback** |
| **4** | **假突破**（突破后迅速拉回、很快跌破突破点 + **很强的下降动能**） | **潜在假突破 → 走势反转 → 理想的沽空入场机会** |

**怎么区分"回踩"和"假突破"（这是关键）**：

| | 特征 |
|---|---|
| **回踩（可做）** | **有秩序的回撤**——**下跌动能不强、波幅不大、成交量不激增** |
| **假突破（不做）** | **猛烈的回撤** |

### 判断 Key Level 的三方面

**① 该位置是否 Key Level**（**3 个以上潜在支撑汇聚**就算非常 key）：
支撑主力位、移动平均线、趋势线、Fibonacci、**Volume Profile（POC）**、**VWAP**。

> **补充两个概念**：
> - **Volume Profile**：成交量在价格区间的分布图；**POC（Point of Control）= 成交量最密集的价位**；
> - **VWAP**：按成交量加权的平均线；**度量起点通常选"对股价有重大影响的事件日"**（如财报日）。

**② 回踩时有止跌反弹的 K 线形态**：**Bullish Pin Bar / Bullish Engulfing / One White Soldier**。

> **补充（很实用）**：**很多时候不是清晰的 K 线反转，而是在支撑区间附近做短时间的紧密盘整** → **这也是可以关注、甚至考虑入场的机会。**

**③ 最好有成交量配合**（放量 + bullish K 线）——**但不是必须**。

### 入场点与止损（两种情况）

| 情况 | 入场 | 止损 |
|---|---|---|
| **回踩时出现 K 线反转** | **在之前那根 K 线的高点入场** | **之前低点 + 一点缓冲** |
| **——如果阳烛烛身太长** | **趁股价拉回到大阳烛 day range 之内、再度靠近 key level 时入场**；**如果没拉回，他大多会放弃这笔交易** | 同上 |
| **回踩时做紧密盘整** | **用突破的思路：股价突破盘整区间时入场** | **盘整区间底部 + 一点缓冲** |

**⚠️ 共同约束**：**入场点到止损点的距离，最好不要超过股价的 ADR。**

### 例子

- **成功**：**OKLO**（Key Level = 支撑位 + 10MA/20MA + Volume Profile POC + VWAP）、
  **First Solar**（支撑位 + 10MA/20MA + Fib 0.5–0.618）、
  **TEM**（支撑位 + MA + VWAP；但股价波动大，9 月下旬剧烈回撤）、
  **HOOD**（One White Soldier 形态，阳烛高点入场，前低点下加缓冲 → **约 4:1 回报风险比**）、
  **CEG**（回踩后无反转形态，做几天紧密盘整 → 突破盘整区间入场，止损放前低点；**因为加缓冲会超过 ADR，所以直接放前低点**）；
- **反面**：**RBLX**——**位置过度延伸、还没充分回调或盘整消化 → Simple Pullback 效果大打折扣**（回踩后反弹明显较弱，周五大幅 gap down）。

### 三点补充（很重要）

1. **Simple Pullback 也是趋势交易** → **最好在大盘和个股处于上升区间时使用；逆势操作多数会失败**；
2. **回撤最好是有秩序的**（下跌温和、**成交量不激增**）；**猛烈的回撤可能代表突破失败 / 假突破**；
3. **股价处于过度延伸时，Simple Pullback 成功率降低**——因为过度延伸时，股价倾向做**较深度的回调或较长时间的盘整** → **Simple Pullback 更容易发展成 Complex Pullback**。
   > **→ 所以 Simple Pullback 最好用在"一个波段开始时的早期"，成功率更高。**

## 8.3 Complex Pullback（多段回撤）

**来源**：同样是 **Adam Grimes《The Art and Science of Technical Analysis》**。

**他对两本书的对比（很有意思）：**

> **"Mark Minervini 的《超级绩效》读起来很爽，感觉技术分析交易是一件不难、我也行的事情；**
> **Adam Grimes 这本读起来像一本教科书……他讲得非常全面、很细致，读起来会比较累一点。"**
> （他还说：**不推荐中译本，"他的翻译真的有够烂"**。）

### 形态特征（四条）

1. **通常有 2 只脚或 3 只脚**（**很少有超过 3 只脚的**）；
2. **趋势要保持向上**——**150MA 向上，股价基本在 150MA 之上**；
3. **短线呈现 lower high / lower low 的下降趋势**；
4. **回撤深度至少到 50 日线**；**大多数会回撤到 50 日线以下，甚至到 150 日线或 200 日线**。

**例子**：Microsoft（2023/7–10，两只脚）、Amazon（2023/9–10，回撤到 150 日线）、
**Google**（2020/9–2021/1，**两次多段回撤**：左边急促、跌到 150 日线；右边三段回撤、**动能轻很多、只在 50 日线**、**三只脚基本没有一只比一只低，更像短期横盘盘整** → **有明显买方力量支持** → 后面走势明显强很多）、Meta。

### 入场思路（三种）

**思路 A：第二只脚跌稳 + 出现反转 K 线**

**反转 K 线**：**One White Soldier / Bullish Engulfing / Hammer（Bullish Pin Bar）**。

- **入场点 = 上升 K 线的顶部**（挂买入限价单）；
- **止损 = 第二段回撤的底部 + 一点缓冲**。

**辅助判断（怎么知道不会有第三只脚）**：

> **"我们无法提前预见接下来走势会否回撤完毕，还是继续回撤。我们只能加入一些辅助的判断条件，去提升胜率和入场信心。"**

**看第二只脚有没有回撤到潜在支撑位置**：

| 支撑 | 说明 |
|---|---|
| **MA 线** | **通常 150MA 和 200MA 的支撑力度相对更大** |
| **关键支撑阻力位置** | —— |
| **Fibonacci 0.5 / 0.618** | —— |
| **趋势线** | ⚠️ **"那么多支撑阻力的指标中，个人认为力度最弱的就是趋势线"** |

**例子（Apple 2021/9–10）**：**多个潜在支撑汇聚** + **底部出现 One White Soldier**。

**思路 B：突破下降趋势线后才入场（更保守）**

> **"牺牲一定的潜在上升空间，来换取较为明确的入场位置。"**

- 等股价**突破短期下降趋势线后、拉回到趋势线附近并出现反转 K 线**时买入；
- 或**突破下降趋势线后出现紧密盘整，突破盘整区间时入场**。

**他的洞察**：

> **"其实这两个形态不就是头肩底形态和杯柄形态吗？许多交易形态名字不同，但万变不离其宗，背后的逻辑都是相通的。"**

**例子**：**Broadcom**（2024/3–6，三段回撤后突破下降趋势线，回踩时入场）、**NVDA**（2024/3–5，两段回撤，突破趋势线后做紧密盘整，突破盘整区间时入场）。

**思路 C：第二只脚底部出现 higher low + 盘整酝酿突破时入场**

> **"好处是骨架呈现较明确的停止下跌特征，同时骨架还处于价格较低的位置，不需要牺牲太多上升空间。"**

- **如果盘整能在 20MA 或 50MA 之上，则更有机会回撤完成、即将重拾上升**；
- **"如果你熟悉 VCP 的话，这个形态其实就是 VCP 的 Low Cheat。"**

**例子**：**CRM**（2017/9–10，第二段回撤立即做紧密盘整、贴着 50MA；上方有下降趋势线阻挡，**但趋势线是力度最弱的**）→ **突破紧密盘整区间时入场**；
**ASML**（2024/3–5，两段回撤后紧密盘整、在 20MA 和 50MA 之上、突破趋势线时入场）。

### 离场思路

**他的观察**：

> **"我对自己的交易记录做过一个比较全面的分析，发现我赚钱最多的交易，往往都是持仓最久的交易。"**

**所以他的目标是"提升持仓能力"**。做法是**分段获利**：

- 设不同获利目标 → 到达时卖出部分 → **把止损上移到买入点**；
- **好处**：让交易不输钱、控制曝险、**获得心理优势、持仓更稳**；
- **坏处**：**最大回报受限**（已经获利了部分仓位）。

**获利参考位置**：

1. **前面的高点**（前高附近通常遇到阻力）→ 部分获利 + **止损上移到买入点（确保必定赚钱）**；
2. **Fibonacci Projection**（从高点拉线到 Complex Pullback 低点）：**1.5 / 1.618 / 2**；
3. **以前一段升幅作为参考**（例：Apple 前一段涨 29% → 期待从回撤低点也涨约 29%）；
4. **移动止损**：**当收盘价跌破 20MA 或 50MA 时离场**。
   - **⚠️ 他强调**：**"我是在首次部分获利之后（比如在前高锁定了部分利润之后），才会执行这样的移动止损。"**
   - **理由**：**"刚回撤完，股价未必会立刻具备动能向上上升，多数情况还是稍微上下波动一下、或者稍作盘整。此时股价收盘跌穿 20MA 是比较常见的，若此时就用移动止损，会很容易被打到、导致过早离场。"**

### 他的四条心得

**① 季节性**：他的 Complex Pullback 例子**主要集中在 3 月和 9 月**
——**因为从季节性看，3 月、9 月很大几率股市进入调整期**。
标普 500 的季节性：**3 月、5–6 月、8 月、9–10 月**都可能是盘整期。

**⚠️ 例外**：**如果大盘非常超买、一路破顶、极度过度延伸（狂牛）→ 不太适合交易 Complex Pullback**。
**理由**：**"当大盘极度过度延伸、随时可能进入调整时，若个股已经出现了 Complex Pullback 的形态，则代表这只股票很可能因为太弱而早就开始下跌，那后续还可能跟随大盘调整而跌得更多。"**

**② 适合的标的**：**市场焦点、但市值大、动能欠佳的大型股，或焦点行业 ETF**。
**"主要科技类为主"**（Mag7、半导体 ETF、AI 相关 ETF、软件股 ETF；也有银行、国防航天军工、基础工业 ETF）。

- **"特别声明：以上不是股票或 ETF 的推荐，这些只是我时常关注的清单而已。"**
- **⚠️ 不适合**：**二三线小盘股**（更适合牛市做突破；**基本面参差，用低买策略买到"升不起来的垃圾股"的概率增加**）；
- **⚠️ 也要避免**：**没有市场关注的股票或 ETF**（**"基本上所有看涨的交易策略，都应该尽量避免交易没有市场关心的标的"**）。

**③ 低买带来价格优势 → 心理优势 → 更容易持仓久**
> **"美股长期趋势向上、牛市长熊市短，那么你买入点较低有优势，去增加持仓时间，就更有机会捕捉到更大的潜在行情。"**

**④ 利用"多均线汇聚 → 扩张"的特性辅助判断入场点**
多条 MA（10/20/50/150）在回撤时从**扩散 → 汇聚 → 相互穿插交错**；
**当多条 MA 开始再次呈现扩散趋势时，就留意有无合适入场机会**。

**例子**：**SOXX**（2024/3/13 MA 开始汇聚 → 4 月底相互穿插、此时已是第二脚 → 5/7–5/8 MA 开始扩散 → **5/9 的回踩是好的入场时机**）。

### 总结

| 项 | 内容 |
|---|---|
| **形态** | 2–3 只脚；150MA 向上；短线 lower high/lower low；**回撤至少到 50MA**（多数到 150/200MA） |
| **适用** | **大盘调整的尾声**；聚焦**大型科技旗舰股 + 焦点行业 ETF** |
| **入场** | 第二段回撤之后——**K 线反转 + 支撑位** / 或**突破下降趋势线** / 或**底部短期盘整突破** |
| **离场** | **分段获利**（前高 / Fib / 前一段升幅）；或**首次获利后等收盘跌破 20MA/50MA** |

## 8.4 三段式沽空（做空）

**⚠️ 他放在最前面的风险声明：**

> **"做空交易属于高风险操作。你不仅有可能输光本金，更有可能让你的亏损无上限。"**

### 为什么做空危险（他解释得很清楚）

| | 结果 |
|---|---|
| **做多** | 股票从 100 跌到 0 → **你只是输光筹码（−100%）** |
| **做空** | 股票从 100 涨到 300 → **你亏 200%，而且理论上可以无限大** |

**例子**：**2021 年 1 月 GME 史诗级轧空**。

**做空的第一优先级：风险控制** —— 最关键的一环是**"你要确保你想跑的时候可以跑得掉"**：

- **中小型股票流通性差、市值低** → 经常因突发消息暴涨（单日 +30%/50% 甚至翻倍）；
- **例子**：**BB（市值约 21 亿美金）在 GME 事件中出现 17%–39% 的裂口高开** → **你的止损单根本成交不了**；
- **第二个问题：滑点（Slippage）** —— 流通性不足的标的买卖价差本身就很宽，大幅波动时价差可以扩大到非常离谱 → **本来计划亏一点就跑，结果因滑点亏损被放大好几倍**。

> **他的一句话总结**：
> **"做空一定要选大象，不要去招惹猴子。大象动作慢，你来得及跑；猴子上窜下跳，你根本控制不了。"**

### 适合做空的大环境（两种）

1. **大盘不再是强势上涨，出现疑似见顶迹象**（指数高位反复冲高但冲不上去 / 领涨权重股一支一支崩坏 / 重大利空消息让市场瞬间变脸）；
2. **大盘已明确进入下降趋势**（均线空头排列、一波比一波低）→ **做空更顺风顺水**。

### 适合做空的标的（**红线**）

- **指数 ETF**（SPY / QQQ / IWM）；
- **板块和行业 ETF**（XLF / XLE / SOXX）；
- **大型股票**（**市值至少几百亿美金以上**）；
- **高流通性期货**（外汇、贵金属、美债、期货）。

> **🚫 红线**：**绝对不可以拿这套策略去做空低流通性或中小市值的个股。**

### 核心观察：为什么"要趁早"

> **"美股下跌有一个特性，跟做多正好相反：做多时股票通常慢慢涨、一步一步往上爬（像爬楼梯）；**
> **但下跌时，初期往往来得非常猛烈——就像石头从高处落下，有地心引力效应。"**
>
> **"一鼓作气，再而衰，三而竭——第一波跌得很猛很快，第二波跌势开始减弱，到第三波动能基本消耗得差不多了。"**
>
> **→ 所以做空有一条很重要的规则：要趁早。越早抓住下跌趋势，盈亏比越好。等跌了一大段再去追空，风险反而更高。**

### 三段

| 段 | 针对 | 特征 | 盈亏比 / 胜率 |
|---|---|---|---|
| **首段** | **Parabolic Run 或 Three Pushes** | **抛物线式加速上涨**（角度越来越陡，最后接近直线）；或**大波幅抖动向上**（反映大户在高位散货） | **盈亏比最好**（转势早期介入，下方空间大、入场点离止损近）；**但难度最高**（要判断转势是否真的成立） |
| **中段** | **确认转势后顺势而为** | **日线出现明确反转信号**（一根或连续几根非常 bearish 的 K 线 + 巨大成交量）；**跌破重要均线 / 关键支撑 / 明显更低的高点** | **胜率更高**（趋势已确认，不需要太多预判）；**盈亏比稍差**（已跌了第一波）→ **胜率与盈亏比比较均衡** |
| **尾段** | **这一轮下跌的最后一段** | 股价可能又做了一些盘整，看似酝酿再次下跌；**社交媒体上开始出现越来越多讨论做空的声音** | **⚠️ 盈亏比开始变差**（已跌一大段、接近超卖或关键支撑）→ **经验丰富的交易者在这个阶段反而开始关注"潜在短期反弹"** |

### 首段的操作（三步）

1. **观察大环境**：**当大盘开始转弱时**，观察哪些标的之前出现过 Parabolic Run 或 Three Pushes；
   > **"大盘强的时候，这些疯涨的标的可能还能维持；但大盘一旦转弱，它们往往是跌得最惨的。"**
2. **切到较小时间框架**（他看 **1 小时或 30 分钟图**）**捕捉第一根高成交量反转 K 线**：
   **一根带着明显放大成交量的阴线，实体比较长，最好是吃掉了之前前几根阳线的涨幅。**
3. **⚠️ 不是看到反转 K 线就马上冲进去**：
   > **等波幅收缩，或等它出现一个小幅度反弹，然后在反弹到合适的阻力位置时才入场沽空。**
   > **好处：止损可以设得更近，风险更小，盈亏比更好。**

### 中段的操作

**不是马上追，等 "Spike and Ledge"（暴跌后横盘）形态**：

- **Spike** = 猛烈下跌（像一根钉子往下钉）；
- **Ledge** = 暴跌后小范围横向盘整、波幅收缩；
- **本质**：市场消化之前跌幅、多空拉锯；**但大趋势已向下 → 这种盘整之后大概率还会再向下突破**。

**入场方法（两种，很实用）**：

| 方法 | 做法 | 好处 |
|---|---|---|
| **① 回测入场法** | **等股价反弹到上方短期主力位置时入场做空**（把"回撤做多"的逻辑反转过来） | **入场价格离止损近，盈亏比好**（传统的"突破做空"入场点容易离下方支撑很近，盈亏比不理想） |
| **② 突破偷入法** | **股票做紧密盘整时，在盘整区间的上沿（靠近上方主力区间）入场做空** | **在靠近主力位的地方做空，止损空间最小化** |

### 止损

- **统一用"上方短期主力位的高点"或"紧密盘整区间的上沿主力位"作为基准**；
- **⚠️ 加缓冲**：**0.5 到 1 倍 ATR**；
  - **理由**：**"市场有时候会稍微突破一点主力位再掉下来（假突破 / 刺穿）。如果止损设得太贴近主力位置，可能会被这种正常的噪音扫出去。"**
- **⚠️ 反过来看盈亏比**：
  > **"设好止损之后，算一算从入场价到止损价的距离，再看看从入场价到潜在目标位的距离。**
  > **如果盈亏比做不到 2:1 或以上，我个人会放弃这笔交易。"**
  > **"做空本来就是逆风操作，盈亏比不够好的交易，风险和回报不匹配，长期下来是会亏钱的。"**

### 止盈

- **首段和中段**：**分段获利**（第一个目标平一半，剩下的继续跑，第二个目标再平一部分）；
- **尾段**：**固定盈亏比**（比如 2:1，**到价立刻止盈，干脆利落，不要留恋**）。

### 提前离场（三种）

1. **个股出现突兀的上涨走势**（不正常的、非常突然的放量上涨）→ **可能有利好消息或大资金进场接盘 → 先走为上**；
2. **入场后 5 天以上股价没有明显下跌** → **入场时机可能不对 → 先出场观望**；
3. **大盘或所在行业出现集体好转迹象** → **做空最怕系统性反转 → 考虑离场或至少减仓**。

### 仓位控制（很关键）

> **"我对沽空交易的定位是四个字：Hit and Run（闪电游击战）。进去打了就跑，不要恋战。"**
> **"在我的整个交易体系里，做空策略只是配菜，不是主菜。"**

**原因**：① 美股长期趋势向上，做空是逆风操作；② 做空本身"盈有限输无限"的结构决定它不适合重仓。

**他的做法**：

> **"我很少很少用足一个 R 来下注，通常我只会用 0.5 个 R 来做空。"**
> **"如果做多我可能愿意下 1 万块钱的风险，那么对于做空我只愿意下 5000——把风险降到一半。"**
> **"做空赚到的是零花钱，但重要的是不能让做空亏掉了你的生活费。"**

### 例子（黄金期货，三段完整演示）

| 段 | 过程 |
|---|---|
| **首段** | Parabolic Run（最后几根 K 线接近 90 度向上）→ 等 → **一根实体很大的 K 线 + 成交量放大** → 1 小时图看到**巨量下跌 K 线 → 反弹（反弹时成交量收缩）→ 反弹到 Fib 0.618 附近、也刚好是 21EMA 附近遇到阻力** → **入场沽空** → **在 20EMA 附近部分获利，接近 200EMA 时全部离场** |
| **中段** | 3 月再次出现向下异动（长下跌 K 线 + 成交量放大）→ 之后几天**紧密盘整，一直沿 Fib 0.5 附近整理但始终突破不了** → **趁股价靠近 Fib 0.5 时入场沽空**（**"其实由于盘整比较充足、区间十分窄，在突破短期上升趋势线的时候入场沽空也是一个 OK 的方式"**）→ **在 200 日线有明显支撑时全部离场** |
| **尾段** | 等价格拉回到**汇聚支撑主力线和 50EMA 的 Key Level 附近** → 看到**价格拒绝（上方有压力）** → 第二天价格靠近上方压力时做尾段沽空 → **设定 2:1 盈亏比，计划到价离场** → 但几天后出现**突兀走势**（原本往下崩，盘中突然抽升，走出还挺 bullish 的 pin bar，显示下方有支撑）→ **因为来到尾段，他格外谨慎，趁还有些许利润就平仓离场** |

> **"可以看到来到尾段，无论是成功率还是赔率，都变得大大的不如之前了。"**

# 九、Timeframe 与多重周期

## 核心概念

> **"你可以把市场想象成一个俄罗斯套娃的结构：大 Timeframe 中的趋势，是由 Lower Timeframe 的走势堆叠出来的。"**
> **"Timeframe 越低，越像显微镜——看细节、看入场点；Timeframe 越高，越像望远镜——看大局、看宏观趋势。"**

## Timeframe 与交易风格

| Timeframe | 风格 | 关注 |
|---|---|---|
| **1 小时以内** | **Day Trading** | **小周期考验的是：对主力（Smart Money）行径的判断、进出场的精准操作、对高频压力的承受能力** |
| **小时 → 日线** | **Swing Trade**（大多数散户） | 以日线看形态，有时结合周线看趋势，在 1 或 2 小时图找入场点 |
| **日线以上** | **Position Trade** | 主要看日线和周线，交易周期以月计算 |

## 不同 Timeframe 的"节奏"

- **Lower Timeframe**（1/5 分钟）：**杂讯极大**，充满高频交易算法和做市商的扫单行为；
  **"看起来像是突破了，下一秒可能就是假动作。"**
- **Higher Timeframe**（日线/周线）：**惯性极大，像一艘巨大邮轮**，一旦形成趋势很难马上掉头；
  **信号更可靠、杂讯更少**，但**考验你对趋势的研判、耐心和纪律**。

## 不同 Timeframe 的策略

**Lower（现在流行 SMC）**：
**Smart Money Concepts** 注重**"在回撤打穿了之前追入者的止损之后（Liquidity Grab / 扫单），再继续往原先方向走"**。

**他的评价**：
> **"我觉得 SMC 的大框架更像是突破后的回撤交易。"**
> **"网上很多交易者用 SMC 都能做到长期 profitable，我也认为 SMC 对主力扫单的判断是很合理的——只是我个人比较不习惯它的节奏，波动太快，因为我很少会长时间坐在电脑前盯盘。"**

**Higher（总结起来就两种）**：
**突破交易和回撤交易**——**一个追逐动能，一个追逐好的盈亏比**。
> **"就像在森林里的猎人，我们要做的就是等待猎物出现上钩，需要我们有好的耐心和纪律。"**

## 学习效率的差异（很有意思）

> **"Lower Timeframe 的 Day Trading 虽然密度高、比较辛苦，但它累积经验的速度快——因为周期短，一天可以交易许多单。**
> **就像天天花很多时间玩 Online Game 打怪的玩家，比每天只在下班后上线玩一两个小时的玩家，升等速度快很多。"**
> **"Position Trading 虽然不用经常盯盘，但交易周期较长，从经验累积效率的角度看，确实没有 Day Trading 那么快。"**

## ⚠️ 新手最常犯的错（这条最重要）

> **"用 Lower Timeframe 的仓位来做 Higher Timeframe 的交易，导致过度曝险甚至爆仓；**
> **或者用 Higher Timeframe 的时间节奏来做 Lower Timeframe 的交易，导致弄错最佳的获利时机。"**

## 你的"主场" Timeframe 由四个因素决定

1. **你所学习并擅长的策略**（**"当你能较稳定获利，这个策略所在的 Timeframe 就是你的主场"**）；
2. **你的时间**（**"如果你有一份忙碌的全职工作，每天朝九晚六偶尔还有加班，那么 Day Trading 未必适合你"**）；
3. **你的心理承受压力**（**"如果一天出现连输的情况，心理上能否真正接受得了？否则心理上的 Breakdown 对交易者来说绝对是致命的打击"**）；
4. **你对交易的定位及目标**。

## 多重周期分析法（Top-Down）

> **"交易的世界里有一条黄金法则：永远不要逆着大周期的趋势去操作小周期。"**

**三步（以日线为主的 Swing Trade 为例）**：

1. **大周期看趋势**（周线：价格在 30 周线以上且上升趋势 → **"这个时候你的脑子里只能有买入这个选项"**）；
2. **中周期找形态**（日线：紧密盘整，价格接近 10/20/50 天均线汇聚位置）；
3. **小周期找入场点**（1 小时图：回测中出现 bullish pin bar / bullish engulfing，或突破盘整区间时入场）。

**他补充**：**"操作上不一定要死板地先看大周期，也可以是中周期发现形态 → 跳到大周期做趋势确认 → 最后到小周期找精准入场点。"**

**例子**：**POWL**（日线：中间位置紧密盘整、类似 VCP Low Cheat，已突破 → 周线：30 周线之上、明显上升趋势 → 1 小时：回测区间时有确认反弹的 bullish K 线 → **在这根 K 线高点设买单，以回测时低点为止损参考** → 成功突破）。

# 十、技术指标（他每天用的 8 个）

> **来源**：`[技術指標] 我每天只看這 8 個技術指標就夠了`
>
> **他的前提（放最前面）**：**"指標沒有好和壞，只有適不適合"**——**所有指标都必须服务你的交易风格。**
>
> 他的风格三句话：**日线图 / Swing（几天到几周）/ 两大策略（紧密盘整突破 + 上升趋势回撤）**。
> 因此他用指标只回答三个问题：**趋势对不对 / 位置好不好 / 动能够不够**。

## 10.1 四层框架（这是他"挑指标"的方式，比指标本身重要）

| 层 | 回答 | 用什么 |
|---|---|---|
| **趋势层** | 趋势对不对 | 移动平均线 |
| **支撑阻力层** | 位置好不好 | MA + Fib + Anchored VWAP + Volume Profile → **Key Level** |
| **波幅层** | 值不值得做 | **ADR%** |
| **动能层** | 动能够不够 | KDJ / MACD / RSI（**按速度分工**） |

## 10.2 移动平均线（一个指标，两个身份）

**身份一：趋势**

- **10MA 之上 = 极强**；**20MA = 短线强势**；**50MA = Swing 安全区**；**200MA = 牛熊分界线**；
- **多头排列** 10 > 20 > 50 > 200 → 做多成功率较高；
- **他的个人偏好**：中短线用 **EMA**（10/20/50，对价格更敏感）；**长线用 SMA**（长趋势不需要那么敏感）。

**身份二：动态支撑阻力**

- 理由：MA = 过去 N 天的**平均成本**；回踩 = 回到大家的平均买入价 → 自然引发买盘；
- **10/20 EMA = 强势股最敏感的支撑线**；
- **50 EMA = Swing 的生命线**（站不稳 = 短期趋势终结）；
- **200MA = 长线底线**（深度回撤时的支撑）。

## 10.3 Fibonacci Retracement

- 他看三个位置：**0.382**（强势股回档极限）/ **0.5**（标准回档 / 黄金平衡）/ **0.618**（深度回档、**多头最后防线**——破了要警惕趋势扭转）；
- **锚点必须是有意义的波段高低点**（不是随便拉的）；
- ⚠️ **单独用准确率有限，必须和其他指标共振**。

## 10.4 Anchored VWAP

- 和 MA 的差别：**它把成交量算进去**——"10 万股成交的那一天，和 100 万股成交的那一天，对市场的意义完全不同"；
- 它回答的是：**从锚点那天到今天，所有买进这只股票的人的平均成本**；
- **锚点三个标准**：① **突破日**（放量突破盘整区间那天）→ 成为多空生死线；② **重大催化日**（财报 / 重大消息；例：2024/11/6 Trump 当选 → 比特币）；③ **前波段的高点或低点**。

## 10.5 Volume Profile

- 把成交量翻 90 度：横轴变成交量、纵轴变价格 → **从"时间维度"变成"价格维度"**；
- **POC（Point of Control）= 成交量最密集的价位 = 市场最强的磁铁**（股价远离后容易被吸回，并在那里获得支撑 / 阻力）；
- 两种：**Visible Range**（跟图表缩放同步）/ **Fixed Range**（框住你关心的那一段）。

> **Key Level 的定义**：当 **MA + Fib + Anchored VWAP + Volume Profile 同时指向同一个价位带** → 那就是 Key Level（市场在**资金、时间**两个维度都认同的位置）。

## 10.6 ADR%（Average Daily Range Percentage）—— 他认为最被忽略的一个

**算法**：过去 20 天，每天 `(最高 − 最低) / 收盘`，再取平均。

**三个用法**：

| 用法 | 规则 |
|---|---|
| **① 选股过滤器** | **< 2.5% → 直接排除**（波幅太低，不值得做动能）；**2.5–5% → 可做但控仓**；**> 5% → 最佳**（高动能） |
| **② 止损距离** | **控制在 1–1.5 倍 ADR 之内**——给波幅一个"正常呼吸空间"（太紧会被日常波动扫出，太松影响仓位和盈亏比） |
| **③ 部分止盈目标** | **至少 2–3 倍 ADR**，确保盈亏比 ≥ 2:1 |

**进阶用法**：**判断盘整是否够紧**——ADR% 从 5% 收缩到 2% = **波动收敛、能量累积 → 突破前兆**；把回溯期设成 3 天会更敏感。
（TradingView 没有原生 ADR%，他用 TheSkruinist 那个。）

## 10.7 动能三件套：按"速度"分工，不是重复

| 指标 | 反应速度 | 他的角色 |
|---|---|---|
| **KDJ** | **最快** | **前哨站** |
| **RSI** | **适中** | **核心仪表板** |
| **MACD** | **最慢** | **确认** |

**KDJ**：只看 K / D 的**金叉死叉**——低位金叉 = 动能恢复；高位金叉（且两者都 > 50）= 续涨讯号；高位死叉 = 转弱。
⚠️ **最大的坑是"钝化"**：强趋势里 KDJ 会黏在 80 以上下不来，**别用它做超买超卖反向操作**——**他只把"KDJ 钝化"当成"强势的证明"**。

**MACD**：三个里最滞后（两重平滑），**所以别用它"金叉买、死叉卖"**；他只用来**辅助确认**（快慢线金叉 + Histogram 为正 = 动能确认）。

## 10.8 RSI（他研究最深的一个）

**定义**：14 天多空力道的积分表（0–100）。

**最被低估的特性：指数化 / 标准化**

- 例：SNDK 单日涨 **8.25%** 和 FTNT 涨 **2.35%**，RSI 的**单日变化都是 ≈ 4.3**——说明 SNDK 的 8.25% ≈ FTNT 的 2.35% 的动力；
- **→ 所以 RSI 可以把不同波动率的股票放到同一把尺子上做横向比较**（跨股票、跨行业、跨市场）。

**他的四大用法**：

| # | 用法 | 细节 |
|---|---|---|
| **①** | **超买超卖** | **> 75** 警惕回档、**< 25** 警惕反弹；**⚠️ 但强趋势里 RSI 80/90 还会继续涨——别赌反转**。他的区分：**"赌反转"是 trade what you think；"做好反转的准备"是 trade what you see。** |
| **②** | **RSI > 50 = 突破交易的核心确认讯号** | 紧密盘整 + RSI 站上 50 = **双重确认**（光看紧密盘整不够——假突破太多）；跌破 50 = 短期行情可能结束或进入修整 |
| **③** | **背离** | 顶背离 = 价创新高、RSI 没创新高 → **动能衰减，但不代表立刻反转**（例：QQQ 顶背离后又横盘 **5 个月**才真正扭转） |
| **④** | **记录 1 / 5 / 20 日 RSI 变化 → 追踪行业与个股的动能轮动**（他的"个性用法"） | 可衍生 **RSI Score**（三个变化加权加总）、**Z-score**（变化是否显著）、**加速度**（有没有在减速）；也可以只做"谁最强 / 最弱"的排行榜，标出新上榜的 |

> **他的总结**：**RSI 不只是动能指标，它是一个"动能和资金流向的监测系统"**——**"當你能看到動能和資金流向，你的選股就不再是靠猜，而是變成一種順勢而為。"**

# 十一、选股机制

## 11.1 先定义 watchlist 的目的，再决定筛什么

**他的三种 watchlist**（另一集里给的是 5 个）：

| 名单 | 装什么 | 用来做什么 |
|---|---|---|
| **动力股名单** | 动力超前 + 有入场 setup 的股票 | **突破交易** |
| **常规名单** | Mag7、重要科技股、各板块权重股 | **回撤交易** + 观测大盘（SA） |
| **热门主题名单** | 近一个月到一季度的热门主题股 | 混合策略 |

**5 个 watchlist 版**：板块 ETF（11 个板块 + ARKK + SPY）／行业 ETF（约 **60** 个）／主题 ETF（**20** 个，围绕 AI 和加密货币）／重要权重股（每个板块 ETF 的前十大权重股）／热门主题股。

> **他的核心**：**"價格通常先於消息"**（散户收到消息时早已 price in）——所以**最有效的市场传感器是价格**。
> 索罗斯：**"Invest first, investigate later."**

## 11.2 Top-down vs Bottom-up

| | **Top-down** | **Bottom-up** |
|---|---|---|
| **逻辑** | 先选强动能板块 / 行业 → 再在里面选个股 | 先按形态 / 指标选个股 → 再对比是否强于行业和大盘 |
| **好处** | **确定性较高** | 可能**更早**抓到领导股，潜在涨幅更大 |
| **坏处** | 板块已经涨很多时，选出来的是**落后股**（强弩之末） | **精度低、数量多、难精选** |

**他的做法**：**主用 top-down；用 bottom-up 的"强于大盘"当精选准则。**

## 11.3 免费工具：判断"领先行业"

**Finviz**（他设的 7 个条件）：市值 > **$2B**、股价 > **$5**、在 **200 / 50 / 20MA 之上**、**RSI > 50**、**Beta > 1**。

- 用法：**group → industry**，按 1 天 / 1 周 / 1 月 / 3 月排序；
- **他主要看 1 个月和 3 个月，取前 20–25 名**（一天的排名只作参考）。

**TradingView Screener**（他的条件）：价 > $5、市值 > $2B、Beta(5 年) > 1、**ADR% > 2.5%**、RSI > 50、**30 日均量 > 20 万股**、价 > 20/150/200MA、剔除 OTC、**剔除生物科技 / 药物 / 必需消费**。

- **结果数量**：**200–300 只最舒服；超过 400 只就太耗精力**（他会加条件压下来）；
- 技巧：把 **industry 列拖到最前面**。

## 11.4 收费工具（他实际在用的）

| 工具 | 他最看重的 | 备注 |
|---|---|---|
| **Deepvue** | **RS（相对强度）有 1 / 3 / 6 / 12 个月四个回溯期**；同时显示**所处行业的相对强度**；有基本面（EPS 预期、销售增长）+ 企业简介 | **他更推荐用 DV 选股**；⚠️ 目前**关闭新用户注册**（waitlist） |
| **StockCharts** | **Watchlist 管理最强**（可建很多清单、自动每日发送 RS 排行）；自有动能指标 **SCTR** | scan 要写代码、看图表要一张张点；基本版 ≈ **$18.42/月**，extra ≈ **$27.65/月**（年订） |
| **MarketSurge（原 MarketSmith）** | **RS Rating 的源头**（如 VRTX 的 RS = 95 = 强过 95% 的股票） | **贵**（⚠️ 注意：这个 RS ≠ RSI） |

**他常用的两个 Deepvue 预设指标**（TradingView 上也有人写过）：

- **DV Relative Measured Volatility（RMV）**：线跌到蓝 / 绿区 = **波幅收缩得很窄**（配合图表用于找突破入场点）；
- **ATR% multiple from 50MA**：股价离 50MA 超过 **10 倍 ATR** → 标星号 = **过度延伸**（突破交易要避免）。

**他的 Deepvue 筛选（示范）**：交易所 = NYSE/NASDAQ、**RS(1M) > 90**（另做 3 / 6 / 12 月）、**ADR(20) > 2.5%**、价 > $5、剔除生物科技 / 药物、价 > 21EMA、非 ETF/ETN、价 > 150MA & 200MA、市值 > $2B、50 日均量 > 20 万股。

## 11.5 ⭐ 用 RSI 筛"紧密盘整"（这两集最实用，可以直接抄）

**核心思路**：**用 RSI 的"指数化"特性，去找"最近几天 RSI 几乎没动"的股票**——RSI 原地踏步 = 股价原地踏步 = **紧密盘整（Tight Flag / VCP 的雏形）**。

**StockCharts ASW 版（5 个条件）**：

| # | 条件 |
|---|---|
| **1** | 最近 **3–4 天** RSI 每日变化 **< 3**，且**累计变化 ≤ 5** |
| **2** | 股价**贴近** 10EMA / 20EMA / 50EMA / 150SMA / 200SMA **中任一条**（误差 ≤ **1 个 ATR**） |
| **3** | 过去 **150 或 260** 个交易日，从最低点**涨 > 30–50%**（强势股的休息，不是弱势股苟延残喘） |
| **4** | **ATR / 收盘价 > 2.5%**（要有波幅的股票） |
| **5** | **RSI > 50**（或 > 45：更早发现、噪音更多） |

**+ 过滤层**：必须是个股（非 ETF）、限 NYSE/NASDAQ、美国、**市值 > $1B**、**50 日均成交额 > $1000 万**、剔除生物科技 / 制药 / 必需消费。

**TradingView Pine Screener 版（放宽版）**：盘整天数 **4 → 3**、涨幅 **30–50% → 25%**、RSI **50 → 47**。

**为什么放宽**：**Pine Screener 不能全量筛，只能筛你自己的 Watchlist**——而 Watchlist 已经过基本面 / 叙事筛选，技术面可以放松一点。

**他的看图评级（很实用）**：

| 评级 | 特征 |
|---|---|
| **A** | 近期**放量上涨** + **回撤有秩序（轻微）** + 在 **10/20MA 附近紧密盘整** + 有叙事催化 |
| **A− / B+** | 有一项不完美（盘整不够充足、涨幅略弱等） |
| **pass** | **过度延伸（超买）** / **像 short setup（受上方均线压制）** / **怪异 K 线（pin bar 交错）** / **低位盘整** / **200MA 仍向下**（落后股） |

> **他的自动化**：StockCharts 的 **schedule scan**——每天美股收盘后自动跑，结果自动替换进一个专门的 chart list + 发 email。**"每天筛完就自动收到。"**
