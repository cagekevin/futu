# 4 · 设计：在场机制说明书

> **定位**：机制设计 **+ 验证框架**，**不是投资建议**。
> **方法**：**每个选项，先验证、再决定**——不先填数字。
> **验证的三个轴**：**回撤 / 收益 / 心理成本**。
> **只有全部想透了，才回到"填"。**
>
> 配套阅读：《2-世界-视频整理.md》《3-认识-思维误区.md》。
>
> 一句话原则：
> **策略，是"你相信什么"；机制，是"你相不相信，都没关系"。**

## 总图：一共要设计 6 块

| 块 | 要设计什么 | 能不能回测 |
|---|---|---|
| **1 结构** | 钱怎么分（桶 / 平台 / 隔离） | 部分能 |
| **2 规则** | 买卖 / 再平衡 / **新钱 / 崩盘回场 / 退出条件** | **能**（部分） |
| **3 约束** | 仓位上限 / 杠杆 / 卫星上限 | **能** |
| **4 机制** | 自动化 / 看盘频率 / 预注册 / 记录 | **不能**（靠自查） |
| **5 买什么** | 具体工具（**放在最后决定**） | 部分能（比成本 / 比分散） |
| **6 检验** | 单点检验 / 定期复盘 | — |

**建议顺序**：**结构 → 规则 → 约束 → 机制 → 买什么 → 检验**。
（"买什么"放最后——**因为它是你圈子的住处**，见那一块。）

**核心是第 2 块（规则）**——它没定，第 3 块的"仓位"就没法定。

> **适用范围**：这份设计**只管你的美元投资资金**。
> 你的**人民币是日常开销**，和这笔钱无关——**不在这份设计里。**

## 前提：什么是"可设计"的，什么不是

**所有"块"本身，都是可设计的**（它们全是你的决定）。
**但真正的分界线，在每一块"里面"。**

| 设计块 | **可设计**（你定） | **不可设计**（市场 / 本能） |
|---|---|---|
| 结构 | 分桶比例、平台角色、隔离 | 它未来赚不赚 |
| 买入 | 何时买、多少、自动否 | 买完涨还是跌 |
| 卖出 | 什么条件卖 | 何时触发、触发后怎样 |
| 约束 | 仓位上限、杠杆 | 这个仓位会不会亏 |
| 机制 | 自动化、看盘频率 | 你会不会恐慌 |
| 买什么 | 选哪个工具 | 它未来收益多少 |
| 崩盘回场 | 把预案写下来 | 崩盘来不来、来多大 |

> **总原则**：**设计能定"你的动作"，定不了"结果"。**
> - **可设计的那一列** = **动作**（你完全说了算）；
> - **不可设计的那一列** = **结果**（市场说了算 + 你的本能说了算）。
>
> **设计的全部意义，就是把"动作"从"结果"里隔离出来。**

> **⚠️ 最要命的是**：**"不可设计"那一列，恰恰是你过去一直在试图设计的。**
> - 想设计**涨跌** → 择时；
> - 想设计**相信** → "等我相信"；
> - 想设计**扛住** → "我一定能扛"。
>
> **这三样，全在"不可设计"那一列——它们就是你一直在找的药。**

**一个补充**：有些东西**"可设计，但你不知道对不对"**——比如**仓位上限**：你能设，但不知道设得准不准（真实容忍度**未验证**）。所以"可设计" ≠ "能一次定对"，要靠**验证**。

## 第二块　规则：买卖条件（核心）

**先定标准：一个"系统"的最低要求，只有四项**——**写完就是系统，不需要精通任何理论。**

| # | 项 | 状态 |
|---|---|---|
| 1 | **入场条件**（可数） | ⬜ 待填 |
| 2 | **单笔风险**（一个 %） | ⬜ 待填 |
| 3 | **退出条件**（写死） | ⬜ 待填 |
| 4 | **总风险上限**（笔数 / 仓位 / 停手线） | ✅ **部分已定**（90 笔/年、$6,000、看盘规则） |

> **他缺的不是"学得深"，是"没写过"。**
> **系统的诞生不是"学完"，是"写完"——四项填完，系统就存在了。**

### 2.1　买入规则

**选项**：一次性买入 / 分批（定投）/ 自动定投。

- 分批买有 **62%** 的时候强过"一直拿现金"。

- **心理成本**：分批让你"敢进场、拿得住"（第 9 章斯塔特曼）。

### 2.2　卖出规则（**最核心**）

**选项**：永不卖 / 只在 X 条件下卖（止损 / 止盈 / 再平衡 / 定期）。

**怎么验证**：**回测**——不同卖出规则下的**最大回撤**和**长期收益**。

**代价**：

- **止损**：在随机游走里**期望 = 0**（不创造收益），只是把分布切成"小亏多、大赚少"；
- **永不卖**：没有"被止损"的痛苦，但要**承受完整回撤**（心理成本最高）；
- **再平衡卖出**：在收益和回撤之间做权衡。

**判据**：________

**⬛ 已定（2026-10）：拿住"可能翻倍"的股票——五个机制**

**前提**：**"吓人"是仓位的函数，不是股票的属性。** 同一只股票，5% 仓位不吓人，50% 仓位很吓人。
→ **解法不是"找不吓人的股票"，是"把仓位降到不吓人"。**

1. **仓位小到"回撤不痛"**（决定其他四条有没有用）

   | 单只仓位 | 若回撤 50% | 你会怎样 |
   |---|---|---|
   | 20% | −10% | 会想卖 |
   | 10% | −5% | 会犹豫 |
   | **5%** | **−2.5%** | **几乎无感** |

2. **用"趋势止损"，不用"固定止损"**——固定 −8% 在高波动股上**几乎必然被日常噪音打掉**（这正是他的老问题）。改成：**跌破长期均线（如 50 日）** 或 **从最高点回撤 X%**。代价：**回吐一部分利润**（从最高点回撤 20–25% 才走）。

3. **分批卖出**（最重要——它直接打断他的循环）
   > **翻倍 → 卖 1/3；再翻倍 → 再卖 1/3；剩下的用趋势止损。**
   > **它让你"永远有一部分在场上" → 所以你不会因为"卖早了"而痛苦 → 所以你不会追回去。**

4. **只看规则，不看盈亏**——周六看盘时**只核对规则**（有没有触发卖点 / 加仓点），**不看浮盈浮亏**。

5. **接受"回撤是拿住的一部分"**——拿住翻倍股，**必须接受中途 30–50% 的回撤**；而这个接受**不能靠心态，只能靠"仓位小 + 规则写死"**。

**⚠️ 必须配：分散 + 单只上限**——**因为事后知道的翻倍股，是"活下来的"**；你同时会持有"没翻倍、甚至归零的"。

### ⚠️ 关键修正：他原来的做法是"等金额"，不是"等风险"

**他原来的做法**：**所有股票一视同仁，每只买 $1,000。**

**直觉是对的**（不重仓单只、不偏袒）——**但要保留它，同时补一个变量：波动率。**

> **等金额 ≠ 等风险。**

**算给他看（同样 $1,000）：**

| 股票 | 止损距离 | **单笔风险** |
|---|---|---|
| 低波动 | 8% | **$80** |
| 高波动 | 25% | **$250** |

**——同样 $1,000，风险差 3 倍。**

**而如果他"一视同仁"都用 −8% 止损**：**高波动股上，8% 几乎必然被日常噪音打掉 → 他必然被震出。**

> **——这就是"波动大的票让我亏得更多"的完整机制：等金额 + 固定止损。**

**正确公式（固定风险，让仓位随波动变）：**

```
股数 = (账户 × 单笔风险%) ÷ 止损距离
```

**波动大 → 止损距离大 → 买少；波动小 → 买多。结果：每一笔的风险一样。**
**——这正是 Minervini 和海龟用的公式（同一个）。**

**所以修正后是两条叠加（不是替代）：**

1. **单只金额上限**（防"看好就重仓"）；
2. **单笔风险上限**（防"高波动股风险超标"）。

### 赔率（盈亏比）在本系统里怎么定

**先统一词**：**"赔率" = 盈亏比 = 平均赢 ÷ 平均输**，单位是 **R**。
**R 的定义**：`R = 止损距离`（一笔最多亏多少）。

**核心一句话：**

> **赔率不是"设计"出来的——它是"止损 + 出场规则"的副产品。**
> **你能设计的只有两件事：① 止损放哪；② 什么时候卖。**

**① 止损 → 决定"分母"**

```
R 倍数 = 涨幅 ÷ 止损距离
```

| 止损距离 | 股票涨 100% | R 倍数 |
|---|---|---|
| 10% | +100% | **10R** |
| 25% | +100% | **4R** |

**止损越紧 → 同样涨幅对应的 R 越大（赔率越高）；但被止损的概率也越高。**
→ **止损近 / 远，是在"赔率"和"胜率"之间交换，不是"赚多赚少"之间。**

**② 出场 → 决定"分子"**

| 出场方式 | 赔率 |
|---|---|
| 固定止盈（+2R 就走） | **锁死在 2R** |
| **移动止损（让利润奔跑）** | **不固定**——是分布：大部分 1–2R，**少数 10R+** |

→ **本系统选后者**（分批卖出 + 趋势止损）。

**③ 赔率和胜率是一对，不能单独看**

$$\text{期望} = p \times \text{赔率} - (1-p)$$

同样 +0.2 的期望：

- **p = 0.4，赔率 3**（低胜率、高赔率）；
- **p = 0.6，赔率 1.33**（高胜率、低赔率）。

→ **"我要高赔率"单独说是没有意义的。**

**④ 本系统的具体值**

| 项 | 设计 |
|---|---|
| **R** | = 止损距离 × 仓位 = **账户 × 单笔风险%**（**固定**，所以每笔风险一样） |
| **止损** | **趋势止损**（跌破长期均线 / 从最高点回撤 X%） |
| **出场** | **分批**：翻倍卖 1/3，再翻倍卖 1/3，剩下的跟移动止损 |
| **结果** | **赔率不固定**，靠"少数大赢" |

**⑤ 最重要的一点**

> **R 不是"目标"，是"记账单位"。**

它的作用只有两个：

1. **统一度量**（+3R、−1R，可横向比较）；
2. **给仓位公式提供输入**（`股数 = 风险预算 ÷ 止损距离`）。

**⑥ 而"追求高赔率"会推你做两件坏事：**

1. **止损设太近** → 被日常噪音震出（**这正是他原来的问题**）；
2. **只挑"看起来能涨很多"的** → 主观，回到"看"。

> **赔率不是旋钮，是仪表盘。你能拧的只有两个：止损位置、卖出规则。**

### 2.4　新钱规则（**已定**）

**决定**：**不往里加钱**——直到你**扛过一次真实下跌**。

**为什么**：

- 它是**仓位上限**的一种（封顶最大亏损）；
- 它符合"**信几分，投几分**"（第 5 章）；
- 它把"新钱怎么办"这个空缺**直接关掉**。

**注意**：条件**不是**"证明我能赚钱"（那要十几年，且大概率达不到），**而是**"**证明我能扛住一次大跌**"——后者**今年就可能验证**。

**判据**：**一次真实下跌中，我没卖。** → 才允许重新讨论"要不要加钱"。

### 2.5　崩盘 + 回场预案（**最重要的一条**）

**要决定什么**：**两个方向都要写死**——**跌的时候做什么、涨回来的时候做什么。**

**为什么最重要**：**"在场"不是死在平时，是死在"崩盘"和"反弹"这两刻。** 前面所有设计，都要在这两刻接受检验。

**方向一：跌的时候（回撤达到 ______%）**
- 答案通常是——**什么都不做**；
- **但必须事先写下来**，否则那一刻你会**现编**（"这次不一样"）。

**方向二：涨回来的时候（反弹 +______%）**
- **这才是你真正失败的地方**——你的历史是"恐慌早退 → 不信反弹 → 追高"；
- **回场必须是机械的**，**不许等"相信"**（"相信"总是来得太晚）；
- 规则示例：**到某个位置，就按事先定好的规则回场**，而不是"等我信了"。

**判据**：
- 方向一：**一次真实下跌中，我没卖**；
- 方向二：**反弹时我按规则回了场，而不是追高**。

### 2.7　熊市 / 减仓规则（**待讨论**）

**问题**：按"永远在场"，**在牛市顶点入场的人，可能几十年不回本**（日本 1990：约 34 年；纳斯达克 2000：约 15 年）。

**先把问题翻译对**：
- "什么时候不该在场" → 正确形式是 **"仓位什么时候小一点"**（**择方向 → 择风险**）。

**两条可能的路（都不完美）**：

| 规则 | 效果 | 代价 |
|---|---|---|
| 波动规则（波动大 → 仓位小） | 回撤 56.8% → 25.3%（第 4 章） | **"线索，不是保证"** |
| 趋势规则（跌破长期均线 → 减仓） | 动量真实（第 7 章） | **震荡市反复打脸** |

**但"在顶部入场"的答案，不是"躲顶"（你做不到），是四个结构性保护：**

- **宽分散**（地理 + 资产类别）——"日本 1990"的答案；
- **分批买入**——不把全部钱押在一个时点；
- **再平衡**——卖高买低，不让自己卡死；
- **仓位**（留非股票部分）——能在低点回补。

**候选方案：触发式规则（低点加仓 / 极值减仓）**（⬜ **待讨论**）

**形式**：事先写死——"跌 X% → 加 Y%""估值 > Z → 减仓"。

**为什么可接受**：它是**规则**，不是**判断**（不需要预测）。

**但有三条硬约束**：

1. **弹药从哪来**——加仓要留现金，而**留钱 = 漏漂移**（第 9 章）；
2. **锚是什么**——"跌 20%" 相对**成本 / 最高点 / 起点**？（**定义不同，结果差很多**）；
3. **连续下跌**——日本跌 13 年，**弹药会半路用光**。

**核心矛盾**：**"一直在场（拿满漂移）"和"有弹药抄底"，不可兼得**——这是取舍，不是"更好的方案"。

**如果要用，正确写法**：锚明确 / 分档 / **总上限事先定死** / 弹药来源事先定死。

**⚠️ 待讨论**：
- 要不要一个**机械的减仓规则**？如果要，它必须**事先写死**，且**你接受踏空代价**；
- **宽分散 / 分批 / 再平衡 / 仓位**的具体参数，**还没定**。

## 第三块　约束：数字定死

**要决定什么**：仓位上限 / 杠杆 / 卫星上限。

**怎么验证**：**回测**——不同仓位下的**最大回撤**。
（例：第 8 章——三倍杠杆，**57% 的历史回撤 > 90%**。）

**判据**：**在大跌回撤下，你还能睡得着。**
——注意：这个"能睡着"要**被验证**，不是被假设（先小、验证、再加）。

**⬛ 已定（本人决定）**：

- **卫星上限 = $6,000**（写死，**不许漂移**）；
- **核心桶 = 其余，只买指数**；
- **杠杆**：⬜ 待定（建议默认**不用**——第 8 章）。

**"卫星上限"的检验，只有一条**：

> **这 $6,000 全亏光，我会不会想从核心桶搬钱？**
> - **会** → 说明它**太大**，往下调；
> - **不会** → 这个数字成立。

**注意**：**比例不是重点**（31% 偏大或偏小都无所谓），**"亏光会不会想搬钱"才是判据。**

### ⬛ 已定：卫星桶用 Tugboat 的骨架（2026-10，本人决定）

**决定**：**这 $6,000 用 Tugboat 的方法。**

**但"用他的方法"必须写清是"用哪一半"**——因为那份资料（见 `9-资料-TradingTugboat.md`）本身分成两半：

| | 用不用 | 内容 | 为什么 |
|---|---|---|---|
| **骨架** | ✅ **用** | **R（每笔风险 1%，新手 0.5–0.75%）／`股数 = R ÷ 止损距离`／ADR% 过滤器／止损 = 结构位 + 0.5–2 ATR 缓冲 + 硬上限／记录／工具** | **可数、可写、可回测；而且不需要"每天在场"** |
| **判断层** | ❌ **不用** | **SA（市况判断）／催化剂／"大市动能"／突破当天日内级别入场** | **主观、不可证伪；而且要求"每天在场"——和周六看盘的笼子冲突** |

> **判据**：**稳定性和"不需要判断"是同一件事。**
> **你能用的那一半，恰好是"不需要每天在场"的那一半——这不是巧合。**

**Tugboat 的骨架，正好能把前面那两个空格填上**：

| 空格 | 用他的骨架填 |
|---|---|
| **单笔仓位** | **`股数 = R ÷ 止损距离`**——**把问题从"我要押多少钱"变成"我每笔愿意亏多少钱"**（后者好回答得多；而且**波动越大 → 仓位自动越小**） |
| **单笔止损** | **结构位 + 0.5–2 ATR 缓冲**，**但保留一条硬上限**（超过 X% 就放弃这笔） |
| **总回撤停手线** | ⬜ **仍然要自己定**（这个骨架填不了） |

**⚠️ 两个具体冲突，动手前要先解决**：

1. **窄止损 + 小账户 → 仓位会被顶到上限**：R = 1% of $6,000 = **$60**；若止损距离只有 1%，则 `$60 ÷ 1% = $6,000` = **满仓**。→ **所以止损距离要设够宽，或者 R 往下调（0.5%）。**
2. **日内入场 → 需要在场**：和"周一到周五不看"直接冲突。→ **要么放弃日内入场（改用次日执行 / 条件单），要么承认这条规则破了。**

**一条判据（写给"那一刻"的他）**：

> **"不甘"可以决定"要不要开这个桶"；不能决定"用哪一半"。**
> **因为不甘会挑"最刺激的那一半"（判断层 / 日内 / 大牛股）——而那恰好是不稳的那一半。**

### ⬛ 卫星桶的四个数字（2026-10 定稿）

**定这四个数的三个输入**：① Tugboat 的核心（R + ADR + 曝险）；② Kevin 的画像；③ 数学（$6,000 + $2/笔）。

### ⬛ 第二个冲突怎么解：不用 HTF，改用 Pullback

| 选项 | 做法 | 代价 |
|---|---|---|
| A | 保留 HTF，改成**次日执行** | 入场价差、可能错过 |
| B | 保留 HTF，**突破当天看盘** | **违反"周一到周五不看"，而且要在波动中做决定** |
| **C ✅** | **改用 Simple Pullback / Complex Pullback**（**预先挂限价单**） | 放弃"抓发动点"最猛的那一段 |

**为什么选 C（三条，都来自他自己）**：

1. **它天生适合"不看盘"**——回撤交易的入场是**在支撑位挂限价单**，**不需要在开盘那一刻在场**；
2. **它符合 Kevin 的心理**——Tugboat 原话：**"低買帶來價格優勢 → 心理優勢 → 更容易持倉久"**；
3. **它避开了 Kevin 的短板**——**HTF 要在"波动放大的那一刻"做决定；Pullback 是在"波动收缩之后"挂单。**

> **配套**：**入场用限价单、止损用条件单**——**把"手"从流程里拿掉。**

### ⬛ 退出条件（2026-10 定稿）—— 这是最要紧的一条

**为什么它最要紧**：**Kevin 的账户亏的那 46%，全在"卖"上**（自选 50+ 只曾翻倍 vs 账户 −46%）。

**用 Tugboat 的三段式**（他自己在 HTF / Complex Pullback 里都是这么做的）：

| 阶段 | 动作 | 触发条件（**事先写死**） |
|---|---|---|
| **① 止损** | 结构位 + 0.5–2 ATR 缓冲（已定） | 跌破即走，**条件单执行** |
| **② 部分获利** | **卖 1/3–1/2**；**同时把止损上移到成本** | 到**前高**，或 **+2R** |
| **③ 移动止损** | **全部结束** | **首次部分获利之后**，收盘跌破 **20MA** |

**⚠️ 三条附加规则（专门针对 Kevin 的病）**：

1. **"涨了多少"不是卖出理由**——**只有 ② ③ 两条触发才卖**（他的病：入场是动量、出场是均值回归）；
2. **② 之后这笔交易"再也不会亏"**——这是给他的心理保险（满足"怕把浮盈还回去"的那个需要，**但只锁一部分**）；
3. **止损上移之后，不许再下移**——**这条最重要**（他一定会想"再给一点空间"）。

**为什么"③ 必须在首次部分获利之后"**：**Tugboat 自己的解释**——"刚回撤完，股价未必立刻向上，多数还是上下波动一下；**此时收盘跌穿 20MA 很常见，若此时就用移动止损，很容易被打到、导致过早离场**。"

> **这条正好治他的病**：**他过去就是"刚有点波动就卖"——③ 把它推迟到"已经锁过利润"之后。**

**卖出也必须是"预先挂单"**：**止损 = 条件单；部分获利 = 限价单**。**不在场决定。**

**第一版不加仓**（Tugboat 有加仓规则，但那需要更多纪律，而且放大波动）——**用"已实现的 R 去开新仓"代替。**

### ⬛ 参数冻结期：什么时候才允许"改进"

**他说的话**：**"先按你的来，做一段时间有数据了，再做改进。"**

**这句话是对的——但它必须有一条规则保护，否则它会变成"亏了就改参数"。**

**因为"改进"和"过拟合"的区别，只在于"什么时候改"**：

| | 什么时候改 | 性质 |
|---|---|---|
| ✅ **改进** | **季度复盘时改** | 有数据 |
| ❌ **过拟合** | **亏损之后改** | 只有情绪 |

**规则（借 Tugboat 自己的规矩）**：

> **参数的调整频率 = 每季度 / 每年一次**（Tugboat 对 R 的原话）。
> **→ 所以：这一版参数（R / 仓位上限 / 止损 / 停手线 / 退出规则），在第一个季度（≈ 22 笔）走完之前，一个字都不改。**

**判据**：

> **改动只能发生在"季度复盘"这个时间点上；不允许发生在"亏损之后"。**
> **如果某次改动是在亏了之后做的 → 那不是改进，是过拟合。**

**⚠️ 唯一的例外**：**停手线触发**（−25% 或连亏 15 笔）→ **停手，但不改参数**。
**停手 ≠ 改参数；停手是"退出"，改参数是"优化"。**

### 卫星桶的成本上限 → 翻译成"笔数上限"

**已知**：卫星上限 **$6,000**；单笔往返成本 **$2**（买 $1 + 卖 $1）。

| 年成本上限 | 金额 | 笔数上限 | 频率 |
|---|---|---|---|
| 1% | $60 | 30 笔 | 每月 2.5 笔 |
| **3%（建议）** | **$180** | **90 笔** | **每周 ≈ 1.7 笔** |
| 5% | $300 | 150 笔 | 每周 ≈ 2.9 笔 |
| 10% | $600 | 300 笔 | 每周 ≈ 5.8 笔 |

**为什么用"笔数"当上限，而不是"金额"**：

> **$2 太小，你感觉不到——它拦不住你。** 而"**今年还剩 23 笔**"是能感觉到的。

**单位先说清**：**1 笔 = 一次完整往返 = 买 $1 + 卖 $1 = $2**。
→ **90 笔/年 = 90 次往返 = 180 次下单 = $180**；**≈ 每周 1.7 次**（即每周"买 1–2 次、卖 1–2 次"）。

**规则**：**一年 90 笔。一张 90 格的表，每交易一次划一格。划完即停，不许补格。**
（更可执行的写法：**每周最多新开 1–2 个仓**；**平仓不额外计笔**——平仓是被止损 / 规则触发的，不该因为"想卖"而多算。）

**它限制了你什么**：

| 你的打法 | 一年需要几笔 | 装得下吗 |
|---|---|---|
| 同时持 5 只，平均持 1 个月 | 60 笔 | ✅ |
| 同时持 5 只，平均持 2 周 | 120 笔 | ❌ |
| Minervini 式频繁换股（每周十几笔） | 700+ 笔 | ❌ 差得远 |

→ **它允许你做"慢版"，不允许"快版"。而这不是限制，是价格标签**：

| 年成本上限 | 笔数/年 | 每周 | 意味着 |
|---|---|---|---|
| **3%** | 90 | 1.7 | 成本可控 |
| 10% | 300 | 5.8 | 一年交 10% 给券商 |
| 33% | 990 | 19 | **一年把本金交出去** |

**⚠️ 更重要的一点**：**$2 只是"看得见"的成本。**

真正的成本藏在——**点差 / 滑点 / 隔夜利息 / 融资费**。它们**不在 $2 里**，而且往往**比 $2 大得多**。

**而"笔数上限"正好把这两样一起锁住**——每多一笔，**看得见和看不见的成本同时增加**。

> **所以：次数上限 = 总成本上限。** 这就是它比"金额上限"好的地方。

**卫星桶的完整数字**：

| 项 | 值 |
|---|---|
| 本金上限 | **$6,000**（已定） |
| 笔数上限 | **90 笔/年**（$180 ≈ 3%） |
| 单笔仓位 | ⬜ 待填（要求：**连亏 10 次不伤筋动骨**） |
| 单笔止损 | ⬜ 待填（Minervini 用 7–8%） |
| 总回撤停手线 | ⬜ 待填（亏到 ____ → 停，**不许搬钱**） |
| 执行判据 | **有没有违反过自己写下的止损？** |

## 第四块　机制：怎么强制自己（**不可回测**）

**要决定什么**：自动化 / 看盘频率 / 预注册 / 记录。

**为什么不可回测**：这些是**行为机制**，不是策略——**回测测不出"你会不会遵守"**。

**怎么验证**：**自查**，只有一条标准——

> **在"你最想动手的那一刻"，它还生效吗？**

> **关键诊断**：你的短板**不是"忍不了痛"**（账户腰斩你睡得着），**是"痛的那一刻手会动"**。
> **所以机制要锁的是"手"，不是训练"耐受"**——物理隔离 / 少看 / 自动，全部指向"**在最痛的那一刻，让你够不着**"。

> **关于频率**：**频率不是解药，是杠杆**——它放大你的优势（如果有），也放大成本。**没优势时，它只放大成本。**（第 1 章：每年换仓 132 次 → −5.0%）

### 看盘规则（⬛ 已定，数字）

| 项 | 规则 |
|---|---|
| **看盘日** | **周六 上午 10:00–10:30**（市场闭市 → 无实时波动 → 无情绪 → **不能马上交易 = 天然 24 小时冷静期**） |
| **看盘日只做一件事** | **看 + 写下"触发条件核对结果"**（**只写，不动手**） |
| **执行日** | **次日 / 开盘前**——按**写下的结果**执行（是就做，否就不做） |
| **核心桶"体检"** | **每季度 1 次**——只看一件事：**有没有偏离规则**（**不是看涨跌**） |
| **周一到周五** | **不看、不动**（0 次） |
| **总量上限** | **每周 ≤ 1 次** |

**为什么"定时"比"减量"有效**：**"少看"是持续的自我对抗（每时每刻都在忍）；"定时"是一个已完成的决定。**

**为什么把"看"和"决定"分开**：**看盘那一刻，情绪最高**。在那一刻做决定 = 把决定权交给情绪——**而那正是他过去亏钱的方式。**

**补充：核心桶和卫星桶的"看"性质不同**

- **核心桶：看它是"体检"，不是"决策"**（买指数、然后不动）；
- **卫星桶：决策不是"判断"，是"核对"**——价格有没有到 pivot？有没有跌破止损？**是 / 否 → 执行。**
- **规则事先写好了，所以不需要"决定"，只需要"查表"。**

### ⚠️ 但这里有一个洞，必须补上：**止损怎么办？**

**如果止损在周三触发，你不能等周六。**

> **解法：条件单（自动委托）——把"执行"交给系统，把"决定"留给周六。**
>
> **这才是"物理隔离"的真正含义：不是"你不看"，是"系统替你看"。**

**注意**：条件单**防不了跳空**（会以更差的价格成交）——但它**远好于"周三慌了手动卖"**。

**"周一到周五不管"是一条可检验的规则：**

> **检验：周一到周五，我打开了几次？**（= 执行判据的日常版）

**例外通道（必须留，否则规则会被破）：**

> **很想动手时 → 写下来，等到周六。**
> **（大概率，周六你会庆幸自己没动。）**

| **集体行为 / 情绪** | 统计"情绪极端"后的**方向**（能预测吗）和**波动**（能预测吗） | 方向超过随机？波动可预测？ | 第 1 章：**方向不可预测、波动可预测** |
| **行业 / 风格 ETF 选择** | 回测："轮动 / 选行业" vs "**宽基持有**" | 扣成本后**显著超过宽基** | 待验证 |
| **Minervini（领导股 / SEPA）** | 趋势模板**可编码** → 回测；VCP 主观 → 只能实盘；对比**持有 + 简单动量**；扣成本 | 扣成本后**显著超过"持有"和"简单动量"** | 待验证（**带"不甘"，需笼子** → 见下） |
| **反形态理论**（假双底 / 假双顶 / 假突破；出自《走出幻觉·走向成熟》「雕虫小技之反形态理论」） | **书里没给数字** → 必须自己写成可数规则（**最少参数，定死不许调**）；对比**随机对照**；扣成本 | 扣成本后**显著超过随机对照** | 待验证（**但先看下面的"13 年"判据**；⚠️ **需要数据环境——本机暂无数据，等换机器/拿到数据再做**） |
| **趋势 / 动量** | 已有多项研究 | —— | 第 7 章：**弱但真实** |
| **他自己的选股 / 记录表**（Google Sheets，自建） | **先不验证策略**——先看**能不能产出两个数**：① 扫出来的股票后来涨了吗？② 涨的那些他买了吗？ | **能稳定产出这两个数**（**不是**"能选出好股票"） | 待验证（**本人自评"不够成熟"**） |
| **GitHub 上的成熟框架 / 算法** | **只找"工具"**（数据 / 指标库 / 回测 / 统计）——**不找"现成策略"** | **能跑出数字**（用它去量上面那条里的规则） | 待验证（⚠️ **先划清"工具 vs 药"** → 见下） |

> **注意**：**宽基 ETF 不需要验证**（它就是市场）；**要验证的，是"选行业 / 风格"能不能超过它**。

### ⚠️ 关于"去 GitHub 找更成熟的算法"：先划一条线

**GitHub 上有两类东西，性质完全相反：**

| | 是什么 | 拿不拿 |
|---|---|---|
| **工具层** | 回测框架、指标库、数据接口、组合统计 | ✅ **拿**——它们只是**算数**，不产生观点 |
| **策略层** | 现成的信号 / 系统 / "某策略回测年化 XX%" | ❌ **不拿**——**那是别人的药**，而且**公开即被套利**（第 5 章：发表后收益少 **58%**） |

**为什么这条线重要：**

> **框架是尺子，你的规则是被量的东西。**
> **没有你自己的规则，再成熟的框架也量不出任何东西。**

**所以顺序必须是**：**先有你自己的表（哪怕不成熟）→ 再用工具去量它。**
**反过来（先去找"更成熟的算法"）→ 会变成"照着某个仓库做"——那就不是验证，是换药。**

**一条写死的判据：**

> **找工具的终点，是"能跑出数字"；不是"找到一套能用的策略"。**
> **如果最后变成"我要照着这个仓库做" → 停，你回到原点了。**

**具体该找什么（方向，不是推荐）：**

- **数据**：美股日线 / 基本面数据的免费接口；
- **指标**：能算 RSI / ATR / ADR% / 均线的库（省得自己写错）；
- **回测**：能把"一组规则"跑成"一串数字"的框架；
- **统计**：胜率 / 期望 / 最大回撤 / 样本量。

**⚠️ 但不急**：这些**都可以等那三个 `⬜` 填完再动**（单笔仓位 / 单笔止损 / 停手线）。
**先有东西可量，再找尺子。**

### ⚠️ 关于"反形态"：一个**先天的判据**——它已经公开 13 年了

**这本书 2012 年出版。到今天，这套方法已经被公开了 13 年。**

**由此可以推出一个"二选一"：**

| 如果 | 那 |
|---|---|
| **它容易执行** | **早被套利掉了**（第 5 章：因子发表后收益少 58%） |
| **它难执行**（需要判断 / 纪律） | **它可能还有效——但"难执行"恰恰意味着你做不了** |

> **两个分支，都指向同一句话：别指望它。**

**而且它属于"错误定价"类**（赚的是"看图者"的钱）→ **所以它会衰减。**
（对比：**价值、动量公开了也不衰减**，因为它们是**风险补偿**，不是错误定价。）

**所以这条的验证，第一步不是回测，是回答一句话：**

> **为什么 13 年过去了，它还没被套利掉？**

**答不出来 → 它大概率已经失效，不必花时间试。**

> **这个判据是他本人提出来的**："这本书已经这么久了，肯定早就有聪明的人试过。"

**三条铁律**（来自第 3 章，缺一不可）：

1. **事先写下规则**（预注册）——不许看完结果再定；
2. **样本外**检验——用没调过参数的数据；
3. **扣掉成本**——手续费、点差、滑点。

**三条验证路径**：

1. **自己回测**——写代码 + 历史数据（需要数据环境）；
2. **找别人的验证**——论文、GitHub 代码（**注意：别人的验证，也要用上面三条铁律检查它本身**）；
3. **猴子对照**——在**打乱的随机数据**上跑同样的规则。

**判据（只有一条）**：

> **它超过"随机对照"了吗？扣成本后还剩多少？样本外还成立吗？**

> **提醒**：**验证的目的，不是"证明它对"，是"看它会不会被打死"。**
> **如果它连随机对照都过不了，就不必再花时间了。**

### 特例：Minervini（领导股 / SEPA）——一条带"不甘"的待验证项

**为什么单独列**：它不是"一个指标"，是**一整套系统**；而且它是被**"不甘"**推进来的——**所以它需要额外的笼子。**

**先公平地说：它比缠论"值得验证"得多。**

- **趋势模板是可数的**（7 条硬条件）→ **可以编码、可以回测**（缠论的笔 / 线段是主观的，没法回测）；
- 它踩在**动量**上——第 7 章：**弱，但真实**；
- 它的成绩是**可核验的**（不是传说）。

**但它有三个断层，验证时要分开对待**：

| 断层 | 能不能验证 |
|---|---|
| **趋势模板 / 突破买点** | ✅ 可回测（事先写死 + 扣成本 + 样本外） |
| **VCP 的"收缩质量"** | ❌ 主观，**回测不了**，只能实盘 |
| **纪律**（严格止损、大盘不好就空仓） | ❌ 回测永远测不了——**而这才是他成绩的来源** |

**所以这条有两条判据，都要事先写死：**

1. **策略判据**：扣成本后，**显著超过"买入持有"和"简单动量"**。→ 不超过 → **停**（不是"再调调参数"）。
2. **执行判据**（更重要）：**你有没有违反过自己写下的止损规则？** → 违反过 → **这不是策略失败，是你失败** → **也要停**。

**笼子（四条，事先定死）：**

- **钱有上限**：只用**卫星桶**——一笔**能整笔输光、且不影响生活**的钱；
- **规则用他的**：不自己改、不"优化"（一改就变成过拟合，第 3 章）；
- **失败条件写死**：上面那两条，**不许事后改**；
- **不许搬钱**：核心桶 → 卫星桶，**一次都不行**。

**关于"不甘"**（这句话是整份讨论里最诚实的一句）：

> 不甘**不会自己消失**。所以正确做法**不是压住它**，是**给它一个笼子**。

**"试试"有两种，别搞混：**

| 笼子里的"试试" | 笼子外的"试试" |
|---|---|
| **预注册实验**——有上限、有规则、有失败条件 | 无上限、无规则、无失败条件 |
| **允许**，而且是**唯一**能测出"你扛不扛得住"的方法 | **那就是 SOXL 的第二次** |

> **笼子的检验标准只有一条：在你最想加注的那一刻，它还锁得住吗？**

**时间 / 样本**：至少 **N 笔独立交易 / X 个月**（第 5 章：**数次数，不数年**）。**少于这个，结论无效——不管赚亏。**

## 公式（可算的判据）

### 1. 你的结果

$$\text{结果} \;=\; \text{漂移} \;+\; \alpha \;-\; C \;-\; B$$

（漂移 = 在场就有；α = 你的优势；C = 成本；B = 行为损耗）

### 2. 频率

$$\text{结果} \;=\; \text{漂移} \;+\; f\,(\alpha_1 - c) \;-\; B$$

（\(f\) = 交易次数，\(\alpha_1\) = 单次优势，\(c\) = 单次成本）
→ **\(\alpha_1 < c\) 时，频率越高越差。**

### 3. "好位置"

$$\text{收益倍数} \;=\; \frac{P_{\text{终}}}{P_{\text{入}}}$$

→ **分子分母你都控不了。**

### 4. 动 vs 不动（**最重要**）

$$\text{不动} \;=\; \text{漂移}$$
$$\text{动} \;=\; \text{漂移} + \Delta\alpha - C - B$$

$$\Rightarrow\quad \text{动} - \text{不动} \;=\; \Delta\alpha - C - B$$

→ **除非 \(\Delta\alpha > C + B\)，否则"动"差于"不动"。**

### 代入你的值（\(\alpha \approx 0\)）

$$\boxed{\;\text{你的结果} \;\approx\; \text{漂移} \;-\; C \;-\; B\;}$$

→ **你能做的只有两件事：\(C \to 0\)，\(B \to 0\)。**

### α 从哪来（以及为什么不是你的）

| α 来源 | 你有可能吗 |
|---|---|
| **信息优势**（知道别人不知道的） | ❌ 机构更快、更全 |
| **分析优势**（更会处理公开信息） | ❌ 机构有团队 / 数据 / 算力 |
| **结构性优势**（拿特殊条款） | ❌ 你拿不到 |
| **速度优势**（微秒级） | ❌ 你没有 |
| **行为 α**（不被自己吃掉） | ✅ **唯一可能** |

→ **你能增加的 α，只有"行为 α"——而它的增加方式，是"少动"。**

### 除了 α，你还有一个优势：**"可以不做"**（唯一不需要资源的优势）

| | **机构** | **散户** |
|---|---|---|
| **考核** | 季度排名 → 必须短期有表现 | **无** |
| **赎回** | 客户会跑 → 被迫卖 | **无** |
| **规模** | 大资金进不去小机会 | **无** |
| **能不能"什么都不做"** | **不能**（基金经理不能空仓一年） | **能** |

**⚠️ 但"对散户有优势"这句话，有一个陷阱：**

> **跑赢散户不赚钱——因为散户不是你的对手方。你的对手方是市场。**
> **"比散户强"可能只是"亏得少"——那是"减少劣势"，不是"优势"。**

**⚠️ 而编程会毁掉这个优势：**

- **程序化 → 提高频率 → 增加成本、增加过拟合机会**；
- **而"可以不做"恰恰需要"低频"**；
- **所以：越会写程序，越容易把自己变成"小机构"——而小机构是最没有优势的位置。**

**编程在这里的正确定位：不是"武器"，是"栏杆"**

| 用处 | 它是什么 |
|---|---|
| **回测** | **检验**想法（不是产生想法） |
| **把规则写成代码** | 写死 = **强制预注册** |
| **自动化执行** | 定投 / 条件单 → **让"不做"自动化** |

**诚实的上限：**

> **"可以不做"只保证你不被自己搞死——它给你的是"市场收益 − 低成本"，不是超额收益。**

> **"学量化"这条路**：它属于**信息 / 分析 / 速度**那一栏——**门槛是资源，不是知识**。
> 而且你能学到的，是**公开知识**（已被套利）；赚钱的模型**从不公开**。
